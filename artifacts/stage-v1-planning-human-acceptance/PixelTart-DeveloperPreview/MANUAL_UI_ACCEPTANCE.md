# Pixel Tart 策划中心人工验收

这是给摄影师的 10–15 分钟体验记录，不需要看代码。

## 开始前

1. 启动本包对应的 Pixel Tart Developer Preview。
2. 使用测试项目和 3–8 张无敏感信息的参考图。
3. 分别在 1920×1080、2560×1440 或 4K 中可用的一台普通电脑上记录体验；如可行，再切换 100%、125%、150%、200% Windows 显示缩放。
4. 不要移动、复制或删除原始照片。

## 体验流程

### 1. 第一次打开策划中心

- 第一眼是否先看到当前参考图，而不是表单？
- 你是否知道下一步要做什么？

### 2. 拍摄清单

- 创建一个拍摄。
- 切换两个拍摄。
- 拖动拍摄调整顺序。
- 用右键查看拍摄操作。

### 3. 参考图

- 添加本地参考，确认原图位置没有被复制或移动。
- 依次查看灯位、姿势、分镜、造型参考。
- 选择一张参考，确认中央大图比例正确、没有裁切或变形。

### 4. 快速预览

- 双击参考图或按 Space。
- 用上一张/下一张切换。
- 按 Esc 关闭。

### 5. 检查器

- 默认先看摘要。
- 点击“编辑”后修改标题、场景、时长和备注。
- 点击“完成”，确认保存状态回到“已保存”。

### 6. 进入联机拍摄

- 点击“进入联机拍摄”。
- 确认当前拍摄仍然对应。
- 返回策划中心。

### 7. 已拍素材

- 在策划中心点击“已拍素材”。
- 确认能够回到当前项目的素材查看范围。

## 只问真实体验

1. 第一眼你知道从哪里开始吗？
2. 哪一块看起来最拥挤？
3. 哪个按钮让你犹豫过？
4. 参考图够不够大？
5. 拍摄切换顺不顺？
6. 灯位/姿势能不能迅速找到？
7. 右侧信息是不是太多？
8. 有没有像后台管理软件的地方？
9. 有没有英文或工程词？
10. 有没有控件看起来特别廉价或不统一？
11. 1080p 下中央图片区够不够大？
