These twelve orig.01-orig.12 designs come from the user-authorized R5.3 final instant-r3.html FRA_ORIG array, not external Polaroid photography or collaboration IP. Design archive SHA256: 16f75c0f40b506e4db57f140f389967264040cd8c5930ad24946b11c171e2ca9. The original metadata states: 光镜原创角色与图案，可随产品发布. Root individual frame source/rights/name/window and PNG/RGBA hashes are retained in manifest.json. Transparent PNG/WebP design pixels were decoded once to RGBA8 and zlib-compressed losslessly for a Core embedded resource, preserving the exact decoded RGBA hash. No GPL code or third-party LUT used. Photos/official collaboration frame samples are not included.

Resource version1: straight encoded-sRGB RGBA8, fixed normalized window. Recipe freezes ID/version/decoded RGBA SHA256 and window geometry; unrecognized or missing resource fails explicitly. Data remain content-bound; future artwork changes require new identity/version, never overwrite existing ID bytes.
