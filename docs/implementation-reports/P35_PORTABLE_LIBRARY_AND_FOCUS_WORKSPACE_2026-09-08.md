## 数据安全与回滚

Reference 不写源文件；Managed 仅复制并校验 hash。容器、导入解压和 staging 均拒绝路径穿越、绝对路径、重复规范路径和 reparse；目标存在不覆盖。锁 owner 记录 PID、启动时间、machine/session、库 ID 和 lease，不能按裸 PID 清除。  
回滚按提交点执行：优先回到 `f083521`（保留全部功能但移除报告），或按上述阶段提交逐点回退；不得 reset/强推。原库迁移失败时原数据库保持原位，包/合并失败只清理本次 operation staging。

## 使用方式与已知限制

用户从素材库顶部库名入口选择父目录/库名，系统自动创建 `.ptlibrary`；离线库从同一菜单重新定位。`.ptpack` 通过库菜单导出/导入，合并先预览再明确提交。专注偏好可关闭，退出素材库恢复进入前窗口状态，崩溃恢复使用持久化标记。  
本轮不实现 P4 策划中心、临时托盘或 Office 导出；仅提供稳定引用记录和素材离线后的重定位能力。10k/100k 性能为合成 metadata 验收，不代表真实用户库文件已被读取。
