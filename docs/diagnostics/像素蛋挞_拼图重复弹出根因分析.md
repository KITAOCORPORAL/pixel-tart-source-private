# 像素蛋挞拼图重复弹出根因分析

## 结论
本次重复拼图由外部安装版验收脚本引起：脚本在系统确认对话框未被可靠关闭时，继续按固定步骤点击工具箱、导入图片和模板，造成重复操作观感。正式 Release 启动路径未调用 UI Review 场景，`UI_REVIEW_BUILD` 代码通过条件编译排除。

## 产品检查
应用启动默认初始化到 `Workbench`/`ProjectCenter`，不会自动导入照片或选择 2×2。拼图页面由用户导航命令进入，页面 ViewModel 在构造时不执行导入。

## 修复
- 停止并记录外部自动化进程，不再控制用户正式窗口。
- 导航命令对同一目标短路，避免重复导航。
- 侧栏移除与首页快速向导重复的“本地分片”完整入口，仅保留首页快速向导和归片工作区。
- 继续保留 UI Review 与安装验收证据，不将测试数据写入正式设置。

## 限制
安装交互验收脚本尚未形成完整通过结果；其余业务与逻辑 DPI 证据需在新的验收器生命周期修复后重跑。
