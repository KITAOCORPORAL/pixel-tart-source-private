# Eagle 交互行为规范（观察版）

本规范描述可复用的行为结构：触发 → 作用对象 → 状态变化 → 反馈 → 取消/失败。具体实现以 `06_PixelTart素材库交互基线.md` 为准。

## 搜索与筛选

- 顶部筛选按钮可增加条件；“更多”浮层仍停留在图库上方，显示搜索范围、图钉/拖动柄和条件当前值。
- 名称与文件夹名可同时勾选；尺寸、时长、大小采用最小/最大区间并带单位；注释支持有/无和关键词（逗号分隔）。浮层未提交查询前，不应清空当前图库。
- 语义搜索入口显示输入框；本片只看到输入，未验证提交、网络失败或无结果。
- 标签选择器显示搜索框、分组和数量；底部明确左键“选择”、右键“排除”、Esc“关闭”。这三种操作应分别表达包含、排除和取消，不以颜色单独表达。

## 标签与分组

- 标签管理按字母分区显示数量，左侧有全部/未分类/常用标签和标签组；组名可内联编辑。
- 加标签浮层按最近使用、推荐、标签组和其它分区组织；输入新标签后数量即时变化。方向键、Enter、Esc 是界面提示，需单独做键盘验收。
- 标签排序至少展示 A→Z、Z→A、数量升/降和分组依据；排序不应改变标签成员关系。

## 布局、密度和选择

- 网格卡片保持横竖素材原比例，格式角标、文件名和尺寸在卡片内表达；图片是主体。
- 切换库时旧页面先进入加载/灰色占位，再渐进出现缩略图；期间不得把空状态误报为库为空。
- 密度滑块可从约 5 列变为 2 列或 1 列。选择卡片的蓝色描边/填充在变化后保持；当前录屏未证明精确滚动锚点算法。
- 多选 Inspector 显示“已选 N 个文件”；右键未选中项时应先单选，已在选择集内右键时保留集合。

## 菜单、触边与反馈

- 右键菜单按打开、整理、复制、导出、显示、危险操作分段；子菜单在右侧空间不足时向左展开，不遮挡触发对象的全部上下文。
- 成功批量删除显示数量 Toast；失败任务显示错误确认弹窗并提供取消/查看详情。不要把任务错误确认误记为素材删除。
- 删除到回收站与永久删除分两步；永久删除有明确二次确认和不可逆文案。旧 Eagle 默认快捷键历史显示 Delete=回收站、Shift+Delete=从文件夹移除，具体产品语义必须在 Pixel Tart 中显式区分。
- 导出子菜单可见素材包、导出到电脑、指定格式/尺寸、CSV；录屏只证明菜单存在，不证明文件已写出。

## 任务和切库

后台任务完成前切库会警告可能的信息遗失，同时提供取消和强制切换。Pixel Tart 应在安全取消/分段后允许强制切换，并将任务绑定原 LibraryId；不能伪装成绝对禁止或让旧任务写入新库。

## 证据边界

插件详情页中的 AI 动作、模型配置和示范截图是说明内容，不是本次已安装或已执行的动作。浏览器/文件管理器/Photoshop 同屏只证明协同环境存在，不证明跨应用操作成功。
