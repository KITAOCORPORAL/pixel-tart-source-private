# 像素蛋挞文件安全规范

## 1. 适用范围

适用于索引、匹配、复制、移动、重命名、整理、压缩、水印、转档、拼图导出、XMP 写入、项目迁移、查重处理和更新回滚。

## 2. 安全优先级

1. 不损坏源文件；
2. 不静默覆盖；
3. 不静默删除；
4. 操作可预览和追溯；
5. 失败可停止、重试或恢复；
6. 便利性不得绕过以上规则。

## 3. 默认行为

- 默认模式：复制；
- 默认冲突策略：自动编号；
- 默认删除：关闭；
- 默认覆盖：关闭；
- 默认网络上传：关闭；
- 默认只扫描用户选择的目录；
- 客户 JPG 默认只作编号依据；
- RAW 和原始高分辨率文件不自动上传。

## 4. 操作分级

| 级别 | 示例 | 要求 |
|---|---|---|
| 只读 | 扫描、索引、预览、哈希、元数据读取 | 不修改源文件时间和属性 |
| 低风险写入 | 复制到新文件、报告、缩略图 | CreateNew 或原子临时文件；不覆盖 |
| 中风险 | 重命名副本、生成目录、XMP 副本 | 操作清单、冲突预览、可撤销 |
| 高风险 | 移动、覆盖、原 XMP 替换 | 二次确认、备份、执行后校验 |
| 极高风险 | 永久删除、批量覆盖源文件 | 默认禁止；逐批确认；必须有恢复/回收站策略 |

## 5. 执行前检查

每个写任务必须检查：

- 来源存在且不是输出目录的别名；
- 目标路径在用户选择的目标根目录内；
- 目录可写；
- 磁盘空间满足预计输出和安全余量；
- 路径长度、非法字符和保留名；
- 目标同名文件和冲突策略；
- 源与目标是否同一文件；
- 外接盘是否在线；
- 文件是否只读、占用或权限不足；
- 操作数量、预计字节数和风险摘要。

## 6. 操作清单

开始执行前必须生成不可变清单：

```text
OperationId
TaskId
SourcePath
DestinationPath
OperationType
ConflictPolicy
ExpectedSourceSize
ExpectedSourceModifiedAt
OptionalSourceHash
State
ErrorCode
```

用户确认的是清单摘要，不是模糊的“开始处理”。清单可导出 JSON/CSV，必须脱敏诊断版本中的真实路径。

## 7. 复制规范

- 源文件以只读共享方式打开；
- 目标使用 `FileMode.CreateNew`；
- 同名默认生成 `_2`、`_3` 或规则化后缀；
- 输出完成后 Flush；
- 校验文件长度；重要任务可选 SHA-256；
- 取消或失败只删除本任务创建的部分文件；
- 不修改源文件；
- 保留必要时间戳时显式记录。

## 8. 移动规范

- 默认不选；
- 二次确认并展示文件数、总大小、来源和目标；
- 优先复制→校验→删除源，而不是直接跨卷 Move；
- 删除源前再次确认目标校验通过；
- 单项失败停止同一文件的后续动作；
- 任务中断后通过清单判断当前文件在源、目标或两处；
- 不允许把未知目标文件覆盖掉。

## 9. 删除规范

- AI、查重和废片工具只标记，不自动删除；
- 优先移到 Windows 回收站或用户指定隔离目录；
- 永久删除必须单独入口和明确确认；
- 删除分组只删除分组定义，不删除照片；
- 删除缓存不得影响源文件；
- 删除用户数据不得与普通卸载混在默认流程。

## 10. 重命名和整理

- 先生成旧名→新名预览；
- 检查循环、重复和大小写冲突；
- 同目录批量重命名使用临时中间名避免互换冲突；
- 默认自动编号，不覆盖；
- 整理输出默认复制到新目录；
- 移动整理遵守移动规范；
- 每次任务生成反向映射供撤销。

## 11. XMP 安全

- 写入前备份原 XMP；
- 不修改 RAW 本体；
- 保留未知命名空间和字段；
- 使用临时文件写入并原子替换；
- 替换后重新解析验证；
- 失败保留原文件和备份；
- 不把 XMP 写入错误的同编号照片。

## 12. 撤销

撤销不是简单反向执行。必须先检查：

- 目标文件仍存在；
- 大小/哈希符合任务完成记录；
- 原位置没有新文件；
- 反向操作不会覆盖；
- 用户未在任务后手工修改文件。

任何前提不满足时停止撤销并生成报告。

## 13. 崩溃恢复

- 每个文件完成后提交检查点；
- 启动时将 Running 任务改为 Interrupted；
- 显示继续、回滚、放弃记录三种选择；
- 不自动继续高风险移动、覆盖或删除；
- 不把部分输出误判为完成；
- 恢复前重新检查源、目标和磁盘状态。

## 14. 故障测试矩阵

必须覆盖：空目录、中文路径、空格、超长路径、只读目录、无权限、磁盘不足、文件占用、外接盘断开、同名文件、同名不同内容、零字节、损坏图片、大文件、大量小文件、取消、进程异常退出和重启恢复。

## 15. 当前实现评价

现有 `MediaCopyService` 和 `RawCopyService` 已满足默认复制、CreateNew、自动编号、磁盘/权限检查、路径约束、取消清理和源文件保护，是后续安全层的可复用基础。

缺口是没有持久化操作清单、完成校验、撤销日志、任务恢复和统一错误码。2.0.4 的真实整理与拼图导出必须先使用版本化操作清单，2.1.0 再统一到任务引擎。
