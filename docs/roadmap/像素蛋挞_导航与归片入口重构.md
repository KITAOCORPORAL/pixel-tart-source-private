# 像素蛋挞导航与归片入口重构

## 当前定义

- `Workbench`：工作台首页。
- `LocalSplit`（后续命名 `LocalSelectionWizard`）：本地分片快速向导，仅处理选择输入、选择来源、设置格式和开始扫描。
- `Workflow`（后续命名 `WorkflowWorkspace`）：归片工作区，负责匹配、冲突、复制、报告、保存和继续项目。
- `ProjectHistory`：项目历史。
- `Toolbox`：工具箱。
- `Settings`：设置。

## 入口原则

首页“开始本地分片”和文件菜单打开快速向导；侧栏“归片工作区”打开完整工作区。二者不映射为同一页面。快速向导完成扫描后通过显式上下文进入工作区，传递 ProjectId、SelectionInput、SourceDirectories、FormatRules、ScanResultId 和 ConflictSummary，不使用静态全局变量。

## 2.0.4 调整

本地分片页标题明确为“本地分片快速向导”，导航命令对当前目标短路，避免重复导航。侧栏不再放置“本地分片”一级入口；工作台大卡片与“文件 → 新建本地分片”负责打开向导，侧栏“归片工作区”只打开完整工作区。
