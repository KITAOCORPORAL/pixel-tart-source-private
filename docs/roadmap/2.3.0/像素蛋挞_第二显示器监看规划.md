# 像素蛋挞第二显示器监看规划

## 1. 结论

独立客户监看窗口在当前 WPF 架构上可行。它应是同一联机会话的只读/有限标记消费者，关闭、崩溃或显示器断开都不得终止联机拍摄、目录监视或复制任务。

## 2. 组件

建议新增：

- `ClientMonitorWindow.xaml`
- `ClientMonitorViewModel.cs`
- `IClientMonitorCoordinator`
- `IMonitorTopologyService`
- `IMonitorColorProfileService`
- `MonitorDescriptor`
- `ClientMonitorSettings`
- `ClientMonitorSnapshotBus`

主窗口不直接设置客户窗口像素位置；由 `IClientMonitorCoordinator` 统一创建、恢复、移动、全屏和关闭。

## 3. 显示器识别

不能持久化“显示器 2”这样的枚举下标，因为拔插、扩展坞、远程桌面或显卡更新会改变顺序。

`MonitorDescriptor` 建议包含：

```text
StableKey = Hash(DeviceName + EDID摘要(若可用))
DeviceName
BoundsPx
WorkingAreaPx
IsPrimary
DpiX / DpiY
ColorProfileKey
FriendlyName（仅本机显示）
```

使用 `System.Windows.Forms.Screen.AllScreens` 或 Win32 `EnumDisplayMonitors` 获取拓扑；持久化 StableKey 和最近边界。恢复时先按 StableKey 匹配，再按设备名/边界保守匹配，禁止只按数组索引。

## 4. 打开流程

1. 用户点击“客户屏幕”。
2. 显示当前可用显示器列表、主屏标记、分辨率、缩放和 ICC 状态。
3. 默认推荐非主屏；只有一个屏幕时允许窗口化预览，不自动全屏主屏。
4. 创建窗口后先设置目标屏幕的正常边界，再进入无边框全屏。
5. 窗口订阅当前选中资产和监看设置快照。
6. 显示成功后保存 StableKey 和显示选项。

用户未显式打开时不得自动创建客户窗口。

## 5. 客户屏幕内容

默认只显示：

- 当前照片/占位图。
- 可选项目显示名或 Logo 占位（Logo 功能后续）。
- 可选星级和客户收藏状态。
- 联机断开时的简洁状态。

默认隐藏：

- 完整路径和目录。
- 文件名。
- 客户/模特资料。
- 相机序列号。
- 技术错误详情。
- EXIF、拍摄参数和摄影师备注。
- 任务路径和备份状态。

文件名、拍摄参数、评分必须分别由用户显式打开；完整路径永远不显示。

## 6. 自动最新与锁定

- 默认与主工作区的 `AutoFollowLatest` 同步。
- 客户窗口可独立锁定当前照片；锁定不改变主窗口选择。
- 主窗口可选择“客户屏跟随主选择”或“客户屏只跟随最新”。
- 新照片到达时使用淡入，不排队播放全部动画。
- 客户窗口关闭后主窗口状态和会话保持不变。

## 7. LUT 与 ICC

- LUT 选择、强度和开关默认与主监看同步；可选“客户屏独立 LUT”留到后续。
- LUT 计算结果在工作空间共享，输出阶段按客户显示器 ICC 单独转换。
- 客户屏无 ICC 时显示只在主窗口可见的警告徽标，客户图面保持简洁。
- 不把主屏已转换像素直接复制到客户屏，避免两屏配置差异。
- 窗口跨屏移动后重新识别目标 ICC 并使旧输出缓存失效。

## 8. 客户收藏和备注

- 客户可通过大按钮或指定快捷输入切换收藏。
- 收藏写入 `ITetherAnnotationService`，主屏立即同步。
- 客户备注使用明确的输入入口；屏保/全屏时默认隐藏键盘焦点。
- 备注正文不进入审计、通知历史或诊断包。
- 客户屏没有删除、移动、复制或“快速拒绝”权限。

## 9. 显示器断开恢复

监听 Windows 显示设置变化并重新枚举拓扑：

1. 如果目标 StableKey 仍存在，仅更新边界/DPI/ICC。
2. 如果目标显示器消失，立即停止向该窗口提交新帧。
3. 默认关闭客户窗口并把控制返回主窗口；显示一次非阻塞通知。
4. 联机会话、Watch Folder、任务和标记服务继续运行。
5. 不自动把客户内容全屏显示到主屏，避免意外遮挡工作区或暴露内容。
6. 显示器重新连接后由用户手动重新打开；可提供“恢复上次屏幕”按钮。

窗口绝不能恢复到不存在的负坐标/离屏区域。

## 10. DPI 与窗口几何

- Windows 屏幕 API 返回物理像素，WPF 使用 DIP；协调器负责每屏换算。
- 支持主屏 100%、客户屏 150/200% 等混合 DPI。
- 响应 `WM_DPICHANGED`，采用系统建议边界，避免缩放后裁切。
- 全屏边界使用目标 `Bounds`；窗口化使用 `WorkingArea`。
- 拔插或编号变化后重新钳制窗口到可见区域。
- 不要求用户切换 Windows 缩放进行开发；自动化覆盖逻辑 DPI，最终人工实机验收独立进行。

## 11. 渲染与性能

- 两个窗口共享源代理图和 LUT 中间结果，不共享显示器最终颜色转换结果。
- `ClientMonitorSnapshotBus` 发布不可变、节流后的当前帧快照。
- 客户窗口慢或被遮挡时丢弃旧帧，只保留最新帧。
- 第二窗口不得让解码并发翻倍；同一资产只解码一次代理图。
- 动画可关闭，高对比/减少动态效果时不使用淡入。
- 客户窗口崩溃捕获为 UI 故障，不释放 `ICameraSession`。

## 12. 设置持久化

`ClientMonitorSettings` 建议保存到 `AppSettings`：

- `LastMonitorStableKey`
- `FullScreen`
- `FollowMode`
- `ShowFileName`
- `ShowExposureSettings`
- `ShowRating`
- `SyncLut`
- `LastWindowBoundsDip`

不保存客户备注、图片像素或显示器 ICC 二进制。保存的设备名/稳定键不得进入诊断包明文。

## 13. 测试矩阵

- 单屏：窗口化预览，不强制主屏全屏。
- 双屏：选择、全屏、关闭、重新打开。
- 目标屏断开、恢复、编号变化、主屏切换。
- 不同分辨率、横竖屏、负坐标布局。
- 主屏/客户屏 100–200% 不同 DPI。
- ICC 相同、不同、缺失和变化。
- LUT 同步、关闭、损坏回退。
- 自动最新、主屏选择跟随、客户独立锁定。
- 客户收藏/备注同步，日志不含正文。
- 客户屏关闭、崩溃不终止联机会话。
- 深色、浅色、高对比、键盘和屏幕阅读器名称。
- Release 不注册 Fake Monitor，不依赖 localhost。

## 14. 发布门禁

- 窗口不会出现在不存在的屏幕。
- 断屏后 2 秒内安全回到主窗口控制，联机会话继续。
- 两屏不同 DPI 无裁切、模糊放大或 100% 像素映射错误。
- 默认隐藏路径和技术资料。
- 源照片、EXIF 和项目输出未被修改。
- 客户窗口关闭不会取消 TaskEngine 中的复制/备份任务。
