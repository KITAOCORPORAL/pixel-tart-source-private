# 像素蛋挞 2.3.0 阶段实施排期

## 1. 总体排期

| 阶段 | 名称 | 建议工作量 | 主要交付 | 是否接入真实厂商 SDK |
|---|---|---:|---|---|
| A | 架构、SDK、色彩只读规划 | 已完成 | 8 份规划文档与总报告 | 否 |
| B | 看守文件夹联机 MVP | 7–10 个工作日 | 目录监视、稳定检测、恢复、任务复制 | 否 |
| C | 现场监看工作区 | 10–14 个工作日 | 大图、缩略图、比较、标记、客户确认 | 否 |
| D | LUT 与第二显示器 | 10–14 个工作日 | `.cube`、ICC、客户屏幕 | 否 |
| E | 性能、恢复、DPI、安装版验收 | 7–10 个工作日 | 全量门禁、隔离安装版验证 | 否 |

总计约 34–48 个工作日，不含真实厂商 SDK、实机采购、法务许可审核和 GPU 渲染器研发。

## 2. 阶段 A 完成条件

- 从 `v2.2.0` 创建 `release/2.3.0`。
- 核验 2.2.0 Tag、正式二进制源和安装包哈希。
- 只新增规划文档，不改产品代码和版本号。
- 官方资料覆盖 Sony、Canon、Nikon、Fujifilm、FileSystemWatcher、WPF ICC 和 Windows 多显示器。
- 确认 2.3.0 默认不接入真实厂商 SDK。

阶段 A 完成后立即停止，不自动开始阶段 B。

## 4. 阶段 C：现场监看工作区

### 主要任务

- 三栏现场监看布局和独立 ViewModel。
- 代理图/100% 按需预览、取消和 LRU。
- 自动最新、锁定、导航、全屏。
- EXIF、RGB 直方图、高光/阴影警告。
- 并排/重叠比较、参考图、辅助线。
- 星级、颜色标签、摄影师备注、客户收藏/备注、快速拒绝。
- 虚拟化、键盘、无障碍和 100–200% DPI。

### 退出门禁

- 新照片不抢占锁定/手动检查。
- 快速切图无旧结果回写。
- 快速拒绝不删除。
- 1000 项列表和 100 张连拍性能达标。
- 全量测试/构建通过后立即停止。

## 5. 阶段 D：LUT 与第二显示器

### 主要任务

- `.cube` 解析/验证、1D/3D CPU 处理。
- LUT 收藏、搜索、默认、强度、开关、分屏。
- ICC 识别、WCS 默认显示器配置、每屏转换和提示。
- 客户监看窗口、StableKey、全屏、锁定、隐私选项。
- 客户收藏/备注同步。
- 断屏、跨屏、混合 DPI 和不同 ICC。

### 退出门禁

- LUT 和 ICC 失败均回退原始监看。
- LUT 零修改源文件。
- 断屏不终止会话。
- 客户屏默认隐藏敏感信息。
- 全量测试/构建通过后立即停止。

## 6. 阶段 E：性能与最终验收

### 主要任务

- 性能基准、内存压力、LRU、长会话和睡眠唤醒。
- GPU 路线只评估；CPU 达标则不引入 D3D 风险。
- 断盘、崩溃、数据库锁定、任务恢复。
- 100–200% DPI、双屏实机、深浅/高对比、无障碍。
- Release 架构扫描：无 Fake、无厂商 DLL、无 localhost、WinExe。
- Debug/Release 全量和隔离安装版验收。

### 最终边界

- 只有阶段 E 获得单独授权后才 Publish、生成 2.3.0 安装包、合并 main、创建 `v2.3.0`。
- 本阶段排期本身不授权这些发布动作。
- 2.3.0 封版后不自动进入 2.4.0 厂商 SDK。

## 9. 风险缓冲

建议为以下不确定项预留 20% 缓冲：

- FileSystemWatcher 在外接盘/网络共享上的差异。
- WPF 大图解码、TIFF 和 RAW 占位策略。
- 多显示器混合 DPI/ICC。
- `.cube` 方言和 CPU 性能。
- SQLite Schema 3 是否在阶段 B 获批。

厂商 SDK、实机采购和许可审计不计入 2.3.0 排期。
