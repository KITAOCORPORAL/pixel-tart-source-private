# 像素蛋挞 2.3.0 测试计划

## 1. 测试基线

- 正式 2.2.0 基线：867/867。
- 2.3.0 必须保留全部 867 项，不允许通过删除、忽略、改名绕过或降低断言恢复绿色。
- 阶段 A 只新增文档，不运行代码测试；阶段 B 起每阶段都运行专项测试和 Debug/Release 全量。
- 所有文件、数据库、LUT、缓存和监视测试使用独立临时目录，禁止操作桌面、真实 LocalAppData、真实照片或客户资料。

## 2. 测试分层

| 层级 | 目标 | 主要项目 |
|---|---|---|
| Core 单元 | 状态机、去重、稳定算法、配对、LUT 数值、隐私 | `RAWSelectionAssistant.Tests` |
| WPF/ViewModel | 命令、可用性、最新/锁定、客户屏同步、无障碍 | `RAWSelectionAssistant.WpfTests` |
| DPI | 100–200%、混合显示器几何、逻辑像素 | `RAWSelectionAssistant.DpiTests` |
| 集成 | FileSystemWatcher + SQLite + TaskEngine + 文件复制 | 独立临时根 |
| 安装版 | Release 注册、Provider=None、无 Fake/localhost、WinExe | 阶段 E 隔离桌面 |
| 性能/耐久 | 连拍、缓存、内存、断盘、长会话 | 可重复合成数据 |

## 3. 测试资产规则

- 图片使用测试代码生成的纯色、渐变、棋盘格、EXIF 最小样本。
- RAW 测试优先使用最小伪容器/占位合同测试；如需要合法公开样本，必须记录许可和来源，不纳入隐私日志。
- LUT 由测试生成：identity、反相、通道交换、小型 3D LUT、损坏/超限文本。
- ICC 使用系统标准 sRGB 或测试自带、许可清晰的最小配置；不读取用户真实显示器配置文件到报告。
- 大文件可使用临时稀疏文件或合成字节流，不复制用户照片。
- 每个测试创建唯一根目录和 SQLite 文件，销毁前只清理该绝对路径。

## 4. Watch Folder 测试

### 4.1 新文件与稳定性

- 新 JPG/JPEG/PNG/TIFF 进入 Ready。
- 受支持 RAW 进入 Ready 或 `RawPreviewUnavailable`，不判定丢失。
- 文件分块慢写时，在稳定前不解码、不复制、不显示完成。
- 长时间锁定、独占写入、零字节后增长。
- 采样长度相同但 LastWrite 继续变化；LastWrite 相同但长度变化。
- 稳定超时进入 NeedsAttention，后续变化可恢复。
- 取消稳定探测无残留任务和文件句柄。

### 4.2 事件语义

- Created + 多次 Changed 只生成一个资产。
- 临时文件创建后 Renamed 为正式扩展名。
- 同名文件替换/修订不覆盖旧资产快照。
- 重复 Renamed、Changed 乱序。
- watcher `Error`/`InternalBufferOverflowException` 触发一次受限补扫。
- 补扫只读取选定目录顶层，`IncludeSubdirectories=false`。
- 子文件夹新文件不进入会话。

### 4.3 大量连拍

- 100、500、1000 个事件突发。
- 有界队列满时合并为补扫信号，不丢最终稳定文件。
- 最新照片优先显示；历史缩略图后台补齐。
- UI 更新节流，不为每个 Changed 产生通知弹窗。
- 内存峰值和最终回落在预算内。

### 4.4 JPG/RAW 配对

- JPG 先、RAW 后。
- RAW 先、JPG 后。
- 只有 JPG、只有 RAW。
- 相同主干、多组时间接近候选进入 NeedsAttention。
- 不同目录/会话不跨会话配对。
- 应用重启后配对结果幂等。

### 4.5 目录故障

- 外接盘断开/恢复。
- 目录删除/重新定位。
- 枚举权限被撤销。
- 中文、空格、组合字符、长路径。
- 只读目录（监看允许，复制目标校验失败）。
- 网络共享暂时不可达（如产品允许选择时），不无限重试。
- 应用重启时不自动开始会话；用户确认后恢复未完成项。

## 5. 安全复制与备份测试

- 默认不创建任何副本。
- Copy + CreateNew + AutoNumber。
- 同名、同名不同内容、目标已存在。
- 长度验证和可选 SHA-256。
- Flush 后输出可重新打开。
- 复制成功后才保存 ManagedCopy 关系。
- 复制一部分后断盘：成功项保留，失败项 PartiallyCompleted/NeedsAttention。
- 取消只清理本任务创建的未完成输出。
- 源文件长度、时间和 SHA-256 在复制、取消、重试、撤销后不变。
- Undo 只删除本任务创建且未被外部修改的副本。
- 项目复制成功而备份失败时，监看继续。
- TaskEngine 暂停/恢复/取消/重试和重启恢复。

## 6. 现场监看测试

- 自动显示最新、锁定当前、返回最新。
- 用户检查旧图时新图不抢焦点。
- 上一张/下一张边界和排序稳定。
- Fit、100%、自由缩放、拖动边界。
- 快速切图取消旧解码，旧结果不能覆盖新选择。
- 虚拟化列表 1000 项，不持有全部大图。
- 缩略图损坏、代理缓存损坏和重建。
- EXIF 成功/失败、序列号脱敏。
- RGB 直方图、高光/阴影警告开关。
- 并排比较同步/独立缩放。
- 重叠比较、参考图叠加和辅助线不生成文件。
- 星级 0–5、颜色标签、摄影师备注、客户收藏/备注。
- 快速拒绝只标记，不删除。
- 源文件丢失后标记仍可见。

## 7. LUT 测试

### 7.1 解析与验证

- 有效 1D/3D、TITLE、DOMAIN_MIN/MAX、注释和空行。
- 数据不足/过多、重复头、缺少尺寸。
- NaN、Infinity、区域顺序错误、非法小数。
- 维度和文件大小上限。
- 混合 1D+3D 返回不兼容，不猜测。
- 文件导入后被外部修改/丢失。

### 7.2 数值

- identity LUT 输出与容差内输入一致。
- 反相、通道交换、端点钳制。
- 三线性插值已知点和边界。
- 强度 0%、50%、100%。
- CPU 重复执行确定性。
- 取消旧 LUT 请求，最新请求胜出。

### 7.3 安全

- 开关、强度、分屏、收藏、搜索不修改源文件。
- 项目 LUT 设置不写入 EXIF/RAW/JPG。
- 损坏 LUT 自动回退原始监看。
- 日志不含 LUT 文件名、路径、内容指纹。
- GPU 不可用时正式路径仍为 CPU；Release 不依赖可选 GPU 组件。

## 8. ICC 与显示器测试

- 嵌入 sRGB、Display P3、Adobe RGB 的识别提示。
- 无嵌入 ICC 按 sRGB 假定并提示。
- 损坏/不支持配置安全回退。
- `WcsGetDefaultColorProfile` 成功、无配置、权限/调用失败。
- 主屏和客户屏不同配置分别转换。
- 配置变化使对应缓存失效。
- 窗口跨屏时切换目标配置。
- 不显示完整 ICC 路径。
- 不出现“保证色准”“完成校色”“软打样准确”等不实声明。

## 9. 第二显示器测试

- 单屏窗口化；不自动主屏全屏。
- 双屏选择和 StableKey 恢复。
- 显示器编号变化但 StableKey 不变。
- 目标显示器断开时关闭客户窗口、会话继续。
- 显示器重新连接后用户手动恢复。
- 负坐标、横竖屏、主屏切换、不同分辨率。
- 主屏/客户屏 100%、125%、150%、175%、200% 混合 DPI。
- 默认隐藏路径、文件名、技术参数、客户资料。
- 客户收藏/备注同步，客户屏无删除/复制命令。
- 客户窗口关闭/异常不取消 Watch Folder 或 TaskEngine 任务。

## 10. 隐私测试

向服务输入包含以下诱饵的路径和文本：客户姓名、手机号、完整文件名、完整路径、64 位哈希、相机序列号、备注正文。

验证：

- AuditLogs 的 `SanitizedMessage` 不包含诱饵。
- Notification 历史不包含完整路径/文件名/备注。
- 诊断导出不包含 LUT/ICC 路径、序列号或图片内容。
- UI 本机需要显示文件名时，不将该值复制到持久通知。
- 客户屏默认不显示诱饵字段。

## 11. 恢复与数据库测试

- 阶段 A 保持 SchemaVersion 2。
- 若阶段 B 批准 Schema 3：迁移前备份、事务、重复执行、失败保留旧库、数据库高版本阻止写入。
- 每个 SQLite 测试使用唯一临时库，并只清理自己的连接池。
- Running/Stabilizing/CopyPending 在重启后转为可恢复状态。
- 已 Ready/Copied 项不重复。
- 数据库锁定时预览继续，标记写入 NeedsAttention。
- `PRAGMA integrity_check=ok`。
- 数据库只存路径和元数据，不存图片/LUT/ICC 二进制。

## 12. Release 架构门禁

自动扫描发布目录和程序集：

- Provider 默认为 `None`。
- 正式注册仅含 `WatchFolderCameraAdapter`。
- Fake Camera、Fake Monitor、测试数据生成器不在 Release。
- Sony/Canon/Nikon/Fujifilm DLL 不在 2.3.0 安装包。
- 无 localhost 监听和开发 Web Server。
- 输出类型为 WinExe，无控制台窗口。
- 不新增后台服务、计划任务、开机启动或退出后常驻。
- 版本在阶段 B 经授权后改为 2.3.0；阶段 A 保持 2.2.0。

## 13. 构建与运行矩阵

每阶段完成时：

1. Core 专项测试。
2. WPF 专项测试。
3. DPI 专项测试。
4. Debug 全量。
5. Release 全量。
6. Debug build 0 error。
7. Release build 0 error。
8. `git status` 仅有本阶段明确文件。

阶段 E 再执行独立桌面安装版验收，不在阶段 A–D 生成正式安装包。

## 14. 计划新增测试规模

建议最低新增：

- 阶段 B：Core/集成 45–60 项，WPF 8–12 项。
- 阶段 C：Core 20–30 项，WPF 25–35 项，DPI 8–12 项。
- 阶段 D：Core 35–50 项，WPF 20–30 项，DPI 10–15 项。
- 阶段 E：恢复/性能/发布门禁 25–40 项。

数量不是替代质量的目标；每个已知故障都必须有可复现断言。

## 15. 阶段 E 人工验收

- 两台实际显示器、不同 DPI 和 ICC。
- 长会话不少于 2 小时或 2000 张合成/测试照片。
- 外接盘断开、重新连接、睡眠/唤醒。
- 代理图/LUT 快速切换和内存回落。
- 客户屏隐私和操作路径。
- 不要求用户提供截图或切换其当前 Windows 缩放；验收在隔离机器/隔离桌面执行并记录环境。
