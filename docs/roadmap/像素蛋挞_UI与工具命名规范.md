# 像素蛋挞 UI 与工具命名规范

## 1. 产品语气

专业、克制、清晰、可靠。界面应像 Windows 原生摄影工作台，不像网页经营后台，也不使用夸张促销视觉。

## 2. 全局命名

| 入口名称 | 页面标题 | 内部能力 |
|---|---|---|
| 工作台 | 工作台 | 项目概览、任务中心、最近项目 |
| 本地分片 | 本地分片 | 编号输入、索引、文件匹配 |
| 归片工作区 | 归片工作区 | 来源、选片、匹配、交付 |
| 项目历史 | 项目历史 | 最近项目、状态、继续处理 |
| 整理图片 | 整理图片 | 智能分组、手动分组、复制整理、移动整理 |
| 拼图 | 拼图 | 模板、长图、参数、预览、导出 |
| 批量压缩 | 批量压缩 | 尺寸、质量、EXIF/ICC |
| 批量水印 | 批量水印 | 文字水印、图片水印 |
| 删废片 | 删废片 | 标记、预览、隔离/回收站 |
| FTP 工具 | FTP 工具 | 连接、上传、下载、队列 |
| 批量重命名 | 批量重命名 | 规则、预览、冲突 |
| 批量转档 | 批量转档 | 格式、色彩、尺寸 |
| 工具箱 | 工具箱 | 全部工具和快捷管理 |

禁止同一能力同时出现“照片整理/整理照片/分组整理工具/图片整理”。统一入口和页面均使用“整理图片”，内部模块可称“分组整理”。统一使用“拼图”，不混用“拼图模式/照片拼版/图片拼接”。

## 3. 状态词

- 未开始、扫描中、匹配中、复制中、等待确认、已暂停、取消中、已取消、失败、已完成；
- 文件结果：已找到、未找到、存在冲突、已手动选择、已复制、复制失败；
- 功能成熟度：可用、预览、开发中。不得用可点击主按钮伪装未实现功能。

## 4. 危险操作文案

按钮必须写明动作和对象：

- “复制到新目录”优于“开始”；
- “移动 328 个文件”优于“确认”；
- “移到回收站”优于“删除”；
- “覆盖现有文件”必须显示风险；
- 二次确认说明文件数、目标目录、是否可撤销。

## 5. 布局规范

- 标题栏和菜单栏保持 Windows 原生；
- 展开侧栏约 168–176 DIP，折叠 52–60 DIP；
- 主工作区自适应，不用小 MaxWidth 锁在左上角；
- 右侧任务中心约 300–328 DIP，窄窗口使用抽屉；
- 卡片圆角 6–8，不使用大面积网页式圆角；
- 基础间距 4/8/12/16/24/32；
- 常用控件高度 32–38；
- 空状态提供原因和下一步，不只显示空白。

## 6. 颜色与主题

- 所有颜色从语义 Token 获取；
- 深色不用纯黑和死白；
- 卡片主要靠明度层级，不给所有元素加边框；
- 主操作使用功能青绿或品牌暖金中的一种，不同时抢焦点；
- 危险色只用于风险和破坏性操作；
- 深浅主题结构一致；
- 高对比模式使用系统颜色。

## 7. 图标

- 项目内原创 PathGeometry/DrawingImage/SVG；
- 24×24 画布、线性、统一视觉线宽；
- 禁止 Emoji、字体 Glyph、来源不明 SVG 和参考软件资源；
- 图标必须有 ToolTip 和 `AutomationProperties.Name`；
- 折叠侧栏时居中且不裁切；
- 后续集中到 `Icons.Tools.xaml`，不继续堆入 MainWindow。

## 8. 输入控件

ComboBox、TextBox、PasswordBox、ListBox、CheckBox、RadioButton、ToggleButton、DatePicker、DataGrid、ContextMenu、TabControl、ScrollBar、ToolTip 和 Popup 必须使用统一主题资源。不得在深色页出现系统白底下拉框或输入框。

## 9. 快捷工具

- 主卡“开始本地分片”不参与排序；
- 快捷工具名称与工具箱一致；
- 固定状态使用小型图钉，不使用促销角标；
- 拖拽必须有浮动预览和插入指示；
- 支持键盘排序、移除和恢复默认；
- 窄窗口使用溢出入口，不压缩标题到多行；
- 工具箱始终可从顶部菜单或左侧访问。

## 10. 无障碍

- 所有图标按钮有可读名称；
- 焦点顺序符合视觉顺序；
- Tooltip 不作为唯一信息载体；
- 键盘可完成导航、工具打开、排序和危险确认；
- 100%、125%、150%、200% DPI 不裁字；
- 状态不能只靠颜色表达。

## 11. 页面拆分原则

每个主要工具使用独立 View/ViewModel。MainWindow 只保留 Shell、菜单、导航、任务中心容器、模态宿主和当前页面内容区。工具定义统一来自注册表，不在菜单、Popup、首页和完整工具箱中分别硬编码名称。
# 像素蛋挞 UI 与工具命名规范

## 2.0.3.1 工具注册与命名基线

- 所有工具入口、顶部工具菜单、工具箱弹层、完整工具箱、工作台快捷候选、ToolTip 和 AutomationProperties.Name 均读取 `ToolRegistry` 的 `ToolDefinition`。
- 工具箱是始终可达的独立入口，不占用普通快捷工具固定名额；普通快捷工具最多固定 3 项。
- 整理工具的入口和页面标题统一为“整理图片”，页面内部能力名称为“分组整理”。
- 拼图工具的入口和页面标题统一为“拼图”。
- 禁止显示“照片整理”“整理照片”“图片整理”“整理图片工具”“分组整理工具”“拼图模式”“图片拼接”“照片拼版”。
- 整理图片与拼图在 2.0.3.1 只提供页面框架、空状态和禁用的未完成功能，不执行文件操作或真实导出。
