# 像素蛋挞 2.0.3 详细实施与验收任务拆分

## 0. 现实基线与处理原则

当前源码、版本字段、安装脚本、安装包和最新回传报告均为 2.0.3。现有安装包：

`<WORKSPACE>\RAWSelectionAssistant\artifacts\installer\像素蛋挞_Setup_2.0.3_x64.exe`

SHA-256：`D6768A5DDC8A3CBCD5AA9C9FB21675006252A7FE480DA9BEF1A9AC60FD8F1AA9`

因此本文件不是授权重新开发或覆盖 2.0.3，而是：

1. 记录 2.0.3 已完成范围；
2. 对照新合并规范列出差异；
3. 给出冻结、补缺、测试和发布任务；
4. 在用户确认前不修改代码。

若需要关闭差异，不能覆盖现有同名安装包。建议由用户选择：

- 方案 A：发布独立维护版 2.0.3.1，关闭 2.0.3 验收差异后再进入 2.0.4；
- 方案 B：接受当前 2.0.3 为冻结基线，把非阻断差异纳入 2.0.4。

在用户选择前，2.0.4 处于阻断状态。
