# 像素蛋挞工作日历设计

## 1. 产品定位与版本

工作日历是摄影师本地拍摄排期与项目资料入口，不是 CRM、预约商城、在线收款平台、员工排班系统或影楼经营后台。

- `2.1.0`：只预留 SQLite 表接口、项目关系接口和 `NotificationCenter` 本地提醒接口。
- `2.2.0`：交付工作日历、拍摄排期、拍摄详情、项目文档、拍摄准备清单、冲突检查和近期提醒。
- 第一阶段完全本地，不实现 ICS、Google/Outlook 同步、多设备同步、共享排期、短信或微信通知。

## 2. 页面结构

一级导航名称为“工作日历”，默认进入月视图，并支持周视图、日视图、今日、上一月/下一月、日期跳转、状态筛选、项目类型筛选和关键词搜索。

月视图每个日期单元格显示当天拍摄数量，最多三条开始时间、项目简称和文字状态，超出显示“另有 N 项”。点击日期在右侧打开当天拍摄列表，点击排期打开详情。日历格默认不显示金额。

## 3. 拍摄详情

详情分为：

1. 基本信息：项目、客户显示名称、日期、起止时间、全天、地点、拍摄类型和状态；
2. 金额：总金额、定金、已收、待收；
3. 拍摄要求：多行说明和带优先级、排序、完成状态的清单；
4. 摄影策划与协议：关联本地文件；
5. 关联项目：进入归片工作区、项目历史、选片和交付状态；
6. 备注：仅本地保存。

状态为 `Tentative`、`Confirmed`、`Preparing`、`Shooting`、`Completed`、`Cancelled`、`Postponed`，对应待确定、已确认、准备中、拍摄中、已完成、已取消、已延期。

## 4. 数据模型

### ShootBooking

`Id`、可空 `ProjectId`、`Title`、`ClientDisplayName`、`StartDateTime`、`EndDateTime`、`IsAllDay`、`Status`、`Location`、`ShootingType`、`ShootingRequirements`、`PreparationNotes`、`TotalAmount`、`DepositAmount`、`PaidAmount`、`Currency`、可选 `ContactName`、可选 `ContactPhone`、`Notes`、`CreatedAt`、`UpdatedAt`、`IsArchived`。

### ShootRequirementItem

`Id`、`BookingId`、`Text`、`IsCompleted`、`Priority`、`SortOrder`。

### BookingDocument

`Id`、`BookingId`、`ProjectId`、`DocumentType`、`DisplayName`、`FilePath`、`FileExtension`、`FileSize`、`LastKnownModifiedAt`、`OptionalHash`、`AddedAt`、`Notes`、`IsMissing`。

### BookingReminder

`Id`、`BookingId`、`TriggerAt`、`IsEnabled`、`LastTriggeredAt`、`CreatedAt`。

SQLite 表名为 `ShootBookings`、`ShootRequirementItems`、`BookingDocuments`、`BookingReminders`。原图、协议和策划文件本体不得写入数据库。

## 5. 金额边界

待收尾款 = 拍摄总金额 - 已收金额。金额只用于本地记录，可由用户隐藏，不接支付、自动扣款、微信、支付宝、发票或收入大屏。

## 6. 文档关联

文档类别包括摄影策划、拍摄协议、模特授权书、报价单、场地资料、服装参考、灯光图和其他。支持 PDF、DOC/DOCX、PPT/PPTX、XLS/XLSX、TXT、JPG/JPEG、PNG。

支持添加、拖入、打开、打开所在文件夹、检查丢失、重新定位和移除关联。移除时明确提示：“仅从当前拍摄中移除，不会删除电脑中的原文件。”如复制到项目目录，必须使用安全 `FileOperationPlan`，默认不移动原文档。

## 7. 排期冲突

保存前检查时间重叠、结束早于开始、跨天、延期项目和同项目重复创建。冲突不直接阻止保存，列出冲突项目、时间、地点和重叠时长，用户可返回修改、仍然保存或标记可重叠。

## 8. 工作台与提醒

工作台增加“今日拍摄”和“未来 7 天”。今日区域显示下一场、今日数量、时间、项目、地点和准备完成情况；未来 7 天最多五条，进入日历查看全部。正式 Release 不注入演示数据。

本地提醒支持前一天、前 3 小时、前 1 小时和自定义时间，默认关闭。启用前必须由用户主动授权；提醒只显示项目、时间、地点、未完成准备项数量和打开详情，不接短信或微信。

## 9. 隐私与安全

默认不联网、不上传客户资料、协议、策划、金额或电话。日志不得记录客户完整姓名、电话、金额明细、协议内容或文档全文；诊断包默认脱敏。文档路径仅用于本地定位，文件丢失只标记 `IsMissing`，不得擅自删除或移动。

## 10. 验收边界

2.2.0 发布前必须通过视图切换、跨天与时区、冲突、金额隐藏、文档丢失/重定位、移除关联不删原文件、提醒授权、数据库迁移/备份/恢复和隐私脱敏测试。第一阶段之外的同步能力只保留未来评估项，不以 Mock 宣称完成。
