# RAW performance report

No legal vendor RAW fixtures are present in this repository. RAW decode timings for 24MP, 33MP, 45MP, 50MP, 60MP and 100MP+ are therefore **NOT MEASURED**. The current code has bounded cancellation and safe error recovery, but no performance claim is made from JPEG or synthetic RGB timings.

Required future measurements: embedded preview, full decode, first visual, peak RAM, cache hit and 16-bit TIFF export for each available fixture.
