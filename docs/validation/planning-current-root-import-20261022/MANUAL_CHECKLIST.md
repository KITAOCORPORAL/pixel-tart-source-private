# 人工待验 本轮未执行

运行统一启动器 → 退出教程 → 策划“导入项目包到当前应用” → 选samples内v1合成包 → 确认项目名称/ID、当前DB和stores位置及排除依赖 → 普通列表找到完整ID → 打开编辑保存 → 退出程序再同启动器打开 → 从普通列表打开并导出15区汇总。

重复导入同ID应拒绝；同名不同ID显示独立ID行。仅合成项目测试取消及恢复，未知/旧.import-stage保留报告，不手动清理个人项目。Word/WPS单独人工检查。

本轮GetCursorPos拒绝访问、capture timeout，真实鼠标和真实程序重启未执行。VM重建不等价实机重启。
