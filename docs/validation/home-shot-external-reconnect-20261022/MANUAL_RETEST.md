# 镜头独有外链手动复验（本轮未完成）

1. 用本轮实验目录 Launch-Diagnostic.ps1 启动；默认只写 ManualSyntheticData，不用默认个人数据根。
2. 退出教程 → 策划 → 导入项目包到当前应用 → final/samples/shot-only-v1.ptplan，核对隔离目的地。
3. 更多 → 缺失外链与手动重连。查找“合成特写镜头”、完整镜头 ID、原路径和缺失原因。
4. 逐项选“定位新文件（继续外链）”或“导入项目副本”，指定 final/samples/replacement-shot.png；核对 PNG、3821 bytes 和 SHA-256，确认。
5. 参考图区检查预览，点击保存，正常退出并确认进程消失。
6. 同启动器/同隔离根新进程启动，从普通列表重开，检查同一参考预览；镜头 ID、原路径、排序和正文不变。
7. 取消/错误/冲突仅使用合成项目；不删除真实数据、不改系统策略。

本轮在退出教程后，目标捕获显示其他前台应用且激活恢复一次无效，故没有继续点击。3 至 6 均待人工执行；VM 测试不代替实体闭环。无 Browser/CDP/localhost，无安装包。
