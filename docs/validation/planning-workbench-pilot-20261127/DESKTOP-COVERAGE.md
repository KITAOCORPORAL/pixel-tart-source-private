# 策划中心 · 桌面原有入口与工作台对照

核对基线：`feature/planning-workbench-pilot-20261127` 从 `a398d6c264b4a90b6e6ab01a0cf453f8e5945312` 接续。动作索引取 `docs/kitao-studio-product-master-spec-20261012@db1eff37393eae50816f932365e453937c05e8cb` 的 `docs/design/product-master/ACTION_INVENTORY.csv`（blob `cd0eff7022a39a10ec568c4477dbeee935091366`）。CSV 中 `PageID=P-Planning` 共 117 行，混有快捷键、自动登记的事件、内部命令和较旧文案；以当前 XAML、动态导航、渲染和操作接线认定桌面入口。下表是**桌面源码可追溯清单**，不是“每项均已点击”的回执。普通 Desktop 简单版逐页 15/15 的验证见[运行回执](DESKTOP-RUNTIME.md)；新工作台的实际覆盖请另看其运行回执；未提供运行证据的业务操作均不得升级为实测通过。

桌面显示「简单版」「进阶版」；这是同一项目的两种呈现方式，和试点的专业/团队成员权限不是同一开关。简单版是 4 组 15 区。进阶版切换会先保存，呈现同一策划的提案正文及镜头/资源结构引用，不会产生第二份项目，也不是叠加在 15 区上的另一套账户权限。

| 方案 · 项目概览 | 进度、时长、素材、资料；可编辑拍摄目标、视觉关键词、客户要求、必拍内容、注意事项、交付用途。镜头摘要可转镜头清单，道具及灯具摘要可转灯位图。 | 项目级字段、统计和两个直达目标；不能用通用富文本替代结构信息。 |

| 视觉 · 参考图 | 图卡显示缩略图、标题、可用性，必要时展开详情；双击/打开大图。筛选全部、主视觉、场景、姿势、造型、灯光、色彩、其他；添加本地图片时可选副本或外链；也可选素材库/灵感板/自由画布来源。 | 项目自有图须按 ID 取内容；外链和图像副本状态分开，保留说明与分类。 |
| 视觉 · 情绪板 | 展示同一参考库里加入情绪板的图，按组显示；可添加、移出、在自由画布中排布；已关联灵感板/自由画布和固定画布版本，打开、插入/更新画布版本，生成中可取消。 | 表达参考图关系和固定快照；不能把新建白板等同于已导入旧自由画布工程。 |
| 视觉 · 灯位图 | 可拖动的 10×10 m 示意图，0.5 m 吸附，Esc 取消拖动。资源表：名称、横向位置 0–1、纵向位置 0–1、方向角度、功率百分比、修饰器、归档；含灯光参考、既有画布快照。 | 图与灯具清单同一对象；有方向、功率、备注、关联镜头和快照，非单纯图片。 |
| 执行 · 服化道与道具 | 表：名称、分类、数量、准备状态、来源、归档；下方可显示造型参考图。 | 行型为道具；可知道准备情况并关联镜头。 |
| 执行 · 设备 | 表：名称、型号、数量、来源目录、归档。桌面明确为手工登记、工具箱设备目录尚未连接；来源目录列不意味着存在写回。 | 设备数据与工具箱目录的承诺分开。 |
| 执行 · 人员 | 表：名称、角色、联系方式、到场时间、归档。 | 项目人员和有登录权限的团队成员分开。 |
| 执行 · 场地 | 表：名称、地址、联系方式、可用时段、报备许可、归档。详情另有日期、时区、手动日落/潮汐、来源等；不同于调用天气服务。 | 场地清单和可编辑详情；保留手工资料标记。 |
| 执行 · 档期 | 显示关联日期和地点。「关联档期」弹窗为可关联档期列表，显示标题，支持选中、关联、取消；数据源为工作日历，不复制日历记录。 | 关系型档期；不可用一个手填日期暗示已接通全局日历。 |
| 执行 · 当天时间表 | 表：名称、日期、开始时间、结束时间、时区ID、地点、负责人、归档。 | 保留多个时间段及负责人，区别于单项档期。 |
| 执行 · 预算 | 表：名称、预算金额、币种、归档；「读取项目实际支出（只读）」另列日期、说明、金额、币种和支付状态。 | 预算编辑与实际支出只读分开，不能默认为记账写入口。 |
| 资料 · 文件 | 添加文件（副本/外链）；展示名称、状态、来源类型；「文件详情」展开原来源及副本相对路径/SHA；打开文件、打开所在位置、移除关联。外链可定位新文件或转成项目副本。 | 远端不能继承本机驱动器权限；只显示安全元数据和已授权副本。 |
| 资料 · 文档内容 | 有包装正文时显示保留排版的文档阅读视图；另有自定义正文输入与「保存」。 | 文档包、可编辑备注、协作评论分别归属，不虚报格式往返。 |

**项目级列表与检查器。** 「策划案」侧栏不是第 16 个分区。卡片逐行展示标题、短身份、日期/地点、状态与参考图数/镜头数；可搜索项目/人物/日期（过滤也匹配地点），按全部/进行中/草稿/已完成筛选，默认最近更新优先。点击项目切换。「新建策划案」填名称、可选关联已有项目、拍摄日期、地点；可导入项目包。较窄窗口通过「分区」「检查器」「策划案」抽屉进入。常驻检查器含完成度、拍摄信息（标题/地点/人员）、关联（档期/开始拍摄）、保存/重试；选中镜头时增加名称、场景、景别、机位/镜头、人物动作、道具、灯光、备注、预计分钟以及应用/取消。不要把另一个 `RenderShotDrawer` 中的“当前、已拍、跳过”机械标为当前 DataGrid 工具栏按钮。

**七类摄影资源表的通用操作。** 灯具、道具、设备、人员、场地、时间段和预算都用同一表框架：新增、撤销上次策划操作；选行打开检查器、双击或 Enter 编辑；检查器可编辑、复制、归档或恢复。编辑弹窗有名称、备注和类型专属字段、关联镜头多选，保存或取消；灯具另可选择已有画布快照。表头是上表的字段，详情字段不冒充列表列。

**图片上下文菜单。** 视条件出现「重新定位素材」；另有查看大图、打开来源、设为/取消策划封面、加入/移出情绪板、用于当前镜头、用于灯光、用于造型、参考分类、分组、上移、下移、明确关联到成片（无候选禁用）、发送到自由画布、用于参考仿色、从策划中移除（只移除引用）。可从灵感托盘预览并插入新正文图片；正文插图和项目参考图不是同一个 ID。

**进阶版与编辑器。** 正文编辑共用 `PlanningRichEditor`。进阶页为「摄影提案 · 文档工作区」，提供保存、撤销策划操作、刷新结构引用、导出/导回摄影 DOCX；正文之外可编辑结构镜头的名称/动作并应用，打开结构资源，移除结构块不删源数据。纸张编辑包括正文/标题层级、大纲、粗斜/下划线、段落对齐、列表、查找/替换、撤销/重做；可插表、编辑/合并拆分单元格、重复表头、增删行列、设列宽/边框，插图和画布快照，分页、方向、A4/Letter、页边距、页眉页脚/页码、分页预览。实际 ribbon 为「开始、插入、布局、文档」，工具在上下文和宽度下呈现。不能据此宣称多人可同时改写原生整篇富文本或通用 Word 完整兼容。

**输出和更多菜单。** 顶部「预览」与「导出」分别打开策划预览和 A4 图片式提案 PDF（300/216 DPI，文字不可选）。富文本编辑器另有正文 PDF、分页预览、打印/PDF、DOCX 导出/导入路径；摄影 DOCX 导回有差异核对；「更多 → 导出15区汇总 DOCX」为不回写资源的阅读快照。「导出策划项目包（含已验证自有副本）」是迁移包，另有导入当前应用、打开独立项目、导入独立目录、任务取消与中断恢复。其他更多项：外链检查/失配修复/手动重连、开始拍摄、查看关联档期、返回策划列表。没有实测的跨端 PDF、DOCX、项目包或账号功能均不能标为已支持。

**新增产品导航的归属。** 新工作台「模板、素材、最近」是跨项目组织入口提案，不是桌面 15 区中漏数的分区。旧桌面有某张参考图的素材来源、项目自有副本、按更新时间排序的策划案，但这些不能证明独立的「素材」或「最近」工作台已经存在。旧协作试点「策划总览/拍摄简报/镜头清单与分镜/参考图」也不等同于普通桌面简单版 15 区。本表不将新增入口的存在、能否写入、跨端同步或 UI 验收情况从名称推断出来。

### 公司工作台：15 项实际对照

在同一台 Windows 的隔离 QA 工作台，以浏览器点击左栏全部 15 项：[实际标题、表头与可见按钮](WEB-ROUTES.json)。这是已填入摄影样例的项目；只读复查前后 revision 都是 45。下表中“打开”只证明页面呈现。画布、镜头、素材及讨论真实写入的范围见[双客户端操作记录](BROWSER-REPORT.md)；不同分镜、冲突、撤权和恢复另见各项回执。旧桌面项目副本的[导入验证](BACKEND-NATIVE-PROJECTION.json)独立于该 UI 样例：首次将可读取的原生字段投影为工作台页，新页保存在工作台扩展。原稿保留，未实现把全部编辑逐项反写原生资源表。
