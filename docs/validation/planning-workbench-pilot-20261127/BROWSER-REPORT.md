# 工作台双客户端浏览器回执 · 2026-11-27

**最终包复核：** [13 项主链路、6 项草稿与排版、4 阶段衣领几何](final-browser/README.md)均通过；最终宽预览已完整容纳概览表。下面保留首次发布字节的证据。

在公司一台 Windows 上，两个独立的 Chromium 159 进程、两个持久配置目录、两个不同的成员身份完成了 [13 项连续断言](browser/BROWSER-E2E.json)。A 从回环地址进入，B 从同一物理机的有线 IPv4 HTTPS 地址进入；程序关闭两个客户端后用各自的配置重新打开，未发生页面脚本异常。此次使用全新的 QA 房间，端口 45753，并非交付给审稿人的地址。未测试第二台物理电脑、其浏览器证书信任或公司防火墙入站策略。

之后再用一次性浏览器只读打开全部 15 个基本分区，[实际表头、控件、项目未递增的 revision 与服务载荷摘要](WEB-ROUTES.json)可供对照。此版本在 1700px 宽视口上，交付预览对话框仅 630px，概览表内容宽 1076px、可见 528px、可以横向滚动；一屏不能对照完整概览表。该观察针对首次服务字节，后续版的视觉情况以新的回执为准。

[可复现脚本](../../../tools/PlanningReview/accept_workbench.py)拒绝旧试点端口、旧项目和已有输出/浏览器目录。脚本输入的 `--local`、`--lan` 都是服务根地址。首次运行使用本轮分支 `feature/planning-workbench-pilot-20261127` 从 `a398d6c264b4a90b6e6ab01a0cf453f8e5945312` 开发的实际 Release（并非该基线提交本身）；确切运行载荷以 `WEB-ROUTES.json` 中的 SHA-256 为准。10 张原始截图逐张核对并匹配本次结果中的 SHA；补拍的第 11 张仅含公开样例原图局部、测试批注与两位模拟成员名。未收录浏览器配置、身份码、邀请链接、数据库、原始素材或证书。
