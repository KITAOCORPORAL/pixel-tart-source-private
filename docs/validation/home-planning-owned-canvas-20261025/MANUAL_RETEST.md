# 简短人工复验（原生工具受阻，本轮未执行）

1. 解压诊断包，用Launch-Diagnostic.ps1启动，确认隔离根在包旁SyntheticUserData、标题“不能发行”；不要直接双击app EXE误用默认根。
2. 退出教程→策划→导入当前应用→samples/native-project-a-v1.ptplan→普通列表打开。检查JPEG方向正确、参考区和镜头缩略图、放大预览。更多→缺失外链→镜头A选replacement-shot.jpg并明确导入自有副本，核对835 bytes/hash。
3. 同样导入native-project-b-v1.ptplan（蓝底橙圆PNG）。快速A↔B切换至少5次，观察标题/参考/镜头图匹配，不出现旧图串入。
4. A编辑标题/正文并保存，正常完全退出，确认进程消失；同启动器新进程启动，普通列表重开A，导出15区汇总DOCX。
5. A参考图右键/菜单“发送到自由画布”，调整位置并保存。关闭重开画布；移除仅该合成项目的原外链、删除仅该合成预览缓存后再重开，应仍呈现自有副本。
6. 仅合成副本另作备份后，改变/移走其受管文件，再请求加载/重开画布：必须提示自有副本不可用，不能显示旧图。恢复备份。不要操作个人目录/真实项目。
7. 用Launch-Second-Isolated.ps1启动第二个隔离根。导入samples/jpeg-owned-v1.ptplan并查看JPEG副本；或用第一根导出的项目包测试。自由画布工作区不在ptplan内，另一根不能据此声称恢复画布。

本轮工具返回unsupported call，以上是人工清单，不是已通过记录。WPF/VM测试不是原生点击或进程重启。
