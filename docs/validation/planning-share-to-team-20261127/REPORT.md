# 光镜「共享到团队」第一阶段 · 公司候选验收

**候选主流程通过。** 在一台实体公司 Windows，A 从普通 EXE 发布已经保存的原生策划；B 用有独立署名的 Chrome 会话经局域网地址编辑。A 正常退出后重开原项目，只点一次「继续团队协作」，同一个工作台同时显示了 B 改过的通告和圈住衣领的署名批注。另一台实体电脑的完整访问、独立证书信任和局域网入站仍待实测。

**审阅入口：** 公司候选包双击 `Start-PlanningShare.cmd` → 普通 `KitaoPhotoSelector.exe` → **策划中心** → **秋冬服装型录**（主样例，排除副标题含「同名对照」的项目）→ 项目标题栏 **继续团队协作**。未发布的项目在同一位置是 **共享到团队**。成员从负责人工作台 **项目成员 → 填受邀成员署名 → 生成成员邀请 → 复制成员链接** 加入；也可在项目的局域网入口填写 **邀请码或个人迁移码**。测试地址和证书属于当前主机配置，地址随交付单独给出。公开的项目入口没有负责人权限，已消费的验收邀请不再使用。

| 关键步骤 | 实际结果 |
| --- | --- |
| 普通 EXE 保存、检查并发布 | A 打开原生保存的测试策划，在桌面改副标题后点「共享到团队」。提示「排版：两端对齐正文在线采用左对齐」。确认后进入已认证的负责人工作台，新副标题可读，桌面主操作切到「继续团队协作」。 |
| 成员加入与内容核对 | B 用一份独立 Chrome 配置及成员链接加入，成员和负责人身份不同。确认 15 个分区、格式化的「衣领织纹」、三行真实正文表、6 镜原顺序、第三镜衣领关联。3 张 JPEG 的内容摘要与项目副本相同；情绪板还读回固定 PNG。B 不读取 A 的 Windows 盘符。 |
| 成员写入 | B 从原第三镜的「打开现场参考」圈选衣领，保存署名「造型师 B · 验收」；把正文通告表一格 `10:00` 改为 `10:25`，并在「当天时间表」把原行改成「北窗衣领复核 · 10:25」。两个修改都从候选服务读回。 |
| A 正常重开与一次点击 | A 正常关闭普通桌面，重开原本地项目，身份和发布绑定保持。A 又改了一条本地副标题，桌面提示「本地有后续修改」。一次「继续团队协作」进入原线上项目，右侧讨论看到 B 的原文，时间表看到 `10:25`。本地副标题留在本机，未覆盖线上；线上通告也未回写本地文件。 |
| 负责人回复、处理、移动；成员重开 | 负责人在独立 Chrome 负责人会话定位衣领、回复并标为已解决，再用第 3 镜的「换序 / 更多」移到第 6 位。B 重开自己的浏览器会话，从讨论点「定位」，看到同一图片摘要、矩形和镜头身份，镜号为 `06`。 |
| 重复发布和中断 | 同一身份的并发发布、文件未齐、服务重启续传、旧清单拒绝、服务端已完成但响应被丢弃、再读回原房间：最终构建的服务协议验收 **8/8**。这是独立合成项目和真实 HTTPS；没有故意断开公司正式连接或在实体跨机链上测试双击。 |
| 候选服务暂断与桌面重试 | 只停独立候选服务。A 的原项目显示连接失败可重试，按键仍是「继续团队协作」，绑定摘要不变。服务用同一数据根和证书重启后，再点一次进入原房间，B 的通告、衣领批注和 A 的回复仍在。局域网成员网址也重新打开到邀请码页。 |
| 同名与本地保存失败 | 最终普通 EXE 实测：仅暂时锁住对照策划的文件，发布停在保存失败并保留原编辑位置与草稿，未开线上房间。解除占用后在同一窗口重试成功，为同名不同身份策划创建另一间工作台；原项目绑定保持。[桌面回执](desktop.md) |
| 从空白创作后首次共享 | 独立第三份合成策划从普通桌面新建，用原生编辑器输入并加粗正文、插入表格、新建镜头、从系统文件选择器导入一张同许可 JPEG 为项目自有副本，并通过「用于当前镜头」关联。正常共享直接打开负责人工作台，无预检弹窗；线上确实看到正文、表格单元格和已关联镜头的「打开现场参考」。 |
| 原生功能回归 | 另用隔离根执行现有 `PlanningFoundationWpfTests`，8 项通过、0 失败、0 跳过，覆盖保存与恢复、分镜表、资源和兼容性。这是独立 WPF 测试，普通 EXE 证据来自上表。 |

主链以已保存的样例开始：格式简报、原生通告表、三张授权参考、固定 PNG 和六镜来自同一原生数据仓；A 在普通编辑器改写副标题并调用保存与发布。另用独立策划验证了从空白手工创作，其中一张图和一个镜头用原生 UI 新建。测试机是 Windows 10 Pro x64（19045），使用公司有线网络；A 走普通 WPF 与 WebView2，B 走 Chrome 158 的独立浏览器配置并从局域网监听口读取，浏览器只信任这一张测试证书的公钥。两端同处一台实体机。

已发布版本以线上为准。首次检查阻断缺失的主参考、活动分镜图及无法核对的项目自有副本；页面明细指出受影响的分区和图片。阶段一的保真边界：附件仅带名称，外链和未授权素材原件不上传；旧情绪板以已保存的固定快照保留，旧可编辑画布、完整排版与桌面专用字段未全量映射；每镜网页只操作一个主参考。历史讨论从受支持扩展迁移，旧内容不会覆盖当前桌面正文；无法确认原位置的批注保留为历史。线上改动写回原生编辑器留待第二阶段。
