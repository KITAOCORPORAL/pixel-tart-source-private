# 家庭材料缺项

原0806D680…的7752×5184RGB48 payload在家庭工作区与既有Guangjing交付目录未找到。旧公司e818现场的物理文件与22项失败原件不在本机，不能声称重新哈希原件；14ed39f1里的原读回记录完整保留。

公司DSCF0347肩部/暖纹理/发丝固定ROI、Canon夕阳固定ROI、V1冻结f32、BasicTone与曲线公平面板及原E盘只读页资产缺失。家中Sony已授权原显影TIFF和源裁片存在，但不是公司公平组；本轮只读页保留缺图标记。

真实材料仍缺：已确认哑光白织物、有光泽白织物、中性及彩色金属反射、真实面部亮部、可追溯日光/暖灯/混合光、额外合法输入ICC。Canon中间调锚点不足不临时改ROI。不同XTrans相机泛化不在本轮。缺图不能作为新解码RAW的理由。

本轮40MP源明确为原有合成显影TIFF；另用原有Sony TIFF冻结RGB48。输入SHA、方向和ICC见INPUTS。两者均非传感器线性数据，均非公司0806payload。
