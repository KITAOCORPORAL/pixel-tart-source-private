## 最小补丁

- 分离高精度处理结果与显示适配，预览API仍生成原显示adapter，导出不生成无用途的整幅RGB24。
- 中性输入按只读borrow处理，Dispose不释放编辑/撤销/预览共享的master；非中性旧路径拥有自己的结果。
- 支持白平衡、BasicTone、色彩平衡、色阶、曲线、肤色及Preset的无蒙版点栈，按16行调用原函数、原顺序，直接交给现有AtomicTiffWriter写行。单次导出复用自己的小条带backing，不分配完整输出float，不清全局cache。
- Details/空间、Develop、Film、ReferenceMatch、ColorRange、图结构、复杂混合保留原高精度处理。没有改色彩公式、量化、ICC、旧recipe或发行解码器；未保证这些fallback在40MP全部过资源门。

## 输入与逐样本结果

原公司 `0806D680…` payload不在家庭机器。本轮冻结此前已有7752×5184合成RGB16（非真实RAW）与已授权Sony TIFF：存储7028×4688、方向8，经过既有生产方向规范化后4688×7028/方向1。输入、payload、ICC身份及差异见INPUTS.json。没有打开原相机RAW；IRawDecoder是只读RGB48替身，伪.raf仅含说明文字；隔离stage只复制托管文件、不含RAW native DLL。导出侧车的SourceHash属于说明marker，不冒称公司原RAW身份。

修改前完整Core链在独立进程生成40MP中性/两点节点oracle，再与修改后的真实VM导出和同进程重开再次导出比较。每次比较 **120,559,104个16位通道样本，差异0**。两份实际TIFF与原Core oracle连文件SHA也相同；RGB16、尺寸、方向1、ICC3144字节及其SHA完全一致。Sony首份输出与方向规范后的原Core oracle比 **98,841,792个样本，差异0**，但第二次导出未完成，不能提升为Sony完整周期通过。

## 合入结论与最小下一步

**暂不满足“整产品内存问题已解决”的合入结论。** 该隔离补丁具备已测中性/点节点导出的严格像素与所有权证据，40MP限定周期过门，但余量较小；Sony同进程重开仍有STOP，处理后点节点100%预览也未覆盖。正式合入由产品线选择和审核，本轮不覆盖共享文件。
