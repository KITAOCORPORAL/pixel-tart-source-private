# 最短人工复验（待用户真实反馈，不预填PASS）

1. 用本批完整诊断包启动器进入独立UserData，新建“合成摄影提案”；不要打开日常数据库。
2. 修改概览和正文，建一个镜头；参考图加入情绪板，灯位/服化道/设备/人员/时间表选同一镜头；关联一个档期，记下标题与ID。
3. 七类资源各改名一次；预算只读查看合成支出；文字插一张合成图、一张基础表和页眉页脚。保存、退出再打开核对。
4. 复制/归档一个道具并撤销重做；导出DOCX/PDF，检查声明内容。导出的PDF是图片式，不要求可选中文字；资源表不全进入导出是现有范围限制。
5. 搬迁只操作这份合成项目副本，保留planning JSON/images/恢复草稿以及shot/DB依赖；原参考图与普通附件绝对外链需要仍可访问，不能当自动便携打包。

每步反馈“动作/实际结果/截图文件名”；未反馈前所有桌面列NOT_RUN。不要分享私人照片、RAW、数据库或凭据。诊断版、不能发行。
