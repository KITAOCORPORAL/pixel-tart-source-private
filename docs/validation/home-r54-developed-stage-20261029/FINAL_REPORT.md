## 实际实现
- 已显影节点是只读类型化 `DevelopedStageProjection`：从当前变体ID和已提交的 InstantFilm.V3 / InstantInput / LightPrint 冻结定义构造，保留算法/配方版本、来源变体、帧ID和SHA256。窗口调色不算冻结响应身份。草稿不生成。旧定义不改写，无持久化新阶段字段；每次读取从文档重建，原始定义已有版本校验。
- 图上显示真实已显影结果缩略、系统锁定、选中可查看完整冻结JSON和身份。阶段不属于普通 `AdjustmentStack`：不接受普通接线/移动/删除/复制，执行仍由 `InstantV3ProductPipeline.Open` → `CandidateRenderSession` 消费一次。该阶段卡目前独立显示在图右侧，**不以装饰线声称它已属于普通图路由**，与草图连线仍有视觉差异。
- 测试覆盖显影前/草稿无阶段、显影后身份/锁定、只读配方、窗口调整身份不变、重拍新变体和旧定义保留、独立进程重开同配方和像素。窗口边框逐像素不变及两种风格的PNG16/TIFF16/JPEG输出沿已有生产回归验证。此次未跑旧版本二进制对同一固定输入的全像素A/B；源码处理链未改且测试覆盖并不能代替该比较。
- 四色轮2×2、色相/强度数值和复位复用原参数；112 DIP是**单轮控件高度**，不含标题和数值。1366截图查看了两行和数值；独立测量完整行高/1920色轮布局及物理手势未完成。
- 专业示波在照片右侧，折叠22 DIP，展开波形/RGB/矢量；用户选择存于可空布局字段，旧项目缺字段默认收起。源分析最长边256、取消与代际隔离、工作串行衔接；隐藏/卸载清理。静态截图及自动测试不能代替实际多变体/设备DPI验收。
