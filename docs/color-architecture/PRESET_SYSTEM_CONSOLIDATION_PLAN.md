# Preset system consolidation plan

Adobe XMP, Cube LUT, Capture One and Pixel Tart presets should share browser/search/favorite/recent/preview/strength/apply/cancellation contracts while retaining provider-specific parsers and processors.

Current evidence: Adobe XMP and Cube LUT are executable and tested; Capture One is an unverified adapter boundary. This phase does not merge provider formats or introduce a second preview engine.
