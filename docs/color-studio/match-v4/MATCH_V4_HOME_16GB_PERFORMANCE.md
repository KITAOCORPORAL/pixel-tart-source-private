# Match V4 Home 16GB Performance

The RTX 5060 Ti reports 16,829,644,800 dedicated bytes and uses the ULTRA tier, 1024 tile plan, and four parallel tile budget. The backend keeps full-resolution source and output in host memory and allocates one tile input/output pair in VRAM.

This phase records correctness and does not claim a completed 4/8/16GB benchmark. The descriptor contract covers LOW/STANDARD/ULTRA tile and sample policies; 4GB and 8GB deterministic image runs, peak VRAM telemetry, and controlled OOM retry evidence remain open. 16GB improves tile capacity and throughput policy; it does not change color quality or parity thresholds.
