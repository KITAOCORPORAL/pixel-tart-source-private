# Premium Visual Principles

Studio v2 is a prototype evolution of the existing design system, not a second theme. Its order is image, space, information, control. Idle controls recede; hover reveals; selection and primary actions receive the restrained accent.

The three prototype routes are Workbench, Asset Library, and Reference Color. They preserve Windows keyboard, resize, snap, file-system, accessibility, and high-DPI behavior while removing default-WPF visual weight.

Review gates are visual hierarchy, canvas dominance, density, spacing, color restraint, typography, control precision, border noise, brand identity, and Windows legacy feel. Any default chrome, blue focus, hard boxed form, thick menu strip, or system-looking scrollbar is a blocker for the prototype.
