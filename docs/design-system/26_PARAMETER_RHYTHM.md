# Parameter Rhythm

Parameter groups follow an optical rhythm: label to control 8–10 DIP, control to helper 8–10 DIP, parameter to parameter 20–24 DIP, group to group 30–36 DIP, and section to section 36–44 DIP.

Labels and values share a row; values use the lighter accent. Controls occupy the following row. Helper text remains separate. Parameters are not cards, and neighboring groups use spacing or a soft divider rather than repeated borders.
