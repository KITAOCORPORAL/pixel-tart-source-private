# Dark Tonal Hierarchy

Studio v2 dark surfaces are neutral with a slight violet warmth: app `#0E0D12`, primary surface `#141318`, secondary `#1A181F`, tertiary `#211F27`, and elevated `#2B2832`. Dividers are white at low alpha rather than opaque gray rules.

Text is off-white: primary `#ECEAED`, secondary `#AAA6AF`, tertiary `#77727E`. Muted Violet v2 uses `#9471C1`, hover `#A07DCC`, pressed `#8462AF`, and value text `#C4A7E3`. Accent is reserved for selected, value, active track, toggle on, focus, primary, and progress states.
