# Premium Shell

The Studio v2 shell uses a 52 DIP custom command bar and 28 DIP status bar. Product identity, current route, compact menus, contextual actions, and Windows controls share one calm horizontal plane. Menus remain keyboard-accessible and retain their commands.

Expanded navigation is 178 DIP and collapsed navigation is 56 DIP. It uses a shared shell surface, no hard outer border, a soft selected wash, and a 2 DIP accent marker. Route content owns the visual emphasis.

The shell remains a real resizable Windows window. It supports caption drag, double-click maximize, snap, system menu, resize borders, minimize, maximize/restore, close, and Alt+F4.
