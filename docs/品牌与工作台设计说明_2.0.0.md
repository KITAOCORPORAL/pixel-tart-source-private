# 像素蛋挞 2.0.0 品牌与工作台设计说明

## 产品定位

像素蛋挞是面向摄影师的 Windows 本地照片工具平台。2.0.0 以“本地分片”为首要入口，同时保留成熟的归片工作区，并为批量压缩、批量水印、删废片、FTP、照片整理、批量重命名和批量转档建立统一工具入口。

产品不启动浏览器，不依赖本地网页服务，不在首页加入预约、收入、橱窗、客资、团队或 AI 挑图等经营型模块。

## 品牌图形

Logo 由四部分构成：石墨色圆角底承载 Windows 桌面工具感；暖金蛋挞外壳表达产品名称；奶油色照片负片表达摄影场景；右上青绿色像素块表达数字文件处理。图形使用原创几何结构，不依赖字体图标。

资源包括主 SVG、浅色 SVG、小尺寸 SVG、1024 PNG、9 种小尺寸 PNG 与 9 帧 ICO。导航与工具图标统一使用 PathGeometry，确保高 DPI 和安装包环境中不出现字形缺失。

## 工作台结构

- 主区：开始本地分片、真实项目统计、最近项目。
- 右区：8 个本地工具快捷入口。
- 侧栏：工作台、工具箱、应用三个分组。
- 顶部：保留文件、项目、编辑、视图、工具、帮助六组原生菜单和 Alt 访问键。
- 本地分片：快速输入、格式与导出选择，并可进入原有高级归片工作区。

## 视觉原则

暖金色作为品牌主色，青绿色作为工具提示色，石墨色提供专业稳定感。卡片、留白和层级参考桌面生产力工具的一般布局规律，但没有复制任何指定产品的标识、文案或独特视觉资产。
