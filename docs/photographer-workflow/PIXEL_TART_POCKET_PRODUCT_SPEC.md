# Pixel Tart Pocket Product Spec

Pocket V1 是摄影师移动工作台：Today、This Week、Calendar、Quick Booking、Client、Project、Location、Price、Deposit、Balance、Payment State、Team、Notes、Checklist、Notifications、Offline、PC↔Mobile Sync。优先 PWA/H5 与微信小程序，Native iOS/Android 后置。

本轮仅建立 provider-neutral 数据语义；不实现移动 RAW、Match V4、3D 或完整 Asset Library。
