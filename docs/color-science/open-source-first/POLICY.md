# Color Studio：开源先行开发门禁

生效：2026-10-15。用户直接指令，适用于当前公司A/B集成及后续Color Studio像素节点开发。此文件不是既有算法批准，也不授权复制外部代码。

## 修改像素前必须完成

每个会改变像素结果的节点（包括解码、白平衡、曝光、肩部、高光、局部滤波、色域映射、ICC、显示和导出）必须先提交：

1. 输入/输出色彩空间与原色、白点、传递函数、数值范围、位深/精度、黑白位、WB是否已应用、裁切行为、alpha/方向和处理链位置。
2. 至少两个相关成熟开源实现：固定版本及完整commit、具体文件/函数、参数/默认项、测试入口、许可证及发布义务。仅列项目名不满足门禁。
3. 说明复用、适配还是独立实现，以及为什么；不同项目的公式不能忽略域/顺序拼接。
4. 可复现独立数值比较：中性灰阶、饱和色、高光、负值/>1、16位/浮点、不同ICC、权限/哈希明确的真实RAW。保留输入hash、完整配置、参考版本、逐阶段差异、误差指标、耗时、内存与失败。
5. 不一致先排查域、白点、OETF/EOTF、WB、曝光和矩阵/局部节点顺序，再决定算法改动。
6. 历史PV4/PV5/PV6 golden必须保持。任何新行为使用独立明确版本，不让旧recipe/项目暗迁；验证同一冻结定义在预览、保存重开和导出的结果一致。

## 问题与首选对照

- RAW/相机WB：LibRaw + RawTherapee。
- 曝光/高光/色域映射/局部节点：darktable + RawTherapee。
- ICC：优先评估Little CMS，同时核对RawTherapee的ICC集成与调用意图；合成ICC parser不能代替通用ICC引擎。
- 显示/未来ACES：评估OpenColorIO及与目标问题相关的第二独立实现；不把OCIO的矩阵节点等同完整相机表征。

版本索引见REFERENCE_INDEX.json，初始阅读与测试计划见INITIAL_REFERENCE_REVIEW.md。它们当前只是资料清点，不是数值对照已通过。

## 许可证

先核验文件级及依赖许可证、版本、来源和发布组件，再决定引入。GPL参考只做研究/行为对照；未经明确许可证兼容评估不得复制、翻译、粘贴或改名移入产品。候选二进制/研究源码只留本地隔离资料，不进Git或发布包。已有LibRaw依赖与新候选分别登记，旧依赖批准不自动扩展到新版本。MIT/BSD等也不能省略归属、许可证文本或随包义务。本文不是法律兼容性审查结论。

## 当前夜间B的准入状态

- PV7后端原型：默认关闭。虽然已有合成数学测试，缺两个成熟实现的可复现运行对照、真实输入profile通路与实际预览/导出编码验证，状态OPEN_RESEARCH_ONLY。
- SyntheticIccMatrixReader：只接受声明合成子集；没有完成Little CMS的数值对照，不升级为真实照片通用ICC加载器。
- LinearInputProbe：现有版本只观测显式传入样本。真实RAW新增只读观测不得用最终RGB16反推sensor值；未取得阶段写UNAVAILABLE。
- 当前集成/SQL诊断/身份校验不改变色彩数学；生产空间节点只有同尺寸/同输入前后证据及本门禁满足后才可修改。

## 色卡与科学结论

现在不要求购买色卡。先使用可追溯公开数据、合成真值、已授权现有照片与独立实现交叉验证。数学/一致性通过不证明A7M4在某光源下绝对色准，也不证明宝丽来相纸精确复刻。
仅明确进入特定相机实测配置或胶片/扫描闭环，且公开数据不足以回答具体误差时，才提出器材方案：先写明待验证问题、误差目标、参考条件、光源/拍摄/扫描/测量方法和不确定度，再请用户准备。没有实测参考时CalibrationEligible=false。

## 提交检查

每个节点提交附NODE_COMPARISON_TEMPLATE填写件和数值测试。缺许可证、第二实现、参考执行或一致性验证时，不以“看起来更好”接入生产；文档如实OPEN/NOT_RUN。
