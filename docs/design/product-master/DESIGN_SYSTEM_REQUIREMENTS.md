# Kitao Studio 光镜 · 设计系统约束

## DS-00 权威与继承

本文件是新设计规范，不是产品代码修改。继承现有 WPF Resources/DesignSystem；优先引用既有 token，新增别名须经过设计系统决策，不逐页面硬编码。Branding.ProductName 已为“Kitao Studio 光镜”，MainWindow 等仍有历史像素蛋挞文案，记为迁移缺口，不能假称全面改名完成。

照片预览周围必须中性、暗色、低反射感；品牌铜色/矿物色只用于操作焦点与小面积强调，不铺满预览周边。参考专业摄影软件的工作组织、素材管理软件的浏览效率，不复制品牌外观，不新增第二套引擎/参数模型。

## DS-01 Token 要求

以下目标值是设计建议，不声称当前资源全部采用这些值。现有尺寸来源 DesignTokens.xaml；现有色值以 Colors.Dark.xaml / Theme.Dark.xaml / Studio.* 为事实。

|语义token|目标/继承约束|用途|
|---|---|---|
|surface.preview|建议 #202020，中性等RGB|照片周围；禁止彩色渐变|
|surface.app|建议 #181A1B|应用背景|
|surface.panel|建议 #232526|工具面板|
|surface.raised|建议 #2B2D2E|浮层、菜单|
|text.primary|建议 #E7E6E2 暖银|正文；实际组合须测对比|
|text.secondary|建议 #B8B9B6|次要说明|
|text.muted|建议 #8C908F|非关键说明，不作唯一状态|
|accent.action|建议 #B58464 氧化铜|主按钮/焦点，不用于照片本身|
|border.default|建议 #444849|分隔与控件边界|
|state.error|沿用错误语义资源|必须同时有图标和具体文字|
|state.warning|沿用警示资源|缺失、冲突、未同步|
|state.success|沿用成功资源|仅已持久化成功，不用在处理中|
|focus.ring|高对比外环 + 形状边界|不可只改变背景色|

暗/亮/高对比主题必须同一语义token集合。自动颜色分析与色值取样不受UI主题影响。关键文字对比以实测为准，目标普通文字4.5:1、大字及关键图形3:1；本任务不构成无障碍认证。

## DS-02 字体、间距、尺寸

现有 DesignTokens：页面标题22、分区16、正文13、次要12、最小caption11；控件38、紧凑32、行42；边栏172/60；抽屉360/420/480；页面内边距24；间距4/8/12/16/24/32/48。保留这些语义尺度，中文优先系统可读字体（建议 Microsoft YaHei UI + Segoe UI fallback），数值对齐采用等宽数字。不能以11px承载关键错误信息。

图标16/20/24分工；同一组保持线宽和视框。纯图标按钮必须有中文可访问名称、悬停提示、键盘焦点。按钮等级：每工作区至多一个主要强调动作；次按钮用于补充操作；幽灵按钮用于工具；危险操作单独警示。切换控件不能误用普通Button样式导致ToggleButton运行失败，组件目标类型须验证。

## DS-03 输入与状态

- 数值框：单位、范围、默认值、当前值可见；Enter提交、Esc回到已提交值；失焦提交必须与预览/保存事务一致。无效值保留并解释，不静默截断；恢复默认属于可撤销编辑。
- 滑条：拖动预览、释放提交；同时有精确输入；键盘方向键微调，Shift大步进需明确声明。
- 下拉：当前值可读，未知/旧版本值不悄悄改成第一个选项；选项影响其他字段时提示。
- 多选：全选范围必须说明是当前筛选结果还是全部库；批量修改前显示数量和混合值。
- 禁用：tooltip可在禁用时显示；说明“请先选择照片”“正在显影，完成后可编辑”“当前提供方未配置”，不用“CanExecute=false”。
- 保存：编辑中→保存中→已保存；失败保留草稿并持续显示，不用一闪而过toast掩盖。
- 错误：用户能做什么先于异常名；高级详情可复制技术信息，默认隐去本地隐私路径与凭据。

## DS-04 面板、菜单、弹窗与通知

面板折叠记忆用户状态但不挤掉主预览；折叠后保留标题/变更标记。右键菜单遵循当前选择；在未选项目右键先明确选择策略，不悄悄对旧选择操作。菜单项顺序“常用→组织→关联→导出→危险”；不可用项说明原因。

弹窗：明确标题、作用对象、主次按钮与返回路径；打开焦点进入，Tab循环，关闭返回触发点。破坏性默认焦点在取消或安全动作。多层弹窗避免；新弹窗不得遮盖已有未保存问题。含损失/冲突的弹窗不能只给确定。

通知分即时toast、持久错误条、通知列表、任务详情。进度区分排队/正在处理/正在保存/完成/部分完成/失败/已取消；未知总量不显示虚假百分比。取消不等于撤销已完成文件；恢复必须说明继续哪个任务及哪些输出。

## DS-05 键盘与焦点

全局实际声明：Ctrl+N新建项目，Ctrl+S保存项目，Ctrl+B侧栏，Ctrl+Shift+F反馈，F1帮助，Alt+Enter所选详情（MainWindow.xaml InputBindings）。模块内快捷键详见Action清单，不从MenuItem.InputGestureText单独推断绑定存在。

冲突优先级：模态弹窗→输入控件/富文本→当前编辑器→工作区→全局。富文本Ctrl+B为加粗，不得同时折叠侧栏；Ctrl+S在文档/画布/调色工作区应保存当前对象，不误存别的项目；这属于必须验证的路由设计要求，不假称已修复。Esc先取消当前操作/关闭浮层，再退出工具；即时胶片中央显影不可被Esc跳过到完成，生命周期退出可中止并回到上一有效版本。

Tab顺序：页头→工具栏→组织区→内容→检查器→底栏；用户可通过明确快捷入口直接进内容。方向键用于当前集合，Home/End及多选范围保持一致。拖拽必须有键盘替代（移动、排列、添加引用）；不能只有鼠标。

## DS-RESP 窄窗口与DPI

事实：MainWindow常规最小1180×720，素材库模式可降至720×400（MainWindow.xaml.cs）。目标：保留中央内容，先折叠左右面板再收进“更多”；不能把参数压成无法阅读的一列或隐藏主操作。宽度按DIP计算；720、960、1180、1600宽度做状态稿。1280×720物理屏幕在高DPI可能不满足旧最小DIP，须明确缺口，不假称适配。

100/125/150/200%逐项验证：文本不截断、图标不模糊、弹窗不超工作区、菜单不越界、命中区域正确、原像素视图的1:1定义与DPI清楚。照片像素不被窗口DPI误当导出尺寸。移动端建议触控目标至少44×44逻辑单位；不照搬桌面密集工具栏。

## DS-06 文案层与工程层

普通文案：“正在生成”“基于当前编辑”“原始照片”“有另一端的新修改”“部分照片未导出”“保留我的副本”。工程详情：ProcessingVersion、CAS、hash、revision、pipeline、任务ID、错误堆栈。工程字段可在高级详情复制，但不能充斥默认工具区。枚举 CurrentEdits/Original/CropFill/FitEntire 等必须映射为本地化文案，不把枚举字符串直接作为最终产品文案。
