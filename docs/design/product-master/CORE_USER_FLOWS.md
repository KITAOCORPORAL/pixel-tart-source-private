# 核心用户任务路径

所有流程的起点/动作/状态绑定到 CSV 中 FeatureID→PageID→ActionID。以下是行为规格，不是本任务桌面操作记录。

## FLOW-01 首次启动和恢复

P-StudioStartupWindow / P-Onboarding → 设置/数据库与服务初始化 → 主题 → 工作区 → 会话恢复 → P-Workbench或有效的上次主页面。启动状态使用普通中文；失败给“重试/打开诊断/退出”目标，不展示空白主窗。教程使用示例项目，不能混入真实客户资料。恢复失败保留草稿与路径，不自动清空；旧名称/旧schema迁移必须可追溯。源：App.xaml.cs、StudioStartupWindow.Report/Complete、MainViewModel.InitializeAsync、SettingsService。

## FLOW-02 项目与归片

新建项目 → 输入客户/拍摄资料 → 添加原片来源 → 导入JPG/粘贴编号/TXT → 解析 → 预览匹配 → 处理一对多歧义和缺失 → 选择JPG+RAW或仅JPG → 确认复制目标与数量 → 执行 → 逐项结果/报告 → 项目历史。任何步骤取消不删除源。缺失不能默认选择同名错误文件；候选必须可预览。批处理部分完成不重复制成功项。项目删除产品策略固定“归档/恢复”，没有批准永久删除。源：MainViewModel、SelectionTools、CandidateSelectionWindow。

## FLOW-03 素材库到策划/画布

导入 → 元数据/缩略图加载 → 去重提示 → 搜索/筛选 → 多选 → 添加标签/注释 → 发送到当前项目策划或画布。传LibraryId+AssetId；缺失源可重新定位；切换库不能重用旧库AssetId。引用与复制说明明确。移出画布/策划引用不删除库资产。原文件删除与回收站清理如当前功能存在必须独立确认，不扩大成项目永久删除。源：AssetLibraryPage、AssetLibraryViewModel.Identity、Canvas、ProjectVisuals。

## FLOW-04 策划文档编辑与安全输出

文档列表 → 创建/打开 → 基础富文本/大纲/分页/图片/表格 → 保存中/已保存 → 预览 → 打印/PDF或DOCX。
DOCX导入：选文件 → 支持内容分析 → 损失清单 → 取消或明确接受 → 单个可撤销事务 → 保存。导出遇未支持分节、复杂表格等应拒绝而非静默删内容。导入不修改原DOCX。PDF印刷路径与应用导出路径分别验证字体、分页与色彩，不把扩展名正确当视觉保真。
当前是原生WPF基础编辑器，不能称完整WPS Word。完整文字处理目标见F-WORD-*。源：PlanningRichEditor、PlanningDocxAdapter、PlanningDocumentLayout、RichDocumentHistory。

## FLOW-05 自由画布

素材库/灵感板选择 → 打开/新建画布 → 拖入引用/文字/连接 → 选择/移动/缩放 → 对齐/排列/分组/图层 → 关联项目 → 自动保存/显式离开保护 → 保存到灵感板或策划快照。
离开有待保存：保存并离开 / 放弃本次未保存 / 取消；保存失败停留原画布。快照更新是显式版本替换，不能把后续画布变化偷偷覆盖已发布策划。文档对象和通用导出若未证实入口仍规划/部分实现。源：FreeCanvasView.PrepareDocumentChangeAsync、CanvasEditor、PlanningCanvasSnapshot。

## FLOW-06 Color Studio 非破坏调色

选择RAW/JPEG → 识别现有处理链 → 明确创建/打开编辑版本 → 白平衡/曝光/曲线/颜色与局部范围内工具 → 对比/直方图/取样 → 撤销重做 → 保存版本 → 导出配方 → 验证结果。
专业RAW版本与旧RAW兼容链分开；JPEG固有8位信息不会因为RGB48容器变成真实高位源。局部效果不能被无边界全图操作冒充；专业HDR与完整ICC是单列目标。打开失败提供重试载入；导出失败按失败项恢复。并发版本冲突不能直接覆盖；选择加载远端、保存副本或取消。源：ReferenceColorWorkspaceViewModel.*、ProfessionalRawPipeline、StudioVersionConflict、ExportRecovery。

## FLOW-07 即时胶片（硬约束）

选照片和输入方式“基于当前编辑/原始照片” → 相机选择 → 相纸选择 → 裁切/适配 → 边框 → 基础色彩强度 → 独立缺陷/温度 → 骰子开关与严格三档 → 生成。
1. 相机与相纸相互独立，选相机不能暗换相纸或预设。
2. 先冻结输入配方并计算最终像素，不把预览位图当导出源。
3. 动画开启：相机出现→纸完整吐出→相机离场→中央显影。
4. 动画关闭：只省去相机/吐纸，仍中央显影。
5. 中央两种模式均3–5秒、默认4秒、不可跳过；当前时间线常量4秒，不虚构已有用户可调时长控件。
6. 重新掷骰仅在骰子启用且不忙时可用；三档为“稳定出片/轻微偶然/实验胶片”，不得新增连续随机强度替代。
7. 基础色彩强度为0不等于全部缺陷关闭；“关闭图像效果”与纸框独立。完全原图几何需明确LegacyFree/不加框条件，不把裁切后图叫逐像素全图一致。
8. 退出/失败回滚到上一有效结果，不提交半张显影图。生命周期取消不是“跳过并完成”。
9. 保存版本与输出绑定相纸、裁切、随机快照和输入版本；再次打开不重新抽随机数。
第九批旧RAW CurrentEdits曾拒绝，用户可显式选Original；第十批添加LegacyRawInstantInput适配，已推送也不等于已集成。源：InstantDevelopmentTimeline、ReferenceColorWorkspaceViewModel.InstantFilm、InstantInputRecipe、LegacyRawInstantInput。

## FLOW-08 联机接收与标注

选看守文件夹/项目输出/备份 → 预览现有文件数量 → 开始接收 → 等文件稳定 → 配对RAW/JPG → 预览/原像素/比较 → 摄影师评分标签备注 → 入库交接 → 停止/断连恢复。
当前生产接入是看守文件夹，不假称USB相机快门、ISO/光圈控制已可用。接收失败区分文件未稳定、复制失败、库离线、标注冲突。断连保留接收记录，恢复扫描去重。客户监看不暴露摄影师内部诊断。源：WatchFolderCameraAdapter、TetherCaptureViewModel、LinkedTetherAnnotationService。

## FLOW-09 客户选片

摄影师项目→选择素材→代理图队列→发布权限/期限→客户访问→选择/批注→确认提交→摄影师拉取→身份核对→归片/项目归档。
现状默认None提供方，未配置时显示真实不可用，不生成假公网链接。旁支本地服务只能作为开发证据。客户状态和摄影师标注分域；更新冲突保留双方，不能按文件显示名盲合并。回收以稳定ImageId/文件名契约核对RAW，多候选进入归片歧义。主线TXT/CSV结果导出禁用不等于旁支已集成。

## FLOW-10 档期三端协作

桌面新建→选择项目/客户/地点/时间/提醒→本地保存→待同步→服务端确认→手机/Web显示。手机离线修改→保留本地草稿→恢复网络→携带变更ID/预期版本提交→无冲突确认或冲突比较。重复重试只提交一次。改时间/客户/金额必须明确决议；归档与恢复同步墓碑。目标时区和重复系列见CROSS_PLATFORM_AND_SYNC；当前三端端到端未实现，不把本地日历验收当跨端验收。

## FLOW-11 摄影收支

选月份/项目→记收入或支出→分类/金额/币种/状态/附件路径→校验→保存→摘要与明细一致→当前筛选CSV导出。混合币种不误加总；同名CSV拒绝覆盖。删除记录确认只影响该本地记录，不删除项目/档期/附件；收支归档与批量导入尚需规划，不能以删除代替。

## FLOW-12 工具与发布队列

选素材/编辑版本→配方（尺寸/质量/水印/命名/色彩范围）→目标目录→预检→排队→执行→完成/部分完成/取消/失败→查看输出/重试失败项/恢复。
原件不覆盖，输出冲突明确处理。取消保留已完成项并说明；崩溃恢复先核对输出与收据，冲突不自动“认领”陌生文件。清理托管临时文件必须验证任务归属。任务中心只管理任务，不另做主导航。源：PublishingExportViewModel、ExportRecipeSnapshot、ExportRecovery、TaskCenterViewModels。

## FLOW-13 扩展采集与手机传输（目标）

扩展：用户触发→选择素材→来源/去重→选择授权目的地→发送/离线队列→桌面确认入库。手机：项目身份→网络策略→上传队列→断点恢复→桌面/云确认。两者均不得仅凭HTTP返回就声称原文件已校验、已入库且已引用；这些是分开的阶段。
