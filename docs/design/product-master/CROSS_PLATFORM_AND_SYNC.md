# 跨端职责与档期同步总规格

## 1. 事实、目标与非目标

桌面是当前生产主体。src/RAWSelectionAssistant.Core/Services/Sync/SyncSemantics.cs 定义 SyncEntityEnvelope、ISyncTransport、DeterministicSyncTransport、SyncConflictPolicy；实现使用内存字典，不能证明网络服务、手机APP、浏览器端已交付。BookingSyncLifecycleSchemaMigration 提供字段/迁移也不等于客户端同步入口。浏览器扩展和手机端未在本次生产树发现可交付工程；下列是明确产品目标。

客户选片另有 OnlineSelectionContracts、SelectionUploadQueue 与 SelectionResultSyncService；主线 OnlineSelectionProviderFactory.CreateDefault 返回 NoneOnlineSelectionProvider。online-selection-v1 的 LocalDevPreview/SelectionApi.Server 是未集成实验服务，不称生产云。扩展不是该演示服务的同义词。

## 3. 目标身份与数据契约

目标：工作区/账号ID + 稳定实体ID + 变更ID；设备ID只作为来源，不作为用户身份。同步协议版本与实体schema版本分别管理。服务端唯一接收同一变更ID一次；客户端重试同一变更不产生第二个档期。来源时间、服务器确认时间、实体版本分开。删除用墓碑/归档语义，恢复产生新变更。附件为独立传输队列，元数据同步成功不代表附件已到达。

现有 SyncConflictPolicy.Apply 对较低/相同Revision直接判重复；高风险字段差异返回RequiresResolution，但结果仍有Applied=true。**这不是安全的生产冲突决议闭环**：同版本不同内容可能被当重复；高风险冲突是否阻断落库尚无三端UI证明。目标必须先保存冲突副本，用户选择后再提交新版本；不得照搬该内存策略假装已安全同步。

## 4. 档期状态机（设计目标）

本地草稿 → 待同步 → 同步中 → 已同步。
- 网络不可用：离线可编辑 → 待同步；显示本地保存时间、未发送数量。
- 权限过期：需登录/权限不足；保留本地草稿，停止发送，不删除数据。
- 服务限流/可恢复失败：失败待重试，退避；用户可手动重试但复用变更ID。
- 版本分叉：有冲突；暂停该实体写入，不阻塞无冲突实体。
- 归档/恢复并发：冲突详情展示双方意图；禁止旧编辑复活已归档记录。
- 部分成功：档期元数据已同步、附件仍上传；分别标记，不用一个绿色图标概括。

每个端状态同时用图标、文字、时间；详情列出本地和远端版本。普通文案不出现revision/CAS/hash；高级诊断可复制。

## 5. 冲突交互

1. 打开“这条档期在另一台设备有新修改”。显示项目/客户、原基准、本地修改、远端修改、来源设备与更新时间。
2. 高风险字段：开始/结束时间、客户身份、价格、定金、付款状态必须逐项确认；禁止自动最后写入覆盖。
3. 互不重叠的低风险字段可建议合并，但保存前展示摘要；同字段备注冲突提供并排与合并编辑，不无声丢字。
4. 操作：采用远端、保留本地为新版本、逐项合并、暂不处理。复制成新档期必须显式用户选择，不以冲突恢复为名自动重复。
5. 提交带预期版本；若又有远端新版本，保持输入重新比较，不能无限覆盖。完成后所有端显示统一结果与修改记录。

## 6. 时区与重复档期

目标存储：UTC瞬间 + 原始时区ID + 本地墙上时间/全天日期 + 用户明确的重复规则。Windows与跨端时区标识须建立映射，不能仅保存当前机器偏移。
- 跨时区显示“拍摄地时间”优先，可切换“我的时间”，同时注明时区。
- 夏令时不存在的本地时刻：阻止保存，建议合法时刻；重叠时刻：让用户选择偏移实例。
- 全天事项按日期，不进行午夜UTC造成跨日漂移。
- 重复：修改本次/本次及以后/整个系列；例外实例保留稳定ID；改时区不悄悄改变系列意图。
- 冲突检查同时涵盖时间重叠、摄影师/设备/场地资源；现有本地 BookingConflictRules 是基础，不等于跨端资源锁。

## 7. 扩展采集目标

明确用户主动触发；列缩略图、来源标题/URL、采集时间、原文件与预览区别、目标库/项目。来源信息与素材身份分开，URL相同不必然是同一文件。按内容/来源提示重复，用户选择跳过或新副本，不静默覆盖原件。

配对：桌面产生短期一次性码→扩展确认工作区/权限→设备列表可撤销。只申请必要域名/用户触发权限；拒绝权限时解释并提供重试，不扫描无关页面。离线队列显示待发送、发送中、已发送、重复、失败、需重新登录；取消只撤销未发送项，已入库需回素材库按其策略处理。

目的地引用失败（项目归档、库离线、画布版本变更）保留采集队列，用户重选目的地；不能默认发送到另一项目。浏览器扩展不是浏览器WebView嵌入产品的授权，本次任务不操作浏览器。

## 8. 手机任务边界

首屏围绕今日拍摄：档期地点/客户/策划/提醒。上传先选项目，显示数量、大小、网络策略、原图/压缩选项；重试保持同一传输身份。后台中断恢复后先校验已接收片段，不重复导入。手机只读策划必须标版本与最近同步时间，离线附件不可用提供下载提示。客户与摄影师身份明确切换，不能把摄影师评分误发为客户选择。

推送只是提示不是同步事实；点开后拉取最新授权数据。登出/撤销设备先说明本地未上传草稿如何保留或安全移除。备份不等于同步；同步删除不应摧毁离线备份。

## 9. 跨端验收门槛

用桌面+真实手机+浏览器客户端验证：同实体并发、乱序、重复提交、断网、令牌失效、权限撤销、归档恢复、时区/夏令时、系列例外、附件部分成功、迁移回滚。当前一律 NOT_RUN / END_TO_END_NOT_IMPLEMENTED，不以DeterministicSyncTransport测试通过替代。
