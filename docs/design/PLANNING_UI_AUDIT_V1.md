# Planning Center UI Audit v1

审计对象：`PlanningCenterView.xaml`、`PlanningCenterView.xaml.cs`、`PlanningCenterViewModel.cs`。本审计只覆盖 Stage V.1 UI/UX，不改变 Planning、Shot、Tether 领域模型。

| 项目 | CURRENT | TARGET | ACTION |
|---|---|---|---|
| 视觉重心 | 中央已有参考区，但卡片与表单同等抢眼 | 当前参考成为第一视觉主体 | 增加主参考 Hero，缩略图降级为选择条 |
| 图片面积 | 参考卡固定 230×220，主参考不突出 | 主参考大、Uniform、不裁切 | Hero + 响应式缩略图 |
| 左栏密度 | 搜索、三个普通按钮、底部上/下移常驻 | 摄影序列 + 紧凑筛选 | Filter Chip；排序动作保留键盘/右键，底部弱化 |
| 中央图片区 | 卡片网格先于低频信息，但图片偏小 | 图片 > 空间 > 信息 > 控件 | Hero 放在分类之后、摘要之后 |
| 右侧 Inspector | 默认直接呈现多个 TextBox | 默认查看态，按需编辑 | 增加查看/编辑切换 |
| 策划摘要表单感 | 打开即看到多个输入框 | 默认折叠，内容摘要优先 | Expander 默认关闭 |
| 视觉方向层级 | 一个 Panel 内标题和列表密集排列 | 简洁的方向摘要 | 减少嵌套卡片，保留真实数据 |
| 按钮数量 | 中央顶部四个动作并排 | 主动作突出，其余低权重 | 缩小素材入口，统一 Ghost/Secondary |
| 边框数量 | 左、中、右及摘要/视觉方向多层 PanelBorder | 用空间和 Divider 分层 | 保留结构边界，去除图片卡厚边框 |
| 圆角一致性 | 大多使用资源，局部仍需复查 | 只使用设计 Token | Planning 页面不新增硬编码半径 |
| 默认 WPF 泄漏 | 全局控件已有产品化样式 | Popup/Menu/输入一致 | 显式应用深色 ContextMenu 与现有控件样式 |
| 中文语言 | 主页面大部分中文，少量内部语义需核验 | 前台自然中文 | 新增文本全部中文，保留 `Shot 03` 摄影编号 |
| 1080p | 左 260 + 中 520 + 右 320，中央接近下限 | 中央图片仍为主角 | 维持最小宽度，缩略图响应式且不固定列数 |
| 125% DPI | 依赖现有 DIP 样式 | 无裁字/重叠 | 自动化几何门 + 人工包复核 |
| 空状态 | 只有一行“尚未建立拍摄清单” | 有下一步动作 | 增加创建第一个拍摄入口 |
| Hover/Selected/Pressed | 通用控件有状态，参考卡选择弱 | 选择与悬停轻量可辨 | 使用现有控件状态与低对比背景 |
| Quick Preview | 已支持双击、Space、Esc、前后切换 | 产品化深色大预览 | 保留现有能力，统一 Modal 圆角/遮罩 |
| Context Menu | 菜单内容合理，样式依赖默认资源 | 深色、低边框、自然分组 | 显式绑定现有 Av2ContextMenu 样式 |

## 验收边界

本轮不宣称真实 WPF 截图、实体 DPI、多屏或真实相机通过。美感结论仍需用户机器上的 10–15 分钟人工验收包确认。
