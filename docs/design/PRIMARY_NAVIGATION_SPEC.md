# 一级导航与项目工作流

2026-09-18。本规范替代此前“策划仅从项目进入、在线选片属于工具”的规则。

- 工作：工作台 → 素材库 → 归片工作区 → 工作日历 → 策划中心 → 联机拍摄 → 在线选片 → 摄影收支 → 项目历史。
- 工具：工具箱（唯一入口）。参考仿色、批量压缩、发布导出保留在工具箱，后两者是不同工作流，不合并重命名。
- 系统：授权与版本、设置、帮助。

策划中心复用 PlanningCenterView/ViewModel。无项目时显示图片优先的项目总览，包含搜索、最近策划、进行中、即将拍摄、最近修改、新建策划。卡片显示参考封面、名称、日期、已拍进度；没有封面时显示中性占位。

一级入口恢复当前或上次项目/拍摄项；项目内“全部策划”返回总览。日历、项目历史及项目/拍摄项深链接进入同一工作区。进入联机拍摄保留当前项目和拍摄项，“返回策划”恢复联机当前拍摄项。

在线选片复用原工作区，项目卡片显示封面、客户、照片/已选数量和中文状态，可搜索和筛选。网页/微信分享仍在该工作区内部，没有新增一级入口。

设置持久化最后一级页面、策划项目及拍摄项。不存在或损坏的项目返回总览，保留原文件；缺失拍摄项回退到有效拍摄项。开发预览版不再每次启动强制打开演示项目。

沿用深色主题、40px 导航行和共享状态样式。策划使用独立几何图标。1920×1080、100% 的实际窗口布局应无侧栏滚动；更高 DPI 不冒充已完成人工验收。
