## 0. 产品与全局规则
- 产品：**Kitao Studio 光镜**，Windows 桌面摄影工作流应用，WPF / .NET 实现。界面文案全部简体中文。
- **品牌**：界面任何位置不得出现旧品牌「Pixel Tart / 像素蛋挞」。
- 视觉：深色、Capture One 式高密度；强调色 **#6E9B91**（青绿），主按钮底 **#4A766C**；正文 11–12px，最小 11px；尺寸单位为 DIP。沿用 `Resources/DesignSystem` token（01-design-system.md）。
- **主界面不放说明文字**：提示放 tooltip、F9 开发标注层（原型中按 F9 或 URL `?review=1`）与「帮助」菜单。所有图标按钮带 tooltip 与 AutomationProperties.Name。
- 画面优先：照片 > 工作区 > 控件；浮窗默认不遮画面。
- 每屏最多一个主按钮（青绿底）。
- 代码基线（只读参考）：`validation/guangjing-whole-app-followup-20261022`。

### 2.2 简易 / 专业双模式
- 两模式**共用一份编辑数据与一条撤销历史**；Ctrl+1 / Ctrl+2 切换，只改变右栏与底部内容。
- **简易右栏**：直方图 → 图层栈 → 选中图层的不透明度 / 混合模式 → 基础（色温、色调、曝光、对比度、高光、阴影、白色、黑色、饱和度、自然饱和度）。
- **图层栈**（行高 38）：显隐眼睛、缩略图、蒙版缩略图（有蒙版时）、名称 + 混合 · 强度、锁定；底部工具：新建调整图层 / 添加蒙版 / 复制 / 删除。左栏预设单击 = 添加为新图层。
- **专业**：节点区 + 右栏「节点参数（可见/旁路、锁定、蒙版、不透明度、混合模式）」+ 页签 曲线 / 色轮 / HSL / 基础。

### 2.3 节点区（专业）
- 串行，从左到右 = 处理顺序：输入 RAW → 01 基础校正 → 各图层节点 → 输出。节点卡 132 宽：序号、类型图标、锁 / 隐藏状态、预览缩略图、名称 + 混合 + 强度。选中 = 青绿描边。旁路 = 45% 透明。
- **节点拥有图层的全部能力**：混合模式、不透明度、锁定、显隐、蒙版与画笔。
- 有蒙版的节点：卡内 34×52 蒙版缩略框，单击进入蒙版编辑（右栏变为画笔：画笔 / 擦除、大小、羽化、流量、密度、叠加显示（红 50%）、反相、清除、智能选主体、「完成」）。无蒙版：不显示框，悬停出现虚线「＋蒙版」。
- 节点区与胶片条标题栏左侧各有 ▾/▸ 折叠箭头，收起后为 22px 细条。标题栏不放说明文字（说明在 tooltip）。
- 即时胶片显影后，节点链末尾出现**系统锁定节点**「即时胶片 · 相纸缩写」，不可解锁。

### 2.4 3D 色彩
- 入口：右栏直方图标题右侧胶囊开关「◎ 3D 色彩」，简易 / 专业都有；开启时高亮。
- 打开为**浮窗**：标题栏拖动、右下角缩放（最小 420×300）；默认停靠在左资源栏上方，宽 = min(600, 画面左缘 − 14)，**默认不遮挡画面**；Esc / × 关闭。
- 内容（移植 R3 3D 色彩空间）：OKLab 点云（拖动旋转、滚轮缩放）；显示 调整前 / 参考 / 当前 / 叠加；H / S / L 滑块（±180° / ±100 / ±100，实时更新画面与点云）；采样 预览 / 标准 / 密集、点大小、明度下限 / 上限；叠加 a/b 平面、迁移向量、保护区、仅选中色域；仿色强度；图片取色 / 清除取样；侧视 / 俯视 / 等轴 / 复位。

### 2.5 变体（Capture One 式，替代旧「版本」）
- 数据：`Photo{file, mainVariant, expanded, variants[]}`；`Variant{id, name, edits, stars, colorLabel}`；原片 = variants[0]，**不可删除**。每个变体独立编辑、星级、色标。
- 收起：同一原片的变体叠成一张（叠纸阴影），显示主变体；右下计数徽标 `▣ N`。单击徽标展开：变体内联排列，1px 青绿细线相连，末尾「＋」；再单击收起。
- 角标：左上「主」= 主变体；左下 = 即时胶片相纸缩写。
- 新建：**F2 从原片新建**、**F3 复制当前**；入口为缩略图右键菜单与展开组末尾「＋」。
- 右键：从原片新建 / 复制当前 / 设为主变体 / 重命名… / 加入对比 / 评分 / 色标 / 删除变体…（原片置灰；删除需确认，可撤销）。
- 对比：Ctrl+单击选 2–4 个变体 → 胶片条标题出现「并排对比 N」→ 画面 1×2 / 2×2 网格，缩放与平移同步；Esc 退出。
- 主变体：收起时显示；导出与「送入拼贴」默认使用。
- 命名：即时胶片显影变体 `{相纸缩写} {yyyyMMdd}-{序号3位}`，例 `ITYPE C 20261018-001`。

### 2.6 即时胶片（R3 模块整体移植 + 方案 B 布局）
**原则：直接移植 R3 / R3.1 / R3.2 / R3.3 的即时胶片模块代码与资源（实拍相机图、实拍相框扫描、显示框、显影动画），不得重画或以色块替代。** 原型中由 `instant-r3.html`（R3 原文件 + 嵌入层）承载。

布局（用户确认的方案 B）：
- **左栏「即时胶片」页 = 唯一的相纸选择处**：拍立得样式相纸卡（3 列），可折叠分组 彩色（i-Type / 600 / SX-70 彩色）· 黑白（3）· 实验性（10：黄、蓝、紫、绿、黑蓝 / 黑黄 / 黑绿 / 黑橙 / 黑红 / 黑粉双色）。R3 右栏的「相纸」分区隐藏，不重复。
- **画面区 = R3 显示框**：真实相纸成品预览（相框扫描包围画面），画面区底边对齐胶片条顶边。
- **右栏（全高，至状态栏）= 参数**：相机（i-2 / SX-70 实拍图 + 「相机动画」开关）→ 相框（经典白 / 黑、彩色、金属、特别版 / 图案（光镜原创角色）、已安装（相框模板 + 边框库…）、**联名（组标题「需授权」，98 款 / 9 系列，可搜索与按系列筛选）**；方形 / 圆形窗口）→ 常用参数（乳剂浓度、相纸质感、光学柔化、成像气温、随机成像组合概率、骰子 轻 / 中 / 重、重新随机）→ 相纸瑕疵（5 组 15 项，开关 + 强度 + 纹理缩略 / 换纹理 + 边缘）→ 高级（色彩与层次、柔光与颗粒、显影缺陷形态、纸框与构图、纸面与表面、窗口与反射、双重曝光（第二张照片选择）、输入来源）。
- **显影栏贴右栏底部**（与胶片条底边对齐，无空白条）：取消 ｜ 显影（主）。

流程：
1. 选相纸 → 实时预览（调参、瑕疵均实时显示在显示框）。若当前照片已有调整，R3 弹出「从原图 / 沿用当前」提示。
2. **显影 = 一次性**：生成新变体（§2.5 命名），配方锁定。显影动画（闪光 → 出片 → 显影 → 光泽扫过 → 缩回画布 + 进度线）由「相机动画」开关控制，**默认开**（R3.2 D-COLOR3-03），关闭时只走进度线。
3. 已显影变体：右栏为只读配方摘要；仅可「进阶调色」（只作用于画面区域，不改相框）；「以原片新建版本 / 从原图重新拍一张」开始新的外观，旧变体保留。
4. 已显影变体选中时，**左栏相纸卡置灰禁用**（不透明度 0.38、cursor not-allowed，仅 tooltip 说明），不可点击。
5. 专业模式节点链出现锁定的「即时胶片」节点。
- 未移植：仅「诊断信息」（开发信息，隐藏）。逐项核对见 `instant-port-check.md`（176 项：175 ✅ / 1 ❌）。
- 联名相框涉及第三方 IP：原型默认安装以便评审，**正式发布前须取得授权**，否则不随产品安装。

### 2.7 锁定规则（图层 / 节点 / 拼贴对象统一）
锁定后：禁止改参数、改 / 涂蒙版、排序、删除、被框选移动；仍参与渲染；允许切换显隐（写入撤销）。锁定参数置灰。即时胶片节点为系统锁定，不可解锁。

### 3.2 对象与画笔
- 对象：移动、角点等比缩放、旋转柄（Shift 15°）、翻转、透明度、锁定、显隐、编组、删除、撤销重做。斜切 / 透视 / 自由变形标注为后续版本，不放模糊「变形」按钮。
- 画笔三目标：绘画 = 写入「绘画层 N」；蒙版 = 写入选中照片的蒙版（未选照片时提示、不落笔）；擦除 = 只擦绘画层笔触。笔刷：铅笔 / 记号笔 / 柔边笔 / 喷点 / 印章。无压感设备时压感禁用。
- 来源：照片显示「暗室 · 变体名」链接或「项目副本」；暗室有新变体时显示「更新可用」+ 手动「更新」（可撤销），不自动改。缺失：斜纹占位 + 「重新定位… / 替换」，保留位置尺寸。
- 导出：PNG（可透明）/ JPEG（填画板背景色）；只导出画板区域；PDF / CMYK 灰显「暂不支持」。旧「模板拼图」作为「画板▾ → 从模板开始」二级入口。

### 3.3 快捷键
V H T U B；X 循环画笔目标；[ ]；Ctrl+G 编组；Delete（锁定对象不删）；Ctrl+S 保存；Ctrl+Shift+E 导出；Shift 点击加选；空白处拖框选（跳过锁定）。

### 3.4 1366×768

- 选卡时预检可用性；不可用（RAW、16 位 / 浮点、透明、复杂节点图、已胶片化）显示一句原因 + tooltip，主按钮禁用。
- 任务状态：等待 / 计算（仅真实上报时显示百分比）/ 取消中 / 失败（保留风格与来源，可重试）；同一任务排队时「生成新变体」禁用；关闭面板 ≠ 取消；接入任务中心；不承诺崩溃恢复。
- 成功：查看结果 / 与来源比较 / 返回暗室；新变体自动入灯箱并选中（满 100 只存变体并提示）。
- SpektraLab：右栏底部一行「负片 / 印相模拟 · 研究中」，仅 tooltip。概念页（草图 13，标后续）：胶卷→相纸（Portra 400/Endura、Ektar 100/Ultra Endura、Tri-X 400/Multigrade）、曝光、颗粒、光晕、强度，无种子；限制：颗粒与光晕为空间效果（非 LUT）、输出不透明 RGBA16 有裁切（无 HDR / 透明）、sRGB 输入为创意模拟、不用 I-2 / SX-70 命名。

### 10.8 只读显影流程（草图 10–12）
- 专业节点图左侧独立泳道，灰色虚线容器「显影流程 · 只读」，4 阶段：冻结输入 → 即时胶片响应 → 照片窗口调整 → 纸框与成品；细线、无端口，与可编辑青绿节点区分。
- 点阶段 → 右栏「配方摘要」：来源 / 相纸·相框 / 效果摘要 / 冻结状态；「高级详情」收起（可复制 JSON 与版本）。跟随所选照片 / 变体。
- 7 种状态：显影前无泳道 · 草稿 · 已显影锁定 · 窗口调色 · 重拍 → 新变体 · 取消重拍恢复 · 旧配方不支持。
- 布局沿用 2×2 色轮（单元 139×186，容器 ≈ 382，色轮 112）与照片右侧示波器条（收起 22）。
