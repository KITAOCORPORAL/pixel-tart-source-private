# Online Selection Project A-v2 Master

## 结构

项目页包含四个固定页签：照片、规则与发布、客户进度、结果与归档。

Header 展示项目名、状态、服务连接状态和上下文主要动作。照片是视觉主角，控制区不得长期占据大面积画布。

## 照片

支持导入 JPG、从 RAW 生成代理 JPG、查看上传队列、失败重试、暂停和恢复。照片网格优先使用大缩略图和安静状态标记。

## 规则与发布

规则必须可读并在发布前验证。发布门禁要求项目有效、至少一张 Ready、规则有效；失败资源必须明确列出。

## 客户进度

只显示客户可见范围内的进度、收藏、评论和确认状态。不得展示 RAW、本地路径、内部备注、财务、人员或完整 EXIF。

## 结果与归档

最终选片可同步回本地归片项目，并保留原始文件名匹配依据。删除云端副本不得删除本地文件。归档后仍可查看同步结果和审计摘要。
