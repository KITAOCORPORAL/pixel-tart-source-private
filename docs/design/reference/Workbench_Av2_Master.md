# Workbench A-v2 Master

## 目标

工作台是摄影师每天进入产品后的行动入口，不是统计仪表盘。

## 固定骨架

1. 本地分片主入口。
2. 四个快捷工具：整理图片、RAW 转 JPG、批量压缩、拼图。
3. 项目概览：进行中、待确认、待返图、已完成。
4. 今日拍摄与未来 7 天。
5. 最近项目。
6. 右侧迷你工作日历。
7. 右侧任务中心。

## 优先级

本地分片 → 今日拍摄 → 工作日历 → 最近项目 → 任务中心 → 汇总数字。

## 布局规则

主内容使用 L1 Workspace，右侧日历和任务中心使用 L2 Local Panel。1280 宽度时右侧改为按需 Drawer，不能压缩正文。任务中心只显示处理中、等待确认、需要处理，以及最多三条最近完成任务。

## 禁止

不增加大面积渐变英雄卡，不增加无行动意义的六宫格数字，不把天气、人员、财务和文档管理塞进迷你日历。
