# Online Selection Home A-v2 Master

## 目标

首页服务摄影师建立、上传、发布和跟踪选片项目，不做运营数据大屏。

## 结构

Header 提供页面标题、服务连接状态和唯一“新建选片项目”Primary。主体依次为需要处理、进行中的项目和最近关闭项目。

项目行展示封面、项目名、客户代号、图片数量、上传或选片进度、当前状态和最近更新时间。服务未配置时显示完整本地原型和明确的“在线选片服务未配置”，不得白屏或显示假生产数据。

## 空状态

说明可先建立本地项目、导入 JPG 或生成 RAW 代理图；同时明确尚未上传、不会自动公开照片。

## 禁止

不增加 GMV、活跃用户、转化率等平台运营指标；不显示客户隐私、完整本地路径或内部备注。
