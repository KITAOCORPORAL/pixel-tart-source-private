# Full Calendar A-v2 Master

## 固定结构

页面采用约 60/40：左侧完整日历，右侧当天概览。

顶部保持一行：视图、上一周期、年月、下一周期、今天、状态、搜索、更多筛选。小窗口可以将筛选降级到第二行，但不得重叠或缩小文字。

## 月视图

日期数字使用五色实心 CalendarDayNumberBadge。今天用独立外框，选中用日期格边框，关闭档期保留原状态并叠加锁图标和降亮。跨日排期必须连续且可识别。

## 右侧当天概览

默认展示日期、项目、客户、时间、地点、状态、天气摘要、资料数量、人员数量和财务摘要。资料、人员、天气提醒和财务细节默认折叠。

日期任务卡只展示项目和时间。点击进入详情；更多菜单提供编辑、状态和归档。时间、客户、地点、状态允许快速编辑；四步完整策划作为明确的次级动作。

## 状态

顶层图例仅空闲、有拍摄、已拍摄、待返图、已返图。更细业务状态放入更多筛选。
