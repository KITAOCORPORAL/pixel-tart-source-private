# 联机拍摄参考模式规格

## 信息结构

联机拍摄保持一个页面：中央主照片、默认 360px（320–480px）可调右栏、底部横向胶片条。右栏独立滚动，前四组依次为曝光评估、参考模式、拍摄参考、相机 / 拍摄会话；旧的 EXIF、比较、叠加、标记、LUT、客户监看和文件处理仍保留。

## 默认参考模式

默认只展示当前项目 Look、仿色强度、查看模式、应用到后续拍摄和“高级”入口。高级展开后显示影调、色彩、对比度、饱和度、启发式肤色保护和高光保护。

查看模式：原片、仿色、左右对比、并排对比。默认左右对比。按住 `B` 临时看原片，松开恢复；该键沿用现有 LUT Before 行为，在参考模式启用时由参考模式优先消费。

## 分割比较

- 左层为当前监看原片，右层为匹配结果。
- 细分割线和小手柄可拖动；双击回到 50%。
- 位置限制在 0–1，25%、50%、75% 均为正常状态。
- 拖动只改变裁剪矩形和手柄位置，不读取磁盘、不解码、不重新匹配。
- 两层放在同一个父级 Scale/Translate 下，共享 Fit、100%、Zoom 和 Pan。

## 后续拍摄

启用“应用到后续拍摄”后，捕获接收与保存仍先完成，原始快速预览立即可用；匹配在后台执行。新素材身份和渲染修订共同阻止旧结果覆盖新图。取消、失败或异常只回退原片，不影响文件发现、缩略图、评分和备注。

## 能力边界

Watch Folder 在界面中只称“文件夹监看”。它不显示相机对焦、遥控快门、曝光设置、电池或存储控件，也不冒充 USB 相机连接。
