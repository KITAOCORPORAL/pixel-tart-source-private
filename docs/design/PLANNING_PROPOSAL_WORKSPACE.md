# 摄影策划案工作区

本轮将策划中心从永久三栏镜头执行面板改为 280 DIP 策划案列表与正文编辑区。全局一级导航不变。
内容顺序固定为文字、参考图、情绪板、镜头清单、灯光图、服化道、文件；默认阅读，编辑按需开启，预览隐藏项目列表和编辑控件。

## 数据兼容

继续使用 ProjectPlanning 的 version-1 JSON 与 ProjectShots 存储。
PlanningSummary 映射文字章节；Shots 映射镜头清单；Lighting/Styling 引用映射灯光图/服化道；
VisualLinks、Canvas、Board、Palette、Tone、ReferenceLook 继续使用原有身份和存储。
可选 Document 扩展保存正文、独立策划状态、封面/情绪板选择、附件关系，不创建第二套数据库，不扩展拍摄状态枚举。

自动保存按项目/镜头身份抓取快照，约 450ms debounce。项目切换、预览、导出和应用关闭需 flush；
保存前先原子写草稿，提交只合并正文相关字段，不覆盖联机执行记录，失败保留草稿且阻止切换/关闭。
草稿包含待写镜头快照，正文和镜头均提交后再清理；最近 450ms 尚未开始保存的输入不在崩溃恢复承诺内。
图片仅保存稳定身份或外部路径；预览缓存是派生缩略图，不复制原图。移除关系不删除源文件。

正文使用轻量标题、段落、列表、引用、粗体和分隔线，不实现 Office 或通用 Markdown IDE。
PDF 导出复用正文排版，保持图片比例和分页；不实现 DOCX。
当前 PDF 为本地 144 DPI 图像页，中文字体通过 WPF 排版，不依赖外部服务；文字不可选择或检索。
演示数据仅由显式验收环境开关产生，普通启动不自动创建项目。

用户已明确以补充的完整文字视觉规范取代参考图；不再请求或等待截图。实施依据为两栏、正文 820–980 DIP、深灰黑、克制控件和现有 Pixel Tart Design System。
