状态：Design Constitution v1.0

## 02 视觉

### Image First

- [ ] 图片或当前摄影工作是页面最强视觉主体。
- [ ] 没有为了文字、统计、筛选或按钮牺牲必要的图片观看面积。
- [ ] Thumbnail 保持比例，横竖图处理一致，没有无理由强裁切。
- [ ] Gallery 有足够呼吸空间，不以“塞满”为目标。
- [ ] 图片状态不使用大面积彩色遮罩，不影响色彩判断。
- [ ] 无图片页面仍把“下一步摄影工作”放在数据汇总之前。

### 暗房气质

- [ ] 第一感受是摄影工作室 / 暗房 / 编辑桌 / 画廊，而不是 Dashboard。
- [ ] 背景中性，不偏色，不使用强渐变、发光、玻璃和游戏化装饰。
- [ ] 视觉克制、可长时间停留，负空间是有意布局而非空壳。
- [ ] 图标线宽、尺寸和语义一致，无 emoji、字体符号与矢量图标混用。

### 颜色

- [ ] 仅有一个品牌交互强调色。
- [ ] 当前 Page / Drawer / Dialog 可见范围最多一个实底 Primary。
- [ ] Success / Warning / Error / Info 只表达状态，不表达模块。
- [ ] 状态同时有文字、图标或形状，不只靠颜色。
- [ ] 未在页面中硬编码色值；Dark / Light / High Contrast token 完整。
- [ ] 不存在白色输入块泄漏、低对比小字或状态色污染图片。

### Typography

- [ ] 只使用 Display、Heading、Section、Body、Caption、Metadata 六级语义样式。
- [ ] 一个页面只有一个 Heading，标题关系清晰。
- [ ] 正文不小于 13 DIP，任何文字不小于 11 DIP。
- [ ] 没有通过缩小文字解决布局问题。
- [ ] 文件名、路径、EXIF、日期、金额的截断和完整读取方式明确。
- [ ] 200% DPI 和大字号下无裁切、重叠或消失。

### Spacing / Layout

- [ ] 只使用 4px 基础间距序列：4、8、12、16、24、32、48。
- [ ] 页面边距、面板间距、图片间距与控件间距符合统一角色。
- [ ] 层级主要靠留白、对齐和排版，不靠卡片套卡片。
- [ ] 中间 Canvas 获得剩余空间；左栏与 Inspector 可收起。
- [ ] 页面只有一个主要滚动区，没有超过两层嵌套滚动。
- [ ] 超宽屏让图片变大，而不是让控制器变多。

### 信息密度 / Card / Button

- [ ] 首屏能在 3 秒内看出当前任务与主操作。
- [ ] 没有无行动价值的指标、Badge、说明或诊断信息。
- [ ] Card 仅用于项目、图片或任务；不存在所有内容都包 Card。
- [ ] 工具栏不超过 5 个同层级按钮，低频动作进入菜单。
- [ ] 未实现能力不以长期禁用按钮或菜单项展示。
- [ ] 无同义、重复、无 Command 或无反馈的死按钮。

## 03 交互

### 鼠标

- [ ] 单击选择 / 定位，双击进入对象，语义不冲突。
- [ ] 右键未选中对象时正确更新上下文选择，多选规则一致。
- [ ] Hover 不改变布局、比例和滚动，不使用弹跳或夸张缩放。
- [ ] 所有 Hover 动作都有键盘等价入口。
- [ ] 菜单按查看、整理、创作、导出、危险操作分组。
- [ ] 二级菜单、屏幕 / DPI 边缘避让和 Hover 路径容错已验证。

### 键盘

- [ ] Esc 每次只关闭最上层，并按规定顺序返回。
- [ ] Enter、Space、Delete 的页面语义清楚且一致。
- [ ] Ctrl / Shift 多选、Ctrl+A、Ctrl+F、Ctrl+Z 可用。
- [ ] 方向键可浏览 Gallery / Menu / Canvas，不产生冗长 Tab 链。
- [ ] 快捷键可发现，并有 Menu / Tooltip 或帮助入口。
- [ ] 删除键不会直接永久删除。

### Focus

- [ ] 键盘焦点始终可见，且与 Hover / Selected 可区分。
- [ ] Tab 顺序符合视觉顺序，不进入不可见或装饰元素。
- [ ] Dialog / Drawer / Menu 关闭后焦点返回触发控件。
- [ ] 导航后焦点进入页面 Heading 或主画布。
- [ ] 浮层打开时焦点和屏幕阅读范围被正确限制。

### Drag & Drop

- [ ] 可拖对象、合法目标、非法原因和 Drop 结果清楚。
- [ ] 拖拽预览显示对象与数量，目标反馈不遮挡内容。
- [ ] Esc 可以取消拖拽并恢复原状态。
- [ ] 拖入 / 拖出 / 重排 / 边缘滚动在适用场景通过。
- [ ] 默认不会静默移动、覆盖或删除源文件。
- [ ] 从集合移除与磁盘删除有明确区分。

## 04 状态

### Loading

- [ ] 不出现空白屏；页面结构和尺寸保持稳定。
- [ ] 图片采用占位 → 代理 / 低清 → 清晰图的渐进加载。
- [ ] 刷新时尽量保留已有内容，不整页清空。
- [ ] 长于 2 秒显示阶段；长于 10 秒提供取消或后台执行。
- [ ] Loading 不只依赖动画表达。

### Empty

- [ ] 说明当前区域是什么、为何为空和下一步动作。
- [ ] 涉及文件时说明原文件安全边界。
- [ ] 不只显示“没有数据 / 暂无内容”。
- [ ] 不使用假照片、假任务或假统计填空。
- [ ] 最多一个 Empty State 主动作。

### Error

- [ ] 显示原因、影响和解决方式。
- [ ] 多文件任务显示成功 / 失败 / 跳过数量。
- [ ] 明确源文件是否安全、能否重试、能否只重试失败项。
- [ ] 技术详情可折叠、可复制且已脱敏。
- [ ] 保存失败后保留用户输入。

### Success / Undo

- [ ] Success 使用轻量 Toast，不用巨大弹窗。
- [ ] Toast 说明完成了什么，不只写“成功”。
- [ ] 可恢复操作提供可发现的 Undo 与快捷键。
- [ ] Undo / Redo 在跨页面或任务边界的行为已定义。
- [ ] Toast 不遮挡主操作、Gallery、胶片带或 Inspector。

### Task Status

- [ ] 长任务进入统一任务中心，页面不重复多个 Badge。
- [ ] 显示任务名、阶段、进度、数量和取消 / 恢复能力。
- [ ] Partial Success 与 Success / Error 可区分。
- [ ] 完成任务自动降噪并可在历史中找回。
- [ ] 任务类型不通过各自专属颜色表达。

---

## 05 组件与工程

- [ ] 页面只组合 Design Tokens、Components、Patterns 与 Layouts。
- [ ] 未在页面新增硬编码颜色、字号、间距、圆角、阴影或动画。
- [ ] 未复制共享 Style 或创建页面私有的相近组件。
- [ ] 所有新增组件有 Default、Hover、Pressed、Focused、Disabled 状态。
- [ ] 选择组件有 Selected；异步组件有 Loading、Empty、Error、Success。
- [ ] 纯图标按钮有可访问名称与 Tooltip。
- [ ] 新 token / 组件已先更新设计系统文档并解释复用价值。
- [ ] 未破坏 Dark、Light、High Contrast 与 Reduced Motion。
- [ ] 未改变功能逻辑、文件安全、任务状态机或数据语义来迁就视觉。
- [ ] 未破坏其他页面或引入第二套主题资源。

## 06 响应式与屏幕门禁

### Windows 缩放

- [ ] 100%
- [ ] 125%
- [ ] 150%
- [ ] 200%

### 分辨率 / 窗口

- [ ] 1280×720 最低有效窗口
- [ ] 1920×1080
- [ ] 2560×1440
- [ ] 3840×2160
- [ ] 超宽屏（21:9 或更宽）

### 每个组合检查

- [ ] 无文字重叠与关键裁切。
- [ ] 主操作可达，浮层不遮挡。
- [ ] 图片比例、清晰度与滚动锚点正确。
- [ ] 左栏 / Inspector 按优先级折叠，不缩小正文。
- [ ] Menu、Tooltip、Drawer、Dialog 避让屏幕和任务栏边缘。
- [ ] 无水平 + 垂直多层滚动陷阱。

## 07 页面专项

### 工作台

- [ ] 感觉是摄影桌，不是 Dashboard。
- [ ] 最近作品 / 当前项目比统计卡更突出。
- [ ] 没有用一排 0 指标填充空状态。

### 工作日历

- [ ] 感觉是拍摄计划墙，不是企业排班表。
- [ ] 点击日期进入当天拍摄故事；状态五色集中且有非颜色通道。
- [ ] 月视图没有塞入金额、客户资料和多按钮。

### 素材库 / 灵感托盘

- [ ] Gallery 获得主要面积，Inspector 无上下文时收起。
- [ ] 灵感托盘必须显示缩略图而不是文件列表。
- [ ] Viewer、Inspector、Tray 三种容器角色没有混淆。

### 情绪板 / 策划中心

- [ ] 情绪板是自由画布，策划中心是创作空间而非表单后台。
- [ ] 参考图片持续可见，文字与控制器为辅助。
- [ ] 画布和结构编辑可 Undo，删除引用不删除源素材。

### 联机拍摄 / 在线选片

- [ ] 最新 / 当前照片最大，连接与同步状态安静且真实。
- [ ] 客户屏与在线分享不暴露路径、隐私或诊断信息。
- [ ] Provider 不可用、离线与同步冲突有真实状态，不伪装成功。

### 项目历史 / 摄影收支 / 设置

- [ ] 项目历史像档案馆，不只有 DataGrid 与操作列。
- [ ] 摄影收支像私密账页，不是 BI 数据大屏。
- [ ] 设置为分类 + 单列内容，未把所有选项包成 Card。

---

## 08 动画

- [ ] 动画只使用淡入、渐显、必要的平滑移动和缩略图显影。
- [ ] 时长与 Motion token 一致，常规反馈约 120—220ms。
- [ ] 无弹跳、夸张缩放、翻转、粒子、庆祝或循环脉冲。
- [ ] 动画不改变图片比例，不阻碍高频键盘操作。
- [ ] Reduced Motion 下取消非必要位移与循环，功能仍可理解。

---

## 09 数据、隐私与诚实性

- [ ] 无假生产数据、假联机、假上传、假分析或假成功。
- [ ] 日志、Automation Name、Toast 与截图不泄漏客户隐私、完整路径、金额或照片。
- [ ] 文件操作明确引用、复制、移动、移除、回收站和永久删除差异。
- [ ] 不可逆操作说明影响并要求明确确认。
- [ ] 缺失、离线、引用失效与解析失败不会被显示成普通空状态。

---

## 10 Evidence 要求

交付至少附：

- [ ] 正常内容状态截图；
- [ ] Loading、Empty、Error、Success 截图或录像；
- [ ] Keyboard Focus 与右键菜单截图；
- [ ] 100%、125%、150%、200% DPI 关键页面截图；
- [ ] Dark、Light、High Contrast 验证；
- [ ] 自动化 / 人工交互记录；
- [ ] 硬编码与重复 Style 静态检查结果；
- [ ] 与本次变更无关页面的回归结果。

截图必须来自真实运行界面，不用设计稿替代实现验收；测试数据必须是合成数据并明确标识。

## 11 Review 结论

选择一项：

- [ ] **通过**：全部适用门禁通过，无未记录例外。
- [ ] **有条件通过**：只有明确、限期、非安全性的例外，已登记负责人。
- [ ] **不通过**：存在 Image First、状态、键盘、DPI、隐私、文件安全、硬编码或复用缺陷。
