# Pixel Tart Interaction Guidelines

状态：Design Constitution v1.0  
目标：让鼠标、键盘、拖拽、焦点、状态与动画在全部摄影工作区中保持一致、可预测、可撤销。

---

## 01 交互原则

1. **直接。** 在照片、项目或拍摄上操作，而不是先进入管理模式。
2. **可预期。** 同一动作在不同页面保持同一点击、键盘与反馈语义。
3. **可恢复。** 整理、评分、移动、移除等操作优先支持 Undo；破坏性动作明确影响。
4. **不打断。** 普通流程使用就地反馈、Drawer 和 Toast；Dialog 只用于必要决定。
5. **状态诚实。** Loading、空、离线、部分完成、错误和成功不可混用。
6. **图片优先。** 控件按需出现，交互反馈不遮挡或改变照片判断。

---

## 02 鼠标与指针

### 2.1 单击

- 照片 / 项目：选择并更新 Inspector，不默认打开新窗口。
- 空白画布：清除当前轻量选择；有未保存编辑时不静默丢失。
- Button / Menu：执行一次明确动作。
- 日期：选择日期并显示当天拍摄故事或右侧详情。
- 已选对象再次单击不切换业务状态，避免误评分、误 Pick。

### 2.2 双击

- 照片：进入沉浸 Preview；再次双击可在适合窗口与 1:1 间切换。
- 项目：进入项目工作区或拍摄故事。
- 日历日期：进入该日期的拍摄故事 / 新建流程应由页面规范明确，不与单击冲突。
- 文件夹：展开或进入；全产品选择一种模式并保持一致。
- 任何单击按钮都不要求双击。

双击动作必须有等价键盘和菜单入口。若单击与双击会造成不可逆冲突，不使用双击承担该动作。

### 2.3 右键

- 打开当前对象菜单；未选中对象先成为上下文选择。
- 在多选集合内右键保持多选；在集合外右键切换为该对象。
- 空白区域菜单只包含画布 / 当前集合动作，不出现对象动作。
- 菜单按查看、整理、创作、导出、危险操作分组。

### 2.4 Hover

- 仅提示可交互、展示名称 / 快捷键或显示低频行操作。
- 反馈时长 120—160ms；不能改变布局、图片比例或滚动位置。
- 禁止弹跳、夸张缩放、彩色蒙版、强阴影与整卡上浮。
- Hover 不是功能前提；所有动作可通过键盘和触屏等价完成。

## 03 键盘

### 3.1 全局基线

| 按键 | 语义 |
| --- | --- |
| `Esc` | 逐层关闭 Menu → Popover → Drawer / Dialog → Preview；不直接退出应用 |
| `Enter` | 执行当前默认动作；在选中照片上进入 Preview |
| `Space` | 切换选择 / Pick，具体语义由当前工作区提示且不可混用 |
| `Delete` | 发起移除 / 回收站流程，不直接永久删除 |
| `Ctrl+Z` | 撤销最近可恢复操作 |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+A` | 选择当前范围内全部对象 |
| `Ctrl+F` | 聚焦当前页面搜索，不强制跳转其他页面 |
| `Ctrl+C` | 复制当前对象允许公开的值或引用 |
| `Ctrl+S` | 保存当前可保存内容，不改变浏览状态 |
| `F2` | 重命名当前对象（若支持） |

### 3.2 选择修饰键

- `Ctrl+Click`：切换单个对象是否在选择集合中。
- `Shift+Click`：从锚点连续选择到当前对象。
- `Ctrl+A`：只选择当前筛选 / 集合的可操作范围；大集合需明确数量。
- 箭头键：移动焦点；`Shift+Arrow` 扩展选择；焦点和选择可区分。
- 批量动作必须显示将影响多少项。

### 3.3 Menu / Dialog / Canvas

- Menu：Up / Down，Left / Right，Enter，Esc。
- Dialog：Tab 限制在 Dialog 内；初始焦点落在标题后第一个安全输入，危险按钮不自动获焦。
- Preview：Left / Right 前后项，`+` / `-` 缩放，`0` 适合窗口，`1` 1:1，Esc 返回。
- Moodboard：方向键移动，Shift 加速，Ctrl / Shift 按设计系统统一修饰；所有画布编辑进入 Undo 栈。

快捷键不得只出现在文档中；Menu、Tooltip 或快捷键帮助页应可发现。

## 04 拖拽

### 4.1 可拖对象

- 图片 / 素材；
- 文件与文件夹；
- 素材库集合、Tag 目标与灵感托盘；
- Moodboard 元素；
- 排期对象（仅在规则允许且结果明确时）。

### 4.2 拖拽阶段

1. Pointer Down：保持当前选择规则；
2. Drag Start：超过系统阈值后显示预览与数量；
3. Drag Over：合法目标使用 `Border.Strong` / Accent 细框；非法目标显示禁止和原因；
4. Drop：先验证目标、文件影响与冲突，再执行；
5. Result：就地更新，必要时 Toast，并提供 Undo。

### 4.3 文件安全

- 默认导入为引用或安全复制，不静默移动原文件。
- 拖入文件夹时明确是“创建引用”“复制到库”还是“加入集合”。
- 拖出应用不自动生成文件，除非用户明确选择导出语义。
- 从集合移除不等于从磁盘删除。
- 移动、覆盖、回收站与永久删除必须在 Drop 前明确影响。
- 拖拽大量文件进入后台任务，允许取消并显示阶段。

### 4.4 画布

Moodboard 拖拽支持吸附、对齐、层级与边缘自动滚动；参考线只在拖动时出现。缩放与平移不能误触对象移动。按 Esc 取消当前拖拽并恢复起始状态。

## 05 焦点

- 键盘焦点始终可见，使用 2 DIP Focus token，不与 Hover / Selected 混淆。
- 导航后焦点移动到页面 Heading 或主要画布，不停留在已消失控件。
- Drawer / Dialog 关闭后焦点返回触发者。
- Popover 和 Menu 关闭后返回原控件。
- 不可见、禁用、装饰元素不进入 Tab 顺序。
- Tab 顺序遵循视觉顺序：标题 → 工具 → 内容 → Inspector → Footer。
- 图片网格采用方向键空间导航，避免为每个缩略图内部的每个图标建立冗长 Tab 链。
- 焦点进入图片时，可访问名称至少包含文件名、序号、选择 / 评分和缺失状态。

## 06 Loading、Empty、Error、Success

### 6.1 Loading

- 不显示空白或纯 Spinner；保留页面结构与内容尺寸。
- 图片：中性占位 → 低清 / 代理 → 完整缩略图，使用轻柔渐显。
- 页面已有内容刷新时保留旧内容并显示局部进度，不把整个工作区清空。
- 0—2 秒只显示轻量进度；超过 2 秒显示阶段；超过 10 秒提供取消、后台执行或原因说明。
- 屏幕阅读器只播报有意义的阶段变化，不持续重复百分比。

### 6.2 Empty

空状态回答：

1. 当前区域是什么；
2. 为什么为空；
3. 用户下一步可以做什么；
4. 涉及文件时，原文件是否安全。

示例：“还没有导入照片。选择一个文件夹开始浏览；Pixel Tart 默认不会移动原文件。”

禁止只写“没有数据”“暂无内容”，禁止用假项目或假统计填满。

### 6.3 Error

错误必须提供：

- 原因：用用户能理解的第一层语言；
- 影响：哪些照片 / 任务受到影响，源文件是否安全；
- 解决方式：重试、重新定位、修改设置或查看详情；
- 技术详情：折叠、可复制、脱敏。

多文件任务显示成功、失败、跳过数量；允许只重试失败项。输入保存失败时保留用户输入。

### 6.4 Success

- 使用 3—5 秒轻量 Toast；Hover 或键盘焦点时暂停消失。
- 文案说明结果，不只写“成功”。
- 可撤销操作附“撤销”；撤销后给出轻量确认。
- 需要继续下一步时，下一步动作位于原上下文，不塞进巨大成功弹窗。

## 07 Undo、确认与危险操作

| 风险级别 | 示例 | 交互 |
| --- | --- | --- |
| 可立即恢复 | 评分、Tag、画布移动、集合排序 | 直接执行 + Undo |
| 可恢复但影响较大 | 批量归档、从集合移除 | 影响数量 + 执行 + Undo |
| 外部副作用 | 复制、导出、上传、移动文件 | 预览目标与冲突；任务反馈 |
| 破坏性 | 回收站、覆盖、永久删除 | 明确确认、影响、不可恢复性；危险按钮 |

- 确认用于风险，不用于普通导航。
- 禁止连续确认弹窗。
- 永久删除不能作为默认 Delete 行为。
- Undo 入口在动作后的上下文和 Toast 中可发现；不能只靠 Ctrl+Z。

## 08 动画

Pixel Tart 动画的感觉是照片显影：慢、克制、连续，但不能拖慢专业操作。

### 8.1 允许

| 动画 | 时长 | 用途 |
| --- | ---: | --- |
| Micro Fade | 120ms | Hover、图标状态 |
| Standard Fade | 160ms | Menu、Tooltip、局部内容 |
| Surface Move + Fade | 180—220ms | Drawer、轻量 Panel |
| Thumbnail Develop | 180—280ms | 低清到清晰的渐显 |
| Layout Move | 180ms | 排序、筛选后的可追踪移动 |

使用标准 EaseOut；动画只作用于 Opacity 和必要的短距离位移。高频键盘导航可即时响应，不强制播放完整动画。

### 8.2 禁止

- 弹跳、弹簧、回弹；
- 夸张缩放、卡片翻转、3D 旋转；
- 游戏化粒子、庆祝动画、连续脉冲；
- 改变图片比例或让图片越过其他内容；
- 大面积颜色扫过；
- 无状态意义的循环动画；
- 多个区域同时入场。

### 8.3 Reduced Motion

减少动效时取消非必要位移、缩放、布局过渡和循环；保留即时状态变化与短淡入。功能不能依赖动画才能理解。

## 09 响应式与屏幕

### 9.1 必须支持

- Windows 缩放：100%、125%、150%、200%；
- 分辨率：1920×1080、2560×1440、3840×2160；
- 最低有效工作窗口：1280×720；
- 21:9 与更宽屏幕。

175% 可作为额外回归点，但不能代替要求的四档。

### 9.2 布局策略

- 使用 DIP、Min / Max 与内容驱动，不用设备像素定位。
- 中间画布优先获得剩余宽度。
- 宽度不足时：先减少空白 → 折叠 Inspector → 收起左栏 → 将低频工具移入菜单；不缩小正文。
- 高度不足时保留标题、画布和主动作，辅助信息进入滚动或 Drawer。
- 超宽屏不把所有内容横向拉满：图片画布可扩展，正文与表单保持舒适行宽，Inspector 有最大宽度。
- 4K 不自动显示更多控制器；允许显示更大、更清楚的图片。
- 固定 Footer / 浮层必须避让 Windows 任务栏和系统边缘。

### 9.3 验收

每个页面在上述组合中检查：无文字重叠、无关键裁切、无不可达按钮、无双重滚动、焦点可见、菜单边缘避让、图片比例正确。不得以截图缩放伪装 DPI 验收。

## 10 多容器关闭顺序

Esc 和点击外部遵循单一关闭权：

1. 输入候选 / 小型 Popover；
2. Context Menu / Menu；
3. 临时工具浮层；
4. Drawer；
5. Dialog；
6. Preview；
7. 返回前一工作区。

一次 Esc 只关闭最上层。未保存更改与进行中的危险操作必须拦截并解释。点击图片画布不能穿透关闭浮层后又触发底层操作。

---

## 11 禁止模式

- Hover 承担唯一入口；
- 双击触发删除、覆盖或提交；
- Delete 直接永久删除；
- 拖拽静默移动原文件；
- 加载时清空全部内容；
- 错误只显示代码或“请重试”；
- 成功用巨大 Dialog 阻断；
- 关闭一个浮层同时误触底层；
- 焦点消失或关闭后无返回位置；
- 通过缩小字体适配 150% / 200% DPI；
- 弹跳、游戏化或无法关闭的循环动画。
