## 跨页检查

- 空间/密度：1920×1080 下两栏成立，列表 280 DIP，正文 940 DIP；不能由这组截图证明 125–200% DPI。下一轮单独测试。
- 字体层级/行高：40 DIP 标题、21 DIP 副标题、17 DIP 正文已建立层级；空段落导致额外大间隔，需修正。
- 按钮/边框：顶栏少量操作符合要求；新建和更多是字符图标，需换共享几何图标。
- 导航：当前 WrapPanel 在窄宽度会换行，需固定单行并压缩间距。
- 列表：长标题需要限两行；状态筛选复用真实 Button，不用默认 WPF 外观。
- 圆角/弹层：源码显示 Modal/Drawer 无统一圆角，更多菜单使用默认 ContextMenu；必须复用主题资源。
- Hover / selected / focus / popup / submenu / modal / empty：静态八图不能证明，标记 **待交互及补充截图验证**，不将源码推断写成视觉通过。
- 中文：页面主要中文，样例中的英文地名是内容而非 UI；编辑字段的自动化名存在属性名后备路径，需消除。
- 黑色边缘：旧图尺寸 1920×1080，但实际窗口客户区小于画布，底部有黑带；新截图应按真实客户区渲染并明确逻辑尺寸，不伪造桌面截图。
- PDF：当前生产导出 144 DPI 整页栅格；不满足本轮质量要求。先审查现有依赖，再选择可维护路径，明确是否可选中文本。
