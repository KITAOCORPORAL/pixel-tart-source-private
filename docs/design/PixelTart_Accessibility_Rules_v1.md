# Pixel Tart Accessibility Rules v1.0

## 1. 文本与对比度

普通文本不小于 11 DIP。正文与背景目标对比度不低于 4.5:1，大字号或粗体不低于 3:1。禁用态仍需可辨认，但不得与可交互态混淆。

颜色不能是唯一状态通道。日历状态同时提供文本、可访问名称或详情；关闭档期同时提供锁图标；错误和警告同时提供文字。

## 2. 键盘

所有操作必须可通过键盘完成。Tab 顺序遵循视觉顺序；Enter 执行默认动作；Space 切换选择；Esc 关闭 Popup、Drawer 和非破坏性 Modal。焦点离开 Modal 后返回触发控件。

不得移除焦点可视化而不提供等价替代。焦点边界使用 Primary 或系统高亮色，并与普通 Hover 区分。

## 3. 可访问名称

纯图标按钮必须设置 AutomationProperties.Name。复杂状态控件提供简洁 HelpText。日期格的可访问名称至少包含完整日期、排期数量、主要状态和关闭状态。

文件、客户和财务隐私内容不得为了可访问性而写入日志；Automation 名称只在当前进程 UI 树中提供必要信息。

## 4. DPI 与窗口

必须验证 100%、125%、150%、175%、200% DPI，以及 1280×720、1280×768、1366×768、1440×900、1600×900、1920×1080、2560×1440。验收标准是无裁切、无重叠、主操作可达且不缩小字体。

## 5. 动效

常规反馈 120–180ms。Reduced Motion 下取消非必要位移、缩放和循环动画，保留即时状态变化。加载状态不能仅靠动画表达。

## 6. 屏幕阅读和朗读顺序

标题先于工具栏，工具栏先于内容，内容先于状态和 Footer。浮层打开时限制朗读范围，关闭后恢复主上下文。错误信息使用适当 LiveSetting，但避免重复播报进度。

## 7. 输入与错误

标签不得只依赖占位文本。错误应指出字段、原因和下一步；保存失败必须保留输入。不可用操作应说明原因，而不是静默禁用。

## 8. 高对比度

HighContrast 使用 Windows 系统颜色。今天、选中、焦点、关闭档期和五种业务状态必须在不依赖细微色差的情况下仍可区分。
