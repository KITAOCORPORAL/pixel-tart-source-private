# Asset Library Eagle parity matrix

RC8 baseline: `integration/pixel-tart-developer-preview`. Eagle behavior is based on the checked-in research under `docs/product/eagle-reference/`; this matrix describes Pixel Tart's own implementation and keeps photography workflow fields distinct.

| Eagle capability | Pixel Tart current | Pixel Tart target | Status |
|---|---|---|---|
| Library tree | Three-pane organization pane with system collections and folder tree | Compact expandable library/folder hierarchy with recent libraries | PARTIAL |
| Folder | Create, rename, move, promote and archive/recover commands | Eagle-density folder tree with drag/drop membership | PARTIAL |
| Smart Folder | Query-backed smart folder editor and organization list | Saved conditions with visible match count and safe loading state | PARTIAL |
| Tag | Tag groups, selection/exclusion query model and tag manager | Grouped selector with recent/recommended sections | PARTIAL |
| Filter | Query composer, ranges, tags, folders and metadata | Compact anchored filter popover with persistent conditions | PARTIAL |
| Search | Debounced search field and P3 query document | Search-first toolbar with scoped field selector | PARTIAL |
| Density | Live thumbnail slider preserves selection and layout anchor | Eagle-like small-to-large density continuum | DONE |
| Layout | Grid, Masonry, Justified and List | Eagle-like image wall with stable anchors | DONE |
| Inspector | Single/multi selection metadata, tags, rating and capture info | Add project, booking, client and retouch/delivery workflow fields | PARTIAL |
| Context Menu | Selection-aware layered menu with organize, visual tools, tray, archive | Eagle grouping: view, organize, tags, folders, create, project, export, danger | PARTIAL |
| Preview | Inline thumbnail and external/open commands | Dedicated image/video viewer with source-safe navigation | PARTIAL |
| Import | Reference/managed import services and task bridge | Single primary import action with duplicate and progress feedback | DONE |
| Export | Export commands and CSV/report plumbing | Grouped export submenu with package, file and metadata targets | PARTIAL |
| Trash | Lifecycle model and recoverable operations | Full restore/conflict handling and explicit permanent delete | PARTIAL |
| Archive | Archive/recover command contract | Symmetric archive collection and inspector state | PARTIAL |
| Multi-select | Extended selection, marquee and batch inspector | Stable multi-select across filtering, paging and context menus | DONE |
| Drag Drop | Source, folder and tag drop behaviors | Eagle-like edge/target feedback with safe membership changes | PARTIAL |

Not planned in RC8: Eagle branding/assets, AI search, browser clipper, moodboard editor and Planning Center implementation.
