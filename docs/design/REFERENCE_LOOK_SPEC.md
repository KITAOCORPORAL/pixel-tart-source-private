# Project Look 产品规格

## 目标

Project Look 是项目级、可编辑的视觉参考参数，不是导出的新图片。它把素材库、灵感板或自由画布的分析结果连接到现场监看。源照片始终不变。

## 模型

- 一个项目可保存多个 Look，并可指定默认 Look。
- Look 由名称、可选项目、一个或多个来源、参数、版本和时间组成。
- 素材来源保存素材库与素材稳定身份；外部来源保存安全引用和内容指纹，不向 JSON 写入大图。
- 多来源权重必须为非负且总和大于零；持久化前归一化为 1。
- 参数范围均为 0–100：仿色、影调、色彩、对比度、饱和度、肤色保护、高光保护。

## 行为

- 创建：素材库选中项、灵感板或自由画布分析结果均可创建 Look。
- 管理：支持新建、重命名、复制、删除、设为项目默认。删除 Look 不删除素材。
- 输出：只产生参数和内存监看图，不生成或覆盖 JPG/RAW。
- 影调为 0 时不应用参考影调；仿色为 0 时输出字节与输入代理图一致。
- “肤色保护”明确为启发式范围保护，不宣称人脸或皮肤语义识别。

## 色彩边界

输入代理图按已有监看解释进入统一工作链，在感知 Lab 空间完成有界的影调/色彩映射，再经过可选 LUT 和现有显示变换。产品语言为“现场监看仿色”，不描述为 RAW 最终调色。

## 非目标

本版不做 AI 语义匹配、ONNX 肤色分割、RAW sensor-native 显影或 LUT 导出。
