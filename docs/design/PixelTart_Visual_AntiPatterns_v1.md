# Pixel Tart Visual Anti-Patterns v1.0

以下模式在 Pixel Tart A-v2 中明确禁止：

1. 大面积高饱和色卡片或渐变英雄区。
2. 将页面设计成 ERP、SaaS 管理后台、数据大屏或赌场式仪表盘。
3. 同一工作区出现两个以上 Primary。
4. 正文或关键说明小于 11 DIP。
5. 为塞入内容而缩小字体、控件或点击区域。
6. 超过两层的嵌套滚动。
7. 空表格、空网格和无意义的大块黑色区域。
8. 将英文枚举直接显示给用户。
9. 同一业务状态在不同页面使用不同颜色。
10. Hover 造成大面积亮度或色相跳变。
11. 依赖 Tooltip 承载关键操作、安全说明或错误恢复。
12. 每一段内容都套卡片、边框和 Badge。
13. 卡片套卡片以及用粗边框代替信息层级。
14. 手机应用式巨大圆角、胶囊按钮和过度悬浮。
15. 日历只在底部画状态线，导致日期状态难以识别。
16. 使用圆点代替可识别的 Pin 图钉。
17. 今天、选中、关闭档期覆盖或替换业务状态色。
18. 独立蓝色 Windows 标题栏破坏应用主题。
19. 文字重叠、裁切后无 Tooltip、按钮被浮层遮挡。
20. 浅色资源泄漏到深色主题或硬编码白色背景。
21. emoji 与矢量图标混用。
22. 为不同页面临时发明相近按钮、卡片和状态组件。
23. 把天气、人员、财务、文档等所有信息永久展开。
24. 用统计卡和图表抢占照片、排期或任务本身。
25. 用假生产数据、假联机状态或假上传结果填充界面。

代码评审发现上述模式时，应优先回到 token、容器规则和组件目录修正，不得新增另一个局部例外掩盖问题。
