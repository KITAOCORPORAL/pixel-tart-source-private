# Pixel Tart Page Design Principles

状态：Design Constitution v1.0  
目标：让每个模块保留自身工作节奏，同时共享“数字暗房”的同一视觉与交互语言。

---

## 01 通用 Workspace Layout

```text
┌────────────────────────────────────────────────────┐
│ Top Bar：面包屑 / 当前项目 / 搜索 / 全局任务         │
├──────────┬───────────────────────────┬─────────────┤
│ Left     │ Canvas                    │ Inspector   │
│ 导航分类 │ 当前摄影工作的视觉主体       │ 当前选择信息  │
│ 可折叠   │ 唯一主要滚动区              │ 可折叠       │
└──────────┴───────────────────────────┴─────────────┘
```

全局约束：

- 中间 Canvas 永远获得剩余空间；
- 左栏只放导航 / 分类，右栏只放当前上下文；
- 无当前选择时 Inspector 收起或显示极轻量提示，不保留重型空面板；
- 一个页面一个 Heading、一个主操作、一个主滚动区；
- 页面不为“看起来完整”注入假图片、假项目、假任务或假统计；
- 页面状态使用统一 Loading / Empty / Error / Success 模式。

## 02 工作台

### 感觉

摄影桌：用户回到这里能看到正在进行的作品、下一场拍摄和最近触碰的照片。

### 主体

- 首要：继续当前项目 / 最近拍摄故事，使用真实项目封面或接触印相式缩略图；
- 次要：今天与未来 7 天的拍摄安排；
- 辅助：进行中的任务和最近项目；
- 工具入口低权重，不做一墙快捷按钮。

### 结构建议

主画布以“继续工作”开场；项目与照片占主要面积。右侧可显示今天排期和运行中任务，但内容为空时收起。数据只回答“下一步做什么”。

### 禁止

- 大量统计卡、图表、四宫格指标；
- 用 0、0、0、0 填满空工作台；
- 同时展示项目概览、处理任务、日历、任务中心、提醒和所有工具；
- 把工作台叫 Dashboard 或让它像经营后台；
- 无照片、无项目封面的纯文字管理首页。

## 03 工作日历

### 感觉

拍摄计划墙：日期是故事入口，不是企业排班格。

### 主体

- 月 / 周 / 日视图共享状态与选择语义；
- 日期格显示日期、最多必要的拍摄故事和溢出数量；
- 点击日期打开当天故事，点击拍摄进入详情；
- 项目图片或封面可在日 / 详情视图出现，月视图保持清楚；
- 金额、人员、文档和天气按需进入详情，不永久塞入日期格。

### 状态

业务阶段使用集中五色；今天、选中、关闭、冲突分别用轮廓、锁、图标和文字表达。状态不只靠颜色。

### 禁止

- 企业排班表、工时表或 CRM 密度；
- 日期格放完整客户资料、金额与操作按钮；
- 底部一条难辨识的色线作为唯一状态；
- 点击日期只弹出“数据库记录”；
- 月、周、日各自定义状态颜色。

## 04 素材库

### 感觉

数字暗房与档案馆：观看、比较、组织和找回影像。

### 主体

- Gallery 至少获得窗口内容区 65% 的宽度；在 1920 宽舒适状态目标为 70% 以上；
- 左栏包含文件夹、集合、智能文件夹与 Tag，可独立收起；
- 右栏是当前选择 Inspector，无选择时收起；
- 搜索、视图、排序与缩略图尺寸留在轻量顶栏；高级筛选进入折叠区 / Drawer；
- Grid、Masonry、Justified、List 共用选择、滚动锚点、缩略图与 Context Menu。

### Thumbnail / Gallery

保持比例，不强裁切；横竖混排；图间有 8—16 DIP 呼吸空间；Metadata 按当前任务减量。双击进入沉浸 Preview，Viewer 独立于 Inspector。

### 禁止

- 文件列表作为默认素材体验；
- Inspector 永久展开所有分析、筛选和任务控件；
- 图片上覆盖大面积评分、Tag、路径和状态；
- 顶部多排筛选持续压缩 Gallery；
- 未实现能力作为大量禁用按钮和菜单项出现；
- 用不同局部色板构成第二套主题。

## 05 灵感托盘

### 感觉

编辑桌上一叠临时参考照片：快速收集、重排、比较，再送往情绪板或策划。

### 主体

- 必须显示图片缩略图；不得退化为文件名列表；
- 允许横向胶片带、底部抽屉或独立轻量工作区，图片仍是主体；
- 支持拖入、拖出、重排、多选、移除与清空；
- 显示来源失效、离线和重复状态，但不复制或修改原文件；
- “从托盘移除”支持 Undo，不等于删除素材。

### 生命周期

托盘是临时集合，但需明确持久化与清空规则；用户把内容送入情绪板 / 策划后，不自动清空，除非主动选择。

### 禁止

- 文件列表、表格、纯 Tag 列表；
- 把托盘做成任务中心；
- 每张图永久显示一排按钮；
- 用无图标 / 无缩略图的计数代替内容。

---

## 06 情绪板

### 感觉

摄影墙：自由、空间化、可以退后观看整体关系。

### 主体

- 无限或足够大的自由画布；
- 图片自由移动、缩放、旋转、分层、成组；
- 支持文字注释、色块与参考线，但图片优先；
- 画布平移 / 缩放、框选、吸附、对齐和层级操作一致；
- 全部结构编辑可 Undo / Redo；源素材保持不变。

### 工具

工具栏保持最少；选中元素时显示上下文工具。缩略导航、图层与 Inspector 默认可收起。演示模式隐藏 Chrome，只显示画布。

### 禁止

- 固定列卡片墙；
- 用表单字段描述情绪板；
- 文字、标签和控制器比图片更大；
- 删除画布元素时删除素材库源文件；
- 自动排版覆盖用户自由布局。

---

## 07 策划中心

### 感觉

拍摄前的创作空间，不是项目管理表单。

### 内容

- 概念；
- 场景；
- 灯光；
- 造型；
- Shot List；
- 参考图。

### 结构

以创作章节或画布组织，不把六部分都做成 Dashboard Card。参考图持续可见；概念和笔记保持舒适行宽；Shot List 是可执行的拍摄序列，可与参考图关联。右侧 Inspector 显示当前 Shot / 图片 / 场景细节。

### 交互

素材可从素材库和灵感托盘拖入；稳定引用失效时提示重新定位，不复制用户原文件。章节排序、Shot 调整和引用移除均支持 Undo。

### 禁止

- 六个等权统计卡或六张大表单卡；
- 参考图缩成附件列表；
- 把概念、场景、灯光、造型全部强制成数据库字段；
- 在未实现解析 / 持久化前显示可用入口；
- 长期 Modal 承担完整策划工作。

---

## 08 联机拍摄

### 感觉

片场监看台：最新照片最大、状态可靠、操作极少。

### 主体

- 最新照片 / 当前选片占主体；
- 底部或侧边胶片带显示近期照片；
- 连接、写入、代理、色彩与磁盘状态集中在安静状态区；
- Histogram、LUT、评分和客户屏控制按需打开；
- 客户屏默认只展示照片与允许公开的最少信息。

### 安全

明确相机 / 看守文件夹来源、文件落盘阶段、复制状态与断连影响。加载未完成不展示半写入文件；错误说明源文件安全与恢复路径。

### 禁止

- 控制面板包围照片；
- 将每个技术参数永久展开；
- 用彩色连接灯污染图片观看；
- 客户屏暴露路径、客户隐私、任务诊断或未允许 Metadata；
- 连接动画、波形或游戏化“拍摄成功”效果。

---

## 09 在线选片

### 感觉

私人看片室与接触印相：观看、选择、沟通、交付，避免网盘和电商感。

### 主体

- 项目封面与 Gallery 为主；
- Pick、评分、备注与选择进度保持轻量；
- 桌面端清楚区分本地状态、待上传、同步中、客户已选与冲突；
- 导出 / 同步只在真实 Provider 和结果可用时出现；
- 离线或 Provider=None 是可解释状态，不伪装成功。

### 禁止

- 素材下载站式卡片和大下载按钮；
- 销售漏斗、转化率、客户画像 Dashboard；
- 每张图片覆盖上传 / 下载 / 分享 / 删除按钮；
- 本地 Pick 与云端客户选择使用无法区分的同一标记；
- 用禁用导出按钮暗示尚未实现能力。

---

## 10 项目历史

### 感觉

档案馆：通过时间、封面与项目故事找回过去工作。

### 主体

- 默认用项目封面 / 接触印相、日期、项目名与阶段浏览；
- 支持时间线、搜索、筛选与必要的列表模式；
- 表格只用于批量核对，不作为唯一默认视图；
- 归档与删除分离，默认可恢复；
- 项目打开后回到离开时的工作上下文。

### 禁止

- 只有 DataGrid、状态列和操作列；
- 把选片数、匹配数、复制数做成主要视觉；
- 每行永久放“打开 / 导出 / 归档 / 删除”按钮；
- 使用无图标、无封面的数据库记录感。

---

## 11 摄影收支

### 感觉

工作室账页：私密、克制、与拍摄项目关联，而非经营数据大屏。

### 主体

- 按时间与项目浏览收入、支出、应收与已收；
- 关键总额使用清楚的排版和单一摘要，不铺满 KPI 卡片；
- 表格允许排序、筛选和导出；行内编辑克制，详情进入 Drawer；
- 默认保护金额与客户隐私，支持隐藏金额；
- 状态文字明确“待收 / 已收 / 退款 / 支出”，不只靠颜色。

### 禁止

- 企业 BI 图表、增长率、销售排行榜；
- 红绿大色块支配页面；
- 金额散落在工作台和日历每个角落；
- 日志、Toast 或客户屏泄漏完整金额与身份；
- 为填空而展示无行动价值的统计。

---

## 12 设置

### 感觉

暗房配置架：稳定、可搜索、改变影响清楚。

### 主体

- 左侧分类，右侧单列设置内容；表单保持舒适行宽；
- 每项包含标签、当前值、必要说明和影响范围；
- 即时生效与需重启明确区分；危险重置独立放置；
- 外观设置提供主题、字号、密度、侧栏和动效，但不能破坏品牌 / 状态语义；
- 文件位置、缓存和隐私设置明确数据影响。

### 禁止

- 所有设置都包成 Card；
- 多个品牌强调色改变全局状态语义；
- 用 Placeholder 代替标签；
- 自动保存失败后清空输入；
- 把开发诊断与普通用户设置混在一起；
- 连续弹窗确认普通设置。

---

## 13 所有弹窗、菜单与任务状态

### 弹窗

短时、单目标、固定 Header / Footer，一个 Primary；普通流程不连续弹窗。完整编辑优先 Page 或 Drawer。

### 菜单

对象菜单按查看、整理、创作、导出、危险操作分组；最多二级；支持边缘避让、键盘与 Hover 路径容错。

### 任务状态

长任务进入统一任务中心；显示阶段、进度、数量、文件安全、取消 / 重试。页面只显示当前工作相关的局部进度，避免同一任务在多个区域重复 Badge。

### Toast

成功轻量、错误可展开、可撤销动作提供 Undo。Toast 不遮挡主操作、底部胶片带或右侧 Inspector。

## 14 响应式优先级

| 可用宽度 | 策略 |
| --- | --- |
| 1280—1439 | 左栏可收起，Inspector 变 Drawer，低频工具进菜单 |
| 1440—1919 | 标准三栏，Inspector 360—420 DIP |
| 1920—2559 | 三栏，Gallery 扩展；不增加工具密度 |
| 2560 及以上 / 超宽 | 图片更大、比较空间更多；正文与 Inspector 保持最大宽度 |

200% DPI 按有效 DIP 宽度套用同一策略。任何档位都不得出现文字重叠、关键动作裁切或把图片压缩成无法判断的小块。

## 15 页面交付定义

页面完成不等于“正常数据截图好看”。每页必须验证：

- Image First 比例与首要任务；
- Loading、Empty、Error、Success；
- Hover、Focused、Disabled、Selected；
- 鼠标、键盘、右键、拖拽；
- Undo 与危险确认；
- 100%、125%、150%、200% DPI；
- 1080p、2K、4K、超宽与 1280×720 最低窗口；
- Dark、Light、High Contrast；
- 无假数据、无死按钮、无源文件副作用。
