# Pixel Tart Component Guidelines

状态：Design Constitution v1.0  
目标：用少量稳定组件构成全部摄影工作区，降低按钮、卡片和状态噪声。

---

## 01 组件共同契约

每个交互组件必须提供：Default、Hover、Pressed、Focused、Disabled；选择类组件增加 Selected；异步组件增加 Loading、Empty、Error、Success。组件必须支持键盘、可访问名称、100%—200% DPI、长中文文案与 Reduced Motion。

默认尺寸：

| 类型 | 高度 | 说明 |
| --- | ---: | --- |
| 标准 Control | 38 DIP | 表单、主要动作 |
| 紧凑 Control | 32 DIP | 工具栏、Inspector；不用于危险确认 |
| Icon Button | 32 × 32 DIP | 图标 18—20 DIP，必须有 Tooltip 与可访问名称 |
| 列表 Row | 最小 42 DIP | 允许内容撑高 |
| 最小鼠标目标 | 32 × 32 DIP | 高频图像工具 |
| 推荐触控 / 大字号目标 | 40 × 40 DIP | 可访问模式 |

## 02 Button

### 2.1 类型

| 类型 | 用途 | 视觉 |
| --- | --- | --- |
| Primary | 当前容器的单一下一步 | Accent 实底 |
| Secondary | 需要稳定可见的常规动作 | 中性表面 + 细边框 |
| Ghost | 工具栏、低权重或上下文动作 | 透明；Hover 使用中性背景 |
| Danger | 破坏性动作与确认 | 默认红色文本 / 描边；最终不可逆确认可实底 |
| Icon | 高频且语义明确的图像工具 | 中性图标；Tooltip 显示名称与快捷键 |

### 2.2 规则

- 一个 Page、Drawer 或 Dialog 的当前视域最多一个 Primary。
- 按钮使用动词开头，如“导入照片”“创建拍摄”“导出选中项”。
- 同一工具栏可见按钮建议不超过 5 个；其余进入“更多”或对象菜单。
- 低频操作不永久占位；随选择出现的 Bulk Action Bar 优于一排禁用按钮。
- 处理中按钮保留原宽度，显示进度或“正在导入…”，避免布局跳动。
- 成功不把按钮变成永久绿色；使用轻量 Toast 或短暂图标反馈。
- 长期不可用或未实现功能不显示；因当前条件暂不可用时才禁用并解释原因。
- 不为每个功能定义颜色按钮，不使用胶囊按钮和夸张阴影。

## 03 Card 与 Panel

Pixel Tart 不鼓励大量 Card。合法 Card 只有：

1. **项目卡**：项目 / 拍摄故事是可独立进入的对象，可含主图、标题、阶段与下一步。
2. **图片卡**：缩略图及最小 Metadata；图片占主体。
3. **任务卡**：长任务的阶段、进度、失败与恢复动作。

其他内容使用：

- `WorkspaceSurface`：页面主体，不画卡片外框；
- `PanelSurface`：稳定的导航、Inspector 或局部分组；
- `Section`：仅靠标题、留白和 Divider 建立关系；
- `ElevatedSurface`：只给浮层。

规则：

- 禁止卡片套卡片；
- 不因“内容属于一组”就添加背景、边框与圆角；
- 图片卡不得强制统一为损害内容的封面比例；
- Card Hover 只改变边框或轻微背景，不整体上浮、发光或放大；
- 状态颜色不得填满 Card；
- 空 Card 应被 Empty State 替代或直接不渲染。

## 04 Tag、Badge 与状态

### 4.1 Tag

Tag 用于用户可理解的轻量分类：题材、人物、地点、风格、用途。Tag 可以筛选、添加、移除；默认使用中性背景，选中时使用 Accent Soft。

Tag 不能代替：任务状态、上传结果、文件安全、拍摄阶段、错误或权限。可编辑 Tag 必须明确移除行为，不以颜色承担语义。

### 4.2 Badge

Badge 只用于短、稀少、需要扫读的状态，如“离线”“缺失”“3”。同一对象最多 2 个可见 Badge；其余进入 Metadata 或 Inspector。禁止在导航、按钮和卡片上重复显示同一状态。

### 4.3 Rating / Pick / Pin

评分、选片与固定是摄影语义控件，应使用稳定图标与文字替代通道。Hover 不触发评分；评分必须通过明确点击或键盘完成，并支持 Undo。

## 05 Image Components

### 5.1 Thumbnail

- 默认 `Stretch=Uniform`，保持原始宽高比，不强裁切。
- 横竖图可在 Masonry、Justified 或自适应 Grid 中混排。
- 图片面积至少占图片卡可见面积的 75%。
- Metadata 位于图片外；仅选择框、评分和缺失图标可小面积叠加。
- 缩略图分阶段加载：占位 → 低清 / 代理 → 清晰图；尺寸稳定，不闪白。
- 缺失或离线显示中性占位与恢复动作，不伪造缩略图。

### 5.2 Gallery

- 默认 gap：12 DIP；紧凑比较模式最小 8 DIP；展示模式可为 16—24 DIP。
- 控制密度但不堆满屏幕；一屏应能辨认单张照片而非只看到色块。
- 用户调整缩略图尺寸时保持滚动锚点与选择。
- 批量操作通过选择状态与浮动 / 固定 Bulk Bar 表达，不在每张图放多个按钮。

### 5.3 Preview / Viewer

- 使用 `Background.Preview`；图片在可用区域内最大化，默认完整显示。
- 工具在移动鼠标或键盘操作时出现，静止后渐隐；文件安全和关键状态保持可达。
- 支持 1:1、适合窗口、缩放、平移、前后项、评分、Pick、对比与 Esc 返回。
- 不自动修改原图；编辑入口必须说明非破坏性状态。
- 信息面板默认可收起，不遮挡图片关键区域。

### 5.4 Moodboard Canvas

- 自由画布是主体，图片自由移动、缩放、旋转、分层和成组。
- 文本是注释，不抢占图片；不把 Moodboard 实现成表格或卡片列表。
- 选框、参考线和吸附只在操作时出现；默认画面保持安静。
- 画布操作可 Undo / Redo，删除元素不删除源素材。

## 06 Navigation

- 一级导航只放稳定业务空间；本阶段不新增入口。
- 图标 20—22 DIP、统一线宽与圆角端点；同一图标不复用不同语义。
- 选中态用 Accent 细指示和中性背景，不整行高饱和填色。
- 导航 Badge 只显示确需处理的数量，不显示普通统计。
- 收起时保留 Tooltip 与可访问名称；不依靠用户记忆图标。
- 页面内分类属于左栏或 Tab，不升级为一级导航。

---

## 07 Menu

### 7.1 右键菜单结构

按以下固定次序分组，只显示适用于当前对象的动作：

```text
查看
  打开预览
  查看信息
整理
  评分 / 标签 / 移动 / 归档
创作
  加入灵感托盘 / 情绪板 / 策划
导出
  导出副本 / 清单 / 素材包
────────
危险操作
  从集合移除 / 丢到回收站 / 永久删除
```

### 7.2 行为

- 右键未选中对象时，先将其设为上下文选择；多选集合保持规则必须一致。
- Menu Item 使用动词；快捷键右对齐。
- 支持二级菜单，但最多两层；二级菜单打开有短延迟与鼠标路径容错。
- 菜单自动避让屏幕、任务栏、窗口边缘与 DPI 边界。
- Up / Down 导航，Right / Left 进入或退出二级菜单，Enter 执行，Esc 逐级关闭。
- 危险操作置底并分隔；不可逆动作必须二次确认。
- 不把整个未来路线图做成禁用菜单；未实现能力不显示。
- Menu 不承担一级导航、长表单或重要说明。

## 08 Dialog、Drawer、Popover 与 Tooltip

### 8.1 Dialog

- 用于短时、单目标、需要决定后返回原上下文的任务。
- Header 固定，Body 可滚动，Footer 固定；Footer 右侧最多一个 Primary。
- 不连续弹出业务 Dialog，不在 Dialog 上再开第二个业务 Dialog。
- Esc 关闭无未保存内容的 Dialog；有更改时询问保存、放弃或继续编辑。
- 关闭后焦点返回触发控件。
- 普通错误不用巨大弹窗；可恢复错误优先就地提示或 Toast + 详情。

### 8.2 Drawer

- 用于拍摄日期详情、照片 Inspector、快速编辑和任务详情，同时保留主画布上下文。
- 推荐宽度 360 / 420 / 480 DIP；小屏可覆盖内容，大屏占用布局空间。
- 没有上下文时收起，不展示永久空 Inspector。

### 8.3 Popover / Tooltip

- Popover 用于小型选择或短说明，不承载长流程。
- Tooltip 只回答“这是什么 / 快捷键是什么 / 为什么暂不可用”，1—3 行，不抢焦点且延迟出现。
- 安全规则、删除影响、错误恢复不能只放 Tooltip。

---

## 09 Inputs 与筛选

- Label 永久可见；Placeholder 是示例，不是标签或默认值。
- 输入高度、圆角、边界与焦点统一；Dark 主题禁止白色输入块。
- 搜索与筛选分离：搜索处理关键词，Filter 处理结构化条件。
- 活动筛选以可移除摘要显示；高级筛选折叠，不永久占用 Gallery 高度。
- 日期、金额、路径与格式错误就地说明，不清空用户输入。
- ComboBox 不显示内部英文枚举；多选筛选使用明确列表，不假装单选下拉。

---

## 10 Table 与列表

- 仅当用户需要按字段扫描、比较或排序时使用 Table。
- 项目历史优先项目 / 时间线视图；财务记录可以 Table，但摘要不做 Dashboard 大卡。
- 行操作默认隐藏，在 Hover / Selection 或右键菜单出现。
- 表头可固定，主要滚动区唯一；避免横向和纵向多层嵌套滚动。
- 列宽内容驱动，支持 200% DPI；操作列不长期堆按钮。
- 空表不绘制大量空行，用 Empty State 替代。

---

## 11 状态组件

### Loading

- 不显示空白；保持内容骨架和尺寸稳定。
- 图片使用渐进缩略图；列表使用轻量骨架或已有内容 + 局部进度。
- 超过 2 秒说明阶段，超过 10 秒提供取消或后台执行方式。

### Empty

由标题、说明与可选单一动作组成，回答：这里是什么、为什么为空、下一步是什么。禁止只写“没有数据”“暂无内容”。

### Error

必须包含：原因、影响、解决方式。文件任务额外说明源文件是否安全、成功 / 失败数量与可否重试。技术详情折叠显示，可复制且脱敏。

### Success

使用轻量 Toast，说明完成结果；可撤销操作附“撤销”。不显示巨大成功 Dialog，不让 Toast 永久遮挡工作区。

### Task Card

显示任务名、阶段、进度、成功 / 失败数量、继续 / 暂停 / 取消能力和失败恢复。任务颜色表达状态，不表达工具类型；完成后自动降噪并进入历史。

---

## 12 禁止模式

- 所有内容都包 Card；
- 每个功能一个彩色按钮；
- 工具栏超过 5 个同权重按钮；
- 未实现功能长期以禁用按钮 / 菜单展示；
- 图片卡上覆盖大面积信息和状态色；
- Dialog 连环弹出；
- Hover 放大、弹跳、发光；
- 用 Tag 代替业务状态；
- 表格操作列堆满按钮；
- 页面复制组件样式形成私有版本。

---

## 13 实现契约

共享目录按 `Design Tokens / Components / Patterns / Layouts / Pages` 管理。业务页面只组合组件并传入内容、状态和命令，不重新定义颜色、字号、圆角、动效或交互状态。任何新组件必须先补齐状态矩阵、键盘契约、DPI 截图和复用理由。
