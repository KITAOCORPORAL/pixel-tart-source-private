# Pixel Tart Page Design Spec v1.0

## 1. 全局页面骨架

```text
┌─────────────────────────────────────────────────────────┐
│ Top Bar：当前工作上下文 / 搜索 / 一个主操作 / 全局任务 │
├──────────┬─────────────────────────────┬────────────────┤
│ Navigation│ Canvas                      │ Inspector      │
│ 去哪里     │ 当前摄影工作的视觉主体        │ 当前选择的细节   │
│ 可折叠     │ 唯一主要滚动区               │ 可折叠          │
└──────────┴─────────────────────────────┴────────────────┘
```

所有页面遵循：一个 Page Title、一个主要工作对象、一个 Primary Action、一个主滚动区。Navigation 只回答“去哪里”，Inspector 只回答“当前选中了什么”。无选择时 Inspector 收起。Loading、Empty、Error、Keyboard 必须在设计稿中与 Default 同级呈现。

## 2. 工作台

### 定位

不是 Dashboard，而是摄影师桌面。用户回来后能立刻继续一项真实工作。

### 信息优先级

1. 继续当前项目或最近拍摄故事：真实封面/接触印相式预览；
2. 最近素材：可直接继续观看、初选或整理；
3. 今天与未来 7 天的拍摄/交付事项；
4. 正在处理的长任务，只在存在时出现；
5. 工具入口进入命令或轻量菜单，不做快捷按钮墙。

### 布局

主画布以“继续工作”开始，项目与图片占最大面积。右侧窄区可承载今天的拍摄与运行中任务；为空时收起。空工作台只给一个创建/导入入口和简短引导，不显示 `0 / 0 / 0 / 0`。

### 禁止

统计卡墙、经营图表、四宫格指标、所有工具永久平铺、纯文字项目表、把页面称为 Dashboard。

## 3. 工作日历

### 定位

不是排班表，而是拍摄故事的时间入口。

### 核心关系

`日期 → Booking → Project → Asset`

日期先连接拍摄与作品，再连接客户、文档、金额和提醒。月/周/日视图共享相同选择与状态语义。

### 布局与交互

- 月视图：日期 + 最多必要的拍摄故事 + 溢出数量；
- 周视图：时间节奏、拍摄持续区间与冲突；
- 日视图：项目封面、代表图片、地点、Shot/准备项；
- 点击日期进入当天故事，点击 Booking 进入拍摄详情；
- 天气、文档、金额与人员按需进入详情/Inspector；
- 今天、选中、关闭、冲突分别使用轮廓、文字和图标，不只用颜色。

### 禁止

CRM 表格密度、完整客户资料塞进日期格、状态只靠底部色线、月/周/日各自定义颜色、点击日期只看到数据库记录。

## 4. 素材库

### 定位

数字暗房与个人影像档案馆。

### 布局

- Canvas / Gallery 至少占内容区 65%，1920 宽目标 70% 以上；
- 左侧 Navigation：文件夹、集合、智能文件夹、标签，可收起；
- 右侧 Inspector：当前选择的预览与 Metadata，可收起；
- 顶栏：搜索、排序、视图、缩略图尺寸、一个导入主操作；
- 高级查询、智能文件夹编辑、标签管理、批量分析进入 Drawer 或专门工作区；
- 底部只保留必要状态和快捷键提示，并可隐藏。

### 浏览

默认 Thumbnail Gallery，保持比例。Grid / Masonry / Justified / List 共用选择、滚动锚点、Context Menu 与 Thumbnail Provider。双击进入独立 Image Viewer。多选 Inspector 只显示共同属性和本次批量动作。

### 禁止

默认文件列表、右栏永久展开分析/查询/任务控件、图片覆盖路径和多排状态、顶部多排筛选、第二套局部配色、未实现能力长期灰置。

## 5. 灵感托盘

### 定位

不是收藏夹，而是编辑桌上一叠临时参考照片。

### 必须包含

- 视觉缩略图；
- 来源与失效状态；
- 标签；
- 项目关联；
- 拖入、重排、多选、移除、清空与 Undo；
- 送入灵感集、情绪板或项目策划的上下文动作。

### 表现

优先横向胶片带或底部抽屉，也可进入独立轻量工作区。图片保持主要面积，Metadata 随选择展开。“从托盘移除”不删除源文件；送出后不自动清空，除非用户明确选择。

### 禁止

AssetId 列表、表格、任务中心式状态、每张图永久按钮排、只有计数没有缩略图。

## 6. 情绪板 Moodboard

### 定位

不是 Card 列表，而是可以退后观看整体关系的摄影墙。

### 必须支持的设计契约

- 自由画布，图片可移动、缩放、旋转、分层、成组；
- 文字、色板、注释与参考线；
- 平移、缩放、框选、吸附、对齐与层级；
- Undo / Redo；
- 隐藏 Chrome 的演示/观看模式；
- 来源引用与失效重定位；删除画布元素不删除素材。

工具栏只保留选择、平移、添加等最小集合。选中元素后显示上下文工具，图层和 Inspector 默认可收起。

### 禁止

固定列卡片墙、表单字段模拟画布、自动排版覆盖用户布局、文字和控件比图片更大。

## 7. 策划中心

### 定位

不是表单，而是拍摄前的创作空间。

### 内容模型

- 概念；
- 场景；
- 灯光；
- 造型；
- Shot List；
- 参考图。

### 页面结构

以创作章节、画布或序列组织，参考图持续可见。概念文字保持舒适行宽；Shot List 是带视觉参考的拍摄顺序，可与场景、灯光和造型关联。当前 Shot/图片/场景的细节进入 Inspector。素材可从素材库和灵感托盘拖入，使用稳定引用。

### 禁止

六个等权 Card、六张大表单、把参考图缩成附件列表、把创作过程强制成所有字段必填、长期 Modal 承载完整策划。

## 8. 项目

### 定位

项目是一个持续发展的拍摄故事，不是一行数据库记录。

### 页面

- 项目索引：封面、名称、阶段、最近照片与下一行动；
- 项目详情：故事封面/代表作品、时间线、Booking、策划、素材、选片与交付；
- 归档项目：按时间、封面与客户/主题找回；
- 无封面时使用中性占位与“设置封面”，不使用假图。

项目阶段只辅助叙事，不以彩色状态卡占据主体。金额、内部 ID、路径与日志进入详情或 Inspector。

## 9. 联机拍摄

定位为片场监看台。最新照片最大，近期照片形成胶片带；连接、写入、代理、LUT 与磁盘状态集中到安静状态区。Histogram 和控制器按需展开。客户屏仅显示允许公开的图片和最少信息，不暴露路径、诊断或隐私。

## 10. 在线选片

定位为私人看片室与接触印相。Gallery 为主，Pick、客户选择、备注和同步状态保持轻量。本地 Pick、客户选择、待上传与冲突必须可区分。导出/同步只在真实 Provider 可用时显示，不伪装成功。

## 11. 设置、帮助与系统页

设置按用户目标而非技术模块分组；不展示内部架构术语。采用单列稳定表单 + 必要预览，不使用 Card 网格。帮助优先当前上下文、快捷键和恢复路径。授权/版本保持低权重，不占主导航视觉中心。

## 12. 跨页连续性

- 从日历进入项目时保留 Booking 上下文；
- 从项目进入素材库时保留项目筛选与返回位置；
- 从素材进入 Viewer、灵感托盘、情绪板和策划时保留选中对象；
- 返回后恢复滚动锚点、缩放与选择；
- 长任务进入全局任务中心，但结果回链到发起页面；
- 页面不通过复制文件来解决引用关系。

## 13. 参考方向（非复制模板）

- [Adobe Lightroom](https://www.adobe.com/products/photoshop-lightroom.html)：照片故事与简化编辑；
- [Capture One Pro](https://www.captureone.com/en/products/capture-one-pro)：色彩准确、快速预览、联机拍摄与可定制工作区；
- [Eagle](https://eagle.cool/en/)：视觉资产浏览与组织；
- [Milanote](https://milanote.com/product)：灵活视觉画布与创意工作室隐喻；
- 摄影画册与美术馆数字档案：序列、负空间、图注层级、准确来源信息。

参考只回答“为什么这样工作”，不得复制界面结构、组件造型、图标或品牌视觉。
