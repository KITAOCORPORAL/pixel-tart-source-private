# 拍摄参考执行规格

## 职责

拍摄参考只负责现场执行策划：灯位、姿势、分镜、造型和备注。它与负责颜色的参考模式分开，不构成完整 Planning Center。

## 数据

Shot 保存项目、顺序、名称、状态、备注、可选 Look 以及引用集合。状态为未开始、拍摄中、已完成。引用按灯位、姿势、分镜、造型、通用参考分类；优先保存素材库与素材身份，外部图片只保存 managed reference，不复制大图。

姿势状态为未拍、当前、已拍。完成当前姿势可自动把下一个未拍姿势设为当前。灯位、姿势与分镜可固定；固定只是状态，不改变源图。

## 现场行为

- 顶部显示 Shot 序号并支持前后切换。
- 切换同步替换引用和 Notes，并把 Shot 置为拍摄中。
- Shot 有 Look 时选用该 Look；否则由项目默认 Look 回退。
- 本版提供引用列表、Pose 完成和 Pin 数据链。居中 Quick Preview、独立可调固定参考面板和第二屏参考窗口仍为后续增量。

## 非目标

不创建第二套 Planning 数据模型，不实现完整策划编辑器，不虚构灯具、角度、高度或旗板信息；界面只呈现 Shot 数据实际包含的字段。
