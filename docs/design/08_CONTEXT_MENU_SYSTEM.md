# Pixel Tart Context Menu System v1.0

## 1. 原则

右键是当前对象的快捷工作流，不是功能垃圾桶。只显示对当前选择有效、用户能够理解且真实可用的动作。菜单不重复整个顶部菜单，不用禁用项预告未来功能。

## 2. 固定分组顺序

对象菜单按以下语义顺序排列，空分组不显示：

1. 查看
2. 整理
3. 创作
4. 项目
5. 导出
6. 危险操作

分组间使用 Separator；组内按频率与可逆性排序。常用默认动作可加粗或显示快捷键，但不得染成 Primary 按钮。

## 3. 查看

适用于阅读和定位，不改变内容：

- 在查看器中打开；
- 适合窗口 / 100%；
- 对比所选照片；
- 在文件位置显示；
- 查看 Metadata；
- 查看来源 / 引用位置。

双击默认动作应与首个“查看”动作一致。

## 4. 整理

适用于可撤销的资料组织：

- 评分 0–5；
- 添加/移除标签；
- 移入集合；
- 标记初选；
- 客户选择；
- 待精修；
- 已交付；
- 重新定位缺失文件。

摄影工作流状态必须有明确互斥/并存规则；菜单只展示当前可发生的状态变化，例如已在初选时显示“移出初选”。

## 5. 创作

未来支持、当前只定义：

- 加入灵感托盘；
- 加入灵感集；
- 加入情绪板…；
- 加入项目策划…；
- 设为视觉参考；
- 创建对比组。

带省略号的动作表示后续还需选择目标或填写信息；立即完成的动作不加省略号。

## 6. 项目

- 关联到项目…；
- 移出当前项目；
- 设为项目封面；
- 转到所属项目；
- 关联 Booking / Shot…。

“移出项目”只移除关系，不删除源文件；文案不得模糊。

## 7. 导出

- 导出副本…；
- 生成联系表…；
- 复制预览；
- 加入导出队列；
- 查看最近导出。

格式、尺寸、命名与目标位置属于后续步骤，不在一级右键菜单展开成几十项。长任务关闭菜单后进入任务中心。

## 8. 危险操作

- 从库中移除…；
- 移到回收站…；
- 永久删除…（仅在产品确有此能力且必要时）。

危险操作必须位于末组，和其他组至少一个 Separator；图标/文字可用 Error 色，但整组不铺红底。必须准确区分“移除引用”“移到回收站”“永久删除”，确认中说明影响对象、数量、源文件和恢复路径。

## 9. 不同对象的最小菜单

### 单张素材

查看 → 评分/标签/工作流状态 → 创作 → 项目 → 导出 → 危险操作。

### 多选素材

只显示全部选中项都适用的动作；标题或首项附近显示数量。混合状态使用“设为…”而不是不明确的 Toggle。批处理失败允许查看报告并对失败项重试。

### Thumbnail 空白区

只显示导入、刷新、粘贴（真实支持时）、新建集合/智能文件夹等画布动作；不得出现素材动作。

### Navigation 节点

打开、重命名、刷新、导出定义、从导航移除；文件夹与智能文件夹菜单必须不同，危险操作精确说明是否涉及磁盘。

### Moodboard 元素

置顶/置底、成组、对齐、复制样式、查看来源、从画布移除。删除画布元素不删除源素材。

### Project / Booking / Shot

打开、继续工作、关联素材、调整阶段、导出/归档；数据库内部动作不对用户暴露。

## 10. 尺寸与交互

- 宽 200–280 DIP，项高 32–36 DIP；
- 左侧 20 DIP 图标槽，右侧快捷键/子菜单槽；没有图标时仍保持对齐；
- Hover 使用 Elevated Surface，Pressed 不缩放；
- 键盘：Menu Key / Shift+F10 打开，方向键导航，Enter 执行，Esc 关闭；
- 关闭后焦点回到触发对象；
- 子菜单不超过一层，超过约 12 项使用 Picker/Dialog；
- 打开菜单前冻结选择快照，执行时验证对象仍存在；
- Loading 不让用户重复触发；结果交给 Toast 或任务中心。

## 11. 文案规则

动词开头，说明对象与影响：`从灵感托盘移除` 优于 `删除`，`在文件位置显示` 优于 `打开位置`。省略号只表示动作后还有一步。快捷键只显示已实现且全局一致的绑定。

## 12. 禁止

- 把所有命令复制到每个菜单；
- 三层以上子菜单；
- 大量禁用未来入口；
- 将设置、授权、帮助放入素材右键；
- 在中间夹入危险操作；
- 以图标颜色区分大量动作；
- 右键行为与工具栏同名动作产生不同结果；
- 未选择对象时沿用上一次选择的菜单。
