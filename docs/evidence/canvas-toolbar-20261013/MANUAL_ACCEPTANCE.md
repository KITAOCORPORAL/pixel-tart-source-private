# 人工验收（本轮全部 NOT_RUN）

不自动打开软件、不发送桌面输入、不改变系统 DPI。以下由用户在允许的机器上执行。

1. 从 RELEASE_IDENTITY 指定 EXE 启动，记录版本/哈希；首次导航到 Color Studio，无异常弹窗。不要用旧发布目录替代。
2. 加载自有 JPEG 和 RAW，使用 V 选择及分界线，H 左键平移，Space/中键临时平移，Z 点击及 Alt 点击缩放；双击适合。确认照片外空白点击不取色。
3. 并排比较右半边进行指针锚点缩放；Ctrl+0 适合，Ctrl+1 100%。100/125/150/200%物理DPI分别检查；RAW代理/分块状态不得被100%比例掩盖。
4. 聚焦文字、下拉框、滑块、曲线和胶片栏，V/H/Z/I/B不应抢夺输入。文本Ctrl+Z/Y只修改文本。
5. 专业调整栈先选颜色范围节点，点取样/I；Shift增加、Alt减少；Esc或切抓手不提交在途取样。完成一次取样后撤销/重做，保存工作文件和版本、关闭重开，导出验证同一结果。
6. 独立PV4/PV5/PV6版本：取样及旧调整栈撤销明确禁用；正常平移缩放比较可用；原版本恢复和全尺寸导出不变。
7. 先选择左右或并排比较，按住B显示原图，释放回前模式；点击原图锁定，再点击恢复。按住B后Alt-Tab/切图/卸载页面，不得卡原图。
8. 开始即时胶片生成时不能通过画布快捷键改变冻结定义；原有显影时长及最终像素不变。
9. 窄窗口工具带横向滚动可达，不遮照片。当前不是五组菜单的最终视觉还原；对照现有shots并记录剩余视觉差异。
10. 快速导出和Publishing分别输出PNG/TIFF与JPEG，核对处理定义和尺寸；本轮自动测试不能替代该实机流程。
11. WPS往返按 PLANNING_IMPLEMENTATION_BATCHES 执行；本轮只是拆分表，不能将现有受限DOCX称为完整Word兼容。

桌面首次启动、实机导航、物理DPI、视觉批准、WPS实际编辑导回：NOT_RUN。
