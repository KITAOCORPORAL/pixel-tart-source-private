# 许可与资料边界

本轮独立编写 WPF 接线及合成测试；未复制 Grok HTML/JS 实现、照片、外部纹理、图标资产或字体。复用仓库现有主题及依赖，未增加第三方包。

用户提供的参考 ZIP/PNG/Markdown/CSV 保留在原目录，仅记录 SHA 和需求映射，不将350MB压缩包或参考图片纳入提交。coverage派生表只用于本次开发追踪，不代表取得其他媒体商业许可。

不新增客户照片、生产数据库、凭据、构建二进制。测试使用两像素合成图；既有授权测试夹具不改动。Release只留本地忽略目录，交付证据只提交哈希和清单。

历史胶片、RAW、ICC及GPL外部研究许可边界不变；创作模拟不称为准确相纸标定。策划中心未来引擎/拼写字典/地图潮汐服务/字体嵌入须逐项核对许可，不能从当前拆分表推断已获许可。
