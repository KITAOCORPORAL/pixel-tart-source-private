# 关键复核与失败记录

- 阶段1发现实际仓库没有工具箱设备目录或稳定设备实体（搜索Equipment/Gear/器材/设备清单；仅有账目分类）。因此不制造导入成功：SourceCatalog+SourceId去重接口可测试，UI明确只提供手动设备编辑。后续接入真实工具箱目录才可验收导入。
- 阶段2复核：旧RTF编辑器卸载可在同文档重新渲染后覆盖程序化导入/撤销。已加render revision，旧实例回调不接纳；程序化保存暂停旧捕获。结构名称/动作离开前捕获进入原草稿门禁。
- 模式落盘失败时显式回退旧模式，并尝试更新恢复草稿，IO失败保留内存；预算缓存按项目过滤，避免显示上一项目金额。新资源编辑先在复制对象上校验，取消不写。
- DOCX输出限制每个列表项单段落+嵌套列表；复杂项拒绝而非抹平。导入其他编号格式、表内列表/嵌套表/合并格/域/批注等保持损失提示。WPS是否保持摄影表标记需实机验证，当前不保证。
- 一次自定义输出测试目录混入自包含运行时导致testhost启动中止：stage3-output-runtime-aborted.trx，总数0；不能写为测试通过。换独立正常testhost并只替换托管DLL，最终专项19通过。
- 原源码完整WPF测试运行期间没有覆盖它的测试目录；最终源码重建使用隔离目录。最后发布组件完整WPF从独立testhost执行，Release组件哈希逐一核对。
