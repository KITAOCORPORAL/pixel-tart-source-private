# 布局、数据与处理设计

状态：实施设计，不是完成证据。

## 界面

按本次原图：左侧参考/3D色彩/胶片预设/节点四模式；中央完整照片与一行视口工具；右侧顶部RGB与亮度两张直方图，下面3D色彩/色彩/色阶/曲线/细节/胶片/创意七页。底部一行动作和紧凑纯图胶片条。中文优先；内部模式与保存键使用稳定标识。

左右栏使用各自滚动。狭窄工作区允许单独收起任一栏，中央照片保有可编辑宽度。直方图与右编辑栏一起收起，不移动到中央。参考图片只读，沿用ReferenceNavigator。

## 处理链

复用ColorAdjustmentStack以及既有方案Version2。枚举只在尾部增加，旧Develop节点保留旧算法，避免旧项目被静默重新解释。新节点：WhiteBalance、BasicTone、ColorBalance、Levels、Curve、Details、SkinTone。每个参数的key/range/default/step由ColorStudioToolCatalog定义，UI和Core校验共享语义。

默认新节点按白平衡→基本影调→颜色范围/肤色/平衡→色阶/曲线→细节→胶片顺序插入；用户在Nodes中更改后的保存顺序具有权威性。预览和导出从同一冻结栈渲染。输入ICC一次转换sRGB；目前工作输入是解码后的display-referred sRGB，RAW并非传感器域曝光恢复。全部输入升float处理中间值，输出阶段再量化。空间滤镜按参考长边定义半径。

色阶与曲线独立作用RGB或单通道。肤色均匀化用OKLab色相/色度/明度及平滑范围；不得把参考仿色strength冒充曝光。所有新参数支持数值验证、单组复位、同一节点undo/redo及保存。

## 3D与分析

真实样本和距离维持OKLab D65。球形采用显式可逆的sRGB色域归一化显示（详见SPACE_AUDIT.md），不是将样本推到球壳。原始OKLab模式仍可检查真实坐标。动态球面受同一相机影响，逆变换用于拾色。点尺寸/背景/轴/网格/表面等只影响观察状态。

两个直方图来自同一版本当前预览快照；标识目标原图/处理结果、sRGB、取样尺寸。影调0–X是线性Y等分，不是摄影曝光Zone System。软选区使用真实OKLab距离和可解释羽化；透明像素排除；overlay独立于编辑和输出。

## 批次与兼容

VisibleTargets统一鼠标/键盘/范围选择；隐藏选择保留但执行集仅可见选中，并显示数量。同步类别只复制编辑栈，排除评分、色标、EXIF、关系。修复多个同类节点同步。历史按target身份隔离。批次会话独立于色彩方案，用原子JSON保存路径/调整/选择/筛选/active，不复制素材或另存metadata。

V4实验路径不支持的组合应明确阻止，不能静默忽略完整栈。生产稳定V3保留完整链；所有engine在目标快照中冻结。
