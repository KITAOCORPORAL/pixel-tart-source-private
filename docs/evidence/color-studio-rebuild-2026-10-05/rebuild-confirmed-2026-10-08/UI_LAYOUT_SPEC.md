# Color Studio 布局实施契约

状态：实施中；不是视觉批准或实机通过证据。

## 区域及停靠

默认辅助区在左（参考、3D、预设、节点），照片在中间，编辑栏在右。右栏 RGB 编码直方图、线性 Y 和影调入口在工具分类之前。照片工具独立停靠在照片下方、胶片条上方靠右，不盖住照片。窄窗口沿用现有响应式折叠，不改照片处理链。

|旧入口|新入口|保留能力及状态来源|

分类是显示层，不排序、删除或复制工程节点。父分类使用稳定 UI Tag，产品文案走三语言资源，用户节点名不翻译。

## 控件状态

数值框使用共享深色 TextBox 样式。有效草稿只在 Enter/合法失焦提交，非法草稿不进入参数；Esc 优先取消草稿。组复位用开放回头箭头，保留可访问名称、提示及现有组级撤销。冷暖/色偏滑条以渐变补充标签，不声称 RAW Kelvin。

## 已接入的逻辑及未完成验收

左右拖宽及开关写入现有批次文档可选 Layout，越界值 Normalize；旧版本文档无需该字段。胶片条在独立底行或右列，不盖照片；列表/缩略图展示与同一可见集合绑定，幻灯片3秒切当前图，播放/暂停及上一张/下一张复用活动目标命令，不重新创建选择状态。实际播放、保存/跨进程恢复仍待实机验证。

色轮编辑已有全局/阴影/中间调/高光 hue/amount；色阶编辑已有RGB/R/G/B输入黑、中间gamma、白及输出黑白。均沿用既有事务，Esc回滚当前手势，不新增节点执行模型。输出父入口显示现有快速格式摘要，所选/可见/发布配方调用既有命令，不假造16位JPEG或独立管线。

自由画布菜单迁移：复制→既有剪贴板Copy；粘贴→Paste；原复制对象行为→明确创建副本Duplicate；变换父项→既有旋转/翻转；排列父项→既有前后层级；组合/取消组合依真实CanGroup/CanUngroup；查看大图/素材库显示/灵感板仅回调存在时显示。引擎和Document未改。顶栏完整迁移与实机菜单仍未闭环。

布局/控件自动检查不能证明真实鼠标可达。当前150%真实程序已启动；多尺寸及100/125/150/200%真实系统测试未完成，自动渲染倍率截图明确为AUTO。
