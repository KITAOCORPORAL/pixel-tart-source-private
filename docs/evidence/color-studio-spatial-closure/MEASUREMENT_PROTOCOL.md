# Camera grey/chart/exposure/ICC acquisition protocol — no invented calibration

Status: acquisition procedure delivered; no measured calibration chart supplied; camera/film profiles NOT calibrated.

Required local authorization per sample: owner/consent, permitted local processing and redistribution separately, origin/device/firmware, file SHA256, original immutable path label, RAW format/compression, exposure/aperture/ISO/lens, orientation, lighting geometry/illuminant, measured illuminant SPD or documented CCT+Duv limitation, chart serial/batch/age and traceable reference measurement file/license. No source image is checked into Git by default.

1. Grey target: neutral calibrated spectrally characterized patch, matte, uniform lighting measured at centre/corners, fixed manual exposure/ISO/WB, no mixed-light speculation. Capture dark frame/black reference, neutral grey and exposure bracket -4..+4EV at1EV steps with unclipped base; record per-channel saturation counts and histograms. Keep source untouched.
2. Colour target: certified chart reference values under documented illuminant/observer, RAW plus camera JPEG only as separate pipelines, at least daylight-like and tungsten-like measured illuminants; repeat captures and hold-out scenes. Record glare, patch ROI, masking, focus, unevenness and uncertainty; compare grey balance, tone and per-patch colour differences. Do not use portrait subjective preference as chart truth.
3. Exposure sequence: constant illuminant/aperture/ISO with shutter sweep, linear sensor-stage values if available, camera black/white metadata and known clipping. Distinguish decoder uint16 clipping from recoverable scene information; no HDR/highlight claims from already-clipped channels.
4. ICC workflow: profile class/version/white point/PCS/primaries/TRC, source profile bytes+SHA and license, destination profile bytes+SHA, rendering intent/BPC/adaptation and engine version. ICC PCS D50 is not interchangeable with LibRaw ProPhoto-D65 numeric convention. Use fixed independent fixtures with expected transforms and epsilon before supporting new profile. Untagged assumptions explicit; unsupported profile requests reject.
5. Analysis: frozen source/recipe, exact full/native export comparisons, linear-light HQ sampling comparison separately, lossless16bit exact after quantization; JPEG MAE/RMSE thresholds separate. DeltaE/report tolerances specified before measuring, not adjusted after failure. Retain raw observations/uncertainty/repeatability and failure files.
6. Any fitted response/profile or changed historical pixels: explicit new processing/version/profile identity, no silent migration ofPV1–6/referenceV1/V2/filmV1/V2; golden input/output archived by hash. Review legal rights and independent hold-out validation before product inclusion.

No calibration samples collected or generated by this task. Existing companyCanon/Sony/Fuji photos validate decode/processing only; they are not grey-card or colour-chart standards. Real authorised JPEG input absent/NOT_RUN.
