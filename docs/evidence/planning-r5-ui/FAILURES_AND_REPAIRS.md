# 失败及修复记录

1. 新增检查器后既有测试断言“不得包含InspectorColumn”失效。按本批明确要求更新为存在检查器和抽屉，并保留原数据/导航测试。
2. 首次检查器文件缺VM命名空间编译失败，补齐后构建成功。
3. 资源对话框测试打开后直接遍历视觉树，尚未Measure/Arrange导致找不到输入框；补真实布局步骤，测试通过。没有删除验证。
4. 基础功能区Tab模板缺x命名空间，进阶渲染测试捕获XamlParseException；补齐模板声明后21项专项通过，失败TRX留存。
5. 视觉复核发现默认亮色分隔线、Tab页白底、高DPI按钮条过长、文档内容黑字黑底；用本模块本地资源、真实四组工具、纸张底修复，未改全局主题。
6. 拖动时SizeChanged重新套用已保存宽度会干扰拖动，加入拖动期间不重排；结束时通过保存门禁写入。检查器合并仅改动字段，避免覆盖其他编辑。

所有失败记录摘要与TRX哈希在TEST_SUMMARY，未执行Windows桌面不称已通过。截图测试只使用合成项目、文本、色块图片和临时SQLite，未读客户照片。

7. 发布组件截图终检发现FlowDocumentScrollViewer主题模板忽略控件Background，文档内容仍黑字黑底；改为显式纸张Border并设置FlowDocument.Background，仅显示层修复，不改RTF像素或格式。重新构建发布并重测。
