# 人工验收门禁（本轮未执行）

Windows启动、真实导航、物理DPI100/125/150/175/200、前台Tab/Esc/拖动、视觉批准、WPS操作分别NOT_RUN。遵守禁止Computer Use及浏览器/WebView/CDP要求；不复用旧任务的前台错误码作为本轮观测。

人工步骤：
1. 核对RELEASE_IDENTITY后启动完整发布目录，在工作台进入策划中心。基线及本次工作区截图不含主壳，需检查与主壳共同布局。
2. 1920×1080和1366×768逐一进入15分区；检查四组大纲、计数、当前项、表格横向滚动、右检查器和真实数据。
3. 改镜头名称/动作与表格场景后保存重开，确认相互不覆盖；取消表单仅丢本次未提交修改。
4. 道具、设备、人员、场地、时间表、预算双击/Enter编辑，错误值留在对话框，取消不写，复制/归档/撤销实际生效。设备工具箱导入和自动地图天象不应出现假入口。
5. 拖列表/检查器分隔条、左右键调整、双击复位、折叠组；重开同文档核对宽度和折叠。窗口变窄不覆盖宽屏记忆。
6. ≤1100检查器抽屉，<880分区抽屉；Tab不逃出、Esc关闭最上层、关闭回原焦点；Ctrl+F展开策划列表。
7. 进阶切换失败留原模式，保留草稿；四组基础排版按钮实际改变同一RTF。不要把四组基础工具当完整Word七页签。
8. 隔离测试目录制造不可写条件，确认失败文字和重试；恢复权限后保存，不能在生产文件上故障注入。
9. 物理DPI逐档系统切换后重复上述检查；离屏缩放矩阵不替代这一步。
