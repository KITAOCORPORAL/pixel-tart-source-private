# 参考对照说明

本机74张r5参考图已逐张经7张联系表检查，原文件SHA清单见REFERENCE_PNGS。它们包括主页、镜头、自定义列、设备/人员/场地/时间表、进阶与多种Word/冲突对话框。只有当前数据能力对应的可用操作接线；不照搬原型Toast。

对照产物：
- artifacts/r5-final-screenshots：160张工作区离屏矩阵图，另4张抽屉/校验/保存失败状态图；matrix.json记录有效DIP和内容宽度。
- artifacts/r5-comparisons：32张逐页并排对照（15分区+进阶 × 两尺寸），每张注记参考是否同页。工作区截图不含主导航/系统窗口，故不做误导的像素差百分比。
- artifacts/r5-review：两尺寸工作区联系表；artifacts/r5-reference：全部74原图联系表。
- VISUAL_COMPARISONS.json记录每张对应关系；SECTION_STATUS.csv分开功能与视觉状态。

文字/参考图/情绪板/灯位/道具/档期/预算/文件/文档内容在这74张中无独立r5对应页，使用同壳参考+spec，标REFERENCE_GAP。这不阻塞数据接线，但不能说已逐像素复刻。DOCX/Word完整对话框参考仅登记缺口，不能生成假功能截图。

全部视觉状态目前为PARTIAL_OFFSCREEN_REVIEW，不是WINDOWS_VISUAL_APPROVED。160布局组合通过只能证明离屏构造无异常、内容有有效宽度；并非所有细微间距/焦点/遮挡已获实机批准。
