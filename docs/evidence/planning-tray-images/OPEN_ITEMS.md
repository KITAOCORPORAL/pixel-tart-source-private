# 可靠性与未关闭事项

- 旧RTF仍兼容，新托盘图片只以身份标记进入RTF，JSON副本元数据不含图片Base64。历史内嵌图不自动批量迁移。
- 图片副本落盘后才写恢复草稿和主文档；不是跨文件ACID。进程突发崩溃可留下完整但未引用PNG，当前不自动GC，避免删掉undo/recovery需要的图片。
- 本地副本CopyPath为绝对路径；本地策划移动到另一目录/电脑尚无自动路径重写。交付无素材库电脑应使用嵌图DOCX；这一输出不依赖副本路径。
- 外部DOCX的图片元数据不能授予库身份。只有同一文档既有ID且副本哈希一致才保留来源；外部文档图片标“文档内图片”。WPS改写描述或重编码后身份降级是安全策略，不静默关联新源文件。
- 已实现基本标题/图注/宽度/顺序；尚不是任意Word浮动图片、锚点、裁剪或高级排版系统。
- 素材库必须明确打开后解析；跨库自动发现未实现，Offline不会使用缓存猜图。来源重新定位必须明确触发，且不自动替换文档副本。
- 真实Windows输入焦点/IME、物理DPI、WPS打开编辑导回：NOT_RUN。
- 原R7表格、分节、页眉脚支持边界和r5视觉OPEN继续保留，未改Color Studio色彩数学。
