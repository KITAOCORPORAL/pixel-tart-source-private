# 视觉与交互证据说明

已查看当前合成离屏图：选择器列出“当前托盘”和“本项目收藏”，支持搜索与多选，预览/取消/插入为真实处理逻辑；基础版图片管理与进阶纸张显示同一份副本。进阶纸张中可见封面标题、图片、中文说明，不是仅旁边参考图库。

证据图使用自绘几何PNG；素材库、托盘、项目均为临时合成数据。实际选择器按钮事件多选测试检查了DocumentImages数量和托盘未变；实际素材解析器测试检查源内容变化被拒绝。

本轮UI是现有壳内modal/图片管理折叠组，并非Grok完整Word七页签或像素复刻。基础版选择封面/参考/情绪板/镜头会向正文加入相应图片段落和标签；不是独立文件夹图库。表内图片排序不跨单元格移动；用进阶正文调整。

最终截图以发布组件测试生成版本为准，中间图只用于诊断。Windows/WPS实机未执行，不把RenderTargetBitmap、原生ImagePart和OpenXML解析当作WPS实操。
