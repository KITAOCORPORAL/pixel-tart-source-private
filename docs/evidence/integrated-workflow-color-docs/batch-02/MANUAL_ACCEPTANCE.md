# 人工验收（未执行）

适用用户 AGENTS 禁止 Computer Use、内置浏览器/WebView/CDP。本批没有绕过；Release 操作和视觉验收全部 NOT_RUN / NOT_APPROVED。以下只使用可分享副本、临时素材库和测试项目。

1. 运行 RELEASE_IDENTITY.json 指定 EXE。确认源码标识一致，打开一个临时 .ptlibrary。
2. 联机页启动 Watch Folder，把一对 JPEG/RAW 副本放入。等稳定后在素材库看到两个素材；重复“顶层核对”和重启不增加副本。核对 Session/Project/Shot。原片 SHA 必须不变。
3. 切换 Shot 后再接收照片；旧照片关系不跟随当前 Shot。停止/重启，打开“待关联详情”；失败可顶层核对重试，Conflict 保留。
4. 素材库与联机设置不同星级、颜色和摄影师备注。分别试保留素材库/采用联机/合并备注。客户备注不得出现在素材库摄影师备注；重启后仍在。
5. 同一素材引用到两个项目和两个 Moodboard。移除一个引用，另一处和原文件仍存在。库离线时提示，恢复后可读。外部改名需先通过既有重新定位入口更新素材记录。
6. 从素材库“进入 Color Studio”和联机“完整编辑”进入，调整、保存 .ptstudio.json、退出重开。替换测试副本内容应拒绝载入/导出并保留调整；旧 v1 会话仍可读。
7. 策划情绪板插入画布版本。返回画布修改文字/位置，先保存；文档点击“插入/更新画布版本”，出现新版本且旧图保留。断开图像源后旧 PNG 仍可看，新更新应提示源图离线。
8. 参考图菜单“明确关联到成片”选择一个明确 AssetId；同 Shot 其他照片不得自动关联。
9. 1180×720、1600×920、1920×1080，实际 Windows 100/125/150/200% 检查新增入口、文字、菜单和快照。记录真实 DPI，不用 WPF 模拟替代。

本批没有承诺 DOCX 产品导入导出、完整分页编辑、打印预览、批注修订或专业 RAW v3 已上线。DOCX 与分页仅为测试工程试验。
