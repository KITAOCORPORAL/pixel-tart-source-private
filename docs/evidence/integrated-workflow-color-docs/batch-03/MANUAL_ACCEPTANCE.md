# 最短人工验收

用户 AGENTS 禁止 Computer Use、Browser/WebView/CDP。本轮未绕过。以下 Release 操作全部 NOT_RUN，视觉未获批准。

1. 使用 RELEASE_IDENTITY.json 指定 EXE；观察黑底三角、真实初始化文字、主窗口就绪淡出。设置系统减少动画或 KITAO_REDUCE_MOTION=1，确认静态降级。
2. 临时库导入可分享照片，移走原路径；用“重新定位素材”分别选同名不同内容和相同内容，前者拒绝，后者保留 AssetId。选另一 .ptlibrary 建立映射，断开目标库显示离线。
3. 从策划参考、画布菜单、联机页和 Studio 打开重新定位。确认原项目关系与调整不丢失；工作台通过项目素材库入口执行。
4. 两个实例读取相同素材标注，各自编辑；第二提交必须提示冲突。客户备注不进入摄影师备注。故障重试重新读权威状态。
5. Studio 同一照片设曝光 0.5，新建版本后设 1.5；切换、保存退出、重开应各自恢复。批量同步只影响当前版本。导出两版本到不同目录，检查 .kitao-export.json 的版本 ID、ProcessingVersion 和实际文件 SHA256。
6. 策划编辑中文、标题、加粗、对齐、列表、图片和表格，撤销重做，保存重启。插入画布快照、返回画布更新、显式刷新；旧快照保留。
7. 分页预览、打印到 PDF、产品 PDF、DOCX 导出重开对照。导入带批注、页眉、浮动对象的 DOCX，必须先显示损失报告，取消不得改变当前文档。
8. 1180×720、1600×920、1920×1080 与实际 Windows 100/125/150/200% 检查新增按钮、编辑区、菜单和分页。记录窗口/DPI，不能以测试模拟代替。

只使用测试库和可分享副本。原片 SHA、旧 v1 Studio/策划内容和未知字段应保持不变。
