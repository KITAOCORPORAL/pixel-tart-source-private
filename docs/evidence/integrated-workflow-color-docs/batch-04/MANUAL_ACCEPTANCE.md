# 最短人工验收

遵守用户 AGENTS：未使用 Computer Use/Browser/WebView/CDP。以下步骤均未执行，状态 NOT_RUN。仅使用临时库和可分享副本。

1. 运行 RELEASE_IDENTITY.json 对应 EXE，核对 ProductVersion。观察黑底空心彩色三角与真实初始化提示，主窗口就绪淡出；启用减少动态验证静态降级。
2. 同一素材单张、Ctrl/Shift 多选、数字快捷键、右键评分、Inspector 备注/色标；另一实例改变后提交旧页面，应显示逐项冲突且不覆盖。刷新后再编辑成功。客户备注保持独立。
3. 素材库与联机打开同一原片，创建、命名、复制、切换、归档和保存版本；另一个会话/重启/改名后找到已有版本。源 hash 改变必须拒绝旧身份。目录冲突保留会话文件。
4. 快速导出与 Publishing 各导出 JPEG/PNG/TIFF；核对配方、位深、输出尺寸、ICC、版本和 hash。用测试路径阻止 sidecar 写入应 Partial；恢复权限后重试不得再次渲染或覆盖正确成片。
5. 策划正文设置标题层级并用大纲跳转；增删行列、列宽、对齐和边框；横竖页、边距和分页，保存退出重开。比较分页预览、打印 PDF 和产品 PDF 的页数/页面方向/边界。
6. 导入带不支持对象的 DOCX，先出现损失报告，取消保持原文档；确认后报告随包保存。已支持子集导出重开核对。
7. 选择画布正文对象更新，原位置被替换、无重复，历史版本和 CanvasId/RevisionId 保留。
8. 实际 Windows 100/125/150/200% 与窄窗检查工具栏、大纲、表格命中和启动视觉。

命令行双进程验证已执行，与上述桌面步骤无关；可用 tests/Kitao.ProcessProbe/Run-ProcessChecks.ps1 在新临时目录重放。
