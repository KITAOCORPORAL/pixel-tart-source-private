# 相机与显影状态规范

纠正依据：用户2026-10-12第八批明确要求“3–5秒、默认4秒、途中不可跳过”；优先于研究报告第9节“支持跳过/连续掷骰取最新”。原研究不改写，只在此记录纠正。

1. Computing：冻结definition、seed、相纸、机型与动画开关；计算最终预览，保留旧有效版本。未ready不进入计时、不假装完成。
2. 动画开：Camera 0–0.3s；Ejecting 0.3–1.2s；1.2–1.35s保留完全吐出的未显影纸；之后相机与暗覆盖层消失。
3. 动画关：直接进入中央Developing，无相机覆盖。
4. Developing：两路径独立完整4秒；可验证边界3–5秒，不提供跳过入口。正常编辑背景中中央纸框一开始清晰，图像乳灰白/灰蓝/灰绿起色；彩色与双色有不同灰阶轮廓→颜色揭晓，黑白无强制先青后暖。
5. Completed：提交准备好的冻结definition为新版本、呈现最终图，恢复编辑。
6. Cancelled/Failed：关闭、卸载、换DataContext/切目标/Dispose取消本次；不提交、不覆盖上一版本。显影期间禁止重复掷骰和编辑配置、快速导出/Publishing。

两相机为本批原创WPF几何绘制（矩形/圆/镜头/纸槽），无下载商标图/外部纹理。机型与film id分离；不宣称光学标定。不作大幅相机位移（减少动态效果路径仍保留中央4秒）；动画变化不参与像素hash或导出。

验收区分：状态与计时自动测试不等于桌面视觉批准。未运行真实应用启动、屏幕DPI或人眼验收；见MANUAL_ACCEPTANCE.md。
