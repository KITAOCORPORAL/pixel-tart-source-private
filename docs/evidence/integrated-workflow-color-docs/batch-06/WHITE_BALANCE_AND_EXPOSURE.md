# 白平衡与曝光

## RAW白平衡

相机模式：解析的四通道cam_mul，一次通过LibRaw user_mul；G2缺值用G1。CameraGains：分别乘R/G/B相对倍率，G2同G1倍率，范围0.125–8。模式中的数值不是Kelvin或Tint；没有使用JPG冷暖算法。UseCameraWb和UseAutoWb同时关闭，以防LibRaw覆盖user_mul。

首期拒绝AsShotWbApplied输入，不把已渲染小RAW当传感器马赛克重新套增益。实际处理后pre_mul应等于应用值除最小值（highlight=0规则），否则失败。相机矩阵只在LibRaw执行一次；后续逆矩阵是工作空间到显示空间，不是再次相机特征化。

真实两相机红倍率1.25均改变大量采样值，规范化结果记录REAL_RAW_RESULTS.json；Sony R从2.4248046875变3.031005859375，G=1、B=1.458984375。Canon R从1.5634765625变1.954345703125，G=1、B=2.142578125。这验证配置生效，不表示真实白平衡色准已获视觉批准。

## 曝光

`RGB_out = RGB_in * pow(2, EV)`，EV范围[-10,+10]，位于已解码的线性工作域，显示变换之前。数学测试覆盖负值、黑附近、灰阶/曝光阶梯、1以上、+1EV精确两倍；真实master抽样最大增益误差0。最终编码图像受肩部、色域映射和sRGB传递函数影响，不能要求最终RGB8/16也翻倍。

修改曝光复用master；修改WB重解码。输入经LibRaw uint16量化/裁切，本批不会以负EV恢复已剪切高光。输入/定义失配拒绝，WB不可在Render再次施加。

## JPG区分

RAW按钮对JPG明确提示“已渲染图像”，继续旧JPG处理语义。5组配对JPEG验证专业解码器拒绝，不用RAW/JPEG或不同内容照片逐像素误差评价仿色。配对JPEG只帮助核实样本内容，不是RAW颜色真值。
