## 用户在Release中验收

1. 用副本打开旧Studio项目/RAW；确认旧版本外观保持。点击“新 RAW 处理版本”，确认新增独立版本，原ID可切回。
2. RAW相机WB/通道倍率/EV：设+1EV、红倍率1.25、保存关闭重开；检查定义恢复。非法数值、缺配置或坏RAW应失败，不创建成功版本、不改旧预览。
3. 新RAW版本HDR/仿色/胶片/参考工具不能操作；旧版本工具仍可用。JPG应提示已渲染，不标Kelvin或套RAW增益。
4. 导出TIFF16，检查完整尺寸、方向、sRGB profile、PV4/编辑ID/定义；同设置预览与导出按中心采样、不同位深/缩放比较，避免要求不同内容照片pixel exact。
5. 新旧版本快速切换、切照片、修改WB后立即切换；旧任务不得呈现覆盖当前版本；保存后从照片库入口重开仍识别版本。
6. 用灰卡/曝光阶梯、亮火焰、混合光、肤色检查肩部/色域映射，不把已剪切高光误认为恢复。尤其观察极饱和色减色度是否可接受。
7. 100%、150%、200%DPI和窄窗口核验RAW参数栏/禁用状态/焦点；本批最大1600边预览不是原生100%细节，不批准过度放大质量。
8. 测试JPEG/PNG输出视觉与ICC、取消/失败恢复。记录CPU/内存/耗时；Sony单张写出可能约2GiB峰值，不能以程序统计替代真实机器体验。

## 已知需补充的输入

两相机实拍灰卡与标定曝光阶梯；未知相机/已WB sRAW；更多光照肤色/色卡。现有火焰人像不能代替中性灰标定。请在授权副本上验收，不导入生产库作为测试库。
