# 最短人工验收

适用用户 AGENTS 禁止 Computer Use、Browser/WebView/CDP。本轮没有绕过；以下桌面步骤全部 NOT_RUN，用户视觉批准 NOT_APPROVED。只使用临时库、可分享照片副本和测试文档。

1. 运行 RELEASE_IDENTITY.json 对应 EXE。确认版本含本批源码 SHA，检查启动动画正常淡出与静态降级。
2. 单张/多选设置评分、色标、摄影师备注；连续撤销/重做。另一实例修改后旧撤销应拒绝并刷新；客户备注不得改变。批量含冲突项时仅成功项可撤销。
3. 两个工作区打开同一素材版本，分别改名/归档/调参数；保存触发冲突窗口。依次验证 Reload、KeepLocal、Cancel；窗口停留期间另一工作区再次保存，应要求重新处理。取消后原会话与 recovery 文件保留。
4. 跨库版本复制：明确选择目标库，hash 不同拒绝、相同且唯一时确认复制；目标只有选中版本副本，源历史不改变，来源记录保留。
5. 快速导出和 Publishing：用测试任务在编码后中断，重开重试恢复；目标同名不同 hash 或 sidecar 冲突不得覆盖。命令行五阶段终止已测试，界面点击尚未测试。
6. 文档交错执行标题/正文、列表、分页、表格行列、42.5mm 列宽、四边距、图片、画布更新，连续撤销/重做。Enter/失焦提交精确输入，Esc 取消，非法输入不改变布局。
7. 立即 Ctrl+S、退出、重开核对正文和语义；比较预览、打印到 PDF、产品 PDF 的页数、方向和内容。检查中文/英文缺字体回退提示与分页变化。

命令行进程验证可复跑：tests/Kitao.ProcessProbe/Run-ProcessChecks.ps1 和 Run-BatchFiveChecks.ps1，必须指定新的隔离输出目录。
