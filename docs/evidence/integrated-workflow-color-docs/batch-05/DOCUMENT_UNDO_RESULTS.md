# 文档联合撤销与精确输入

RichDocumentHistory 保存 RTF 正文、PlanningRichLayout、页设置、CanvasId/RevisionId、导入损失信息及光标。工具按钮通过 Execute 包裹，一个动作记录一份前后联合快照。原生 RTF undo 禁用，Ctrl+Z/Y、工具栏撤销/重做均走同一历史。文字输入按既有 350ms 编辑批次记录，Enter 前建立边界。最多 100 步/约 128MiB 历史，避免大图无限占用。

标题/正文、对齐、列表、分页、表格增删行列/宽度/边框/对齐、页面方向/尺寸/边距、图片及指定画布更新使用同一操作边界。失败动作回滚到前快照。恢复后重新序列化建立规范状态，修复 RTF 自规范化导致连续撤销出现额外步骤的问题。

精确输入单位 mm：列宽 5–250，四边距 0–80；Enter/失焦提交，Esc 恢复输入前文本；NaN/无穷/越界显示橙色边框与原因，不提交。页面剩余面积仍需满足布局验证，便捷档位保留。

测试包含中文、English、标题、列表、表格、边框、列宽、横向页、分页和 Canvas 语义；联合历史连续撤销/重做，保存重开核对正文与元数据。另用实际 PlanningRichEditor 按钮事件验证标题→页面→表格→连续撤销重做及 42.5mm/NaN 输入。命令级测试不等于真人桌面操作。

字体样本：指定不存在的 Kitao Definitely Missing Font，系统发生回退；本机固定文档前后均为 1 页。不同机器字体可能改变行宽/分页，FONT_MEASUREMENT.txt 明确记录，不承诺相同分页。打印/预览/PDF继续使用共同 PlanningDocumentLayout，第四批横向 PDF MediaBox 测试保留。真实打印与逐页视觉对照 NOT_RUN。

限制：历史是有限内存栈，重开保留文档当前正文/元数据与自动恢复快照，不保存整个 undo 栈。复杂 Word 域、环绕、批注修订仍在本批范围外。
