# Color Studio 管线架构

## 目标分层

```text
RAW/栅格输入
  -> 输入识别与解码
  -> 黑电平、白电平、线性化、解马赛克
  -> 白平衡与相机输入特征化
  -> 场景线性宽色域工作空间
  -> 版本化非破坏性节点
  -> 色调与显示渲染变换
  -> 显示器 ICC 或目标输出空间
  -> 编码与导出
```

## 域约束

- 白平衡和曝光：场景线性域；
- 对比度、曲线和亮度：由节点声明的亮度或编码域；
- HSL/颜色范围：使用明确的选择空间，选择权重与像素处理空间分离；
- 阴影/中间调/高光：连续亮度权重，不能用硬分段产生接缝；
- 输出：统一执行色域映射、传递函数和 ICC/目标配置。

## 版本兼容

历史会话继续绑定其原 ProcessingVersion。新管线必须使用新的版本标识，只有用户显式迁移或新建编辑时启用。参数迁移需可回退，并保存原参数快照。
