# 新调色页操作

在Color Studio标题栏选择“新照片调色页V1”，旧页面仍可返回。

1. 导入照片，在右侧“预设与宝丽来V3”选择相纸、V3与当前编辑/原片来源。PNG/TIFF暂使用CurrentEdits；Original旧入口仅JPEG。
2. 展开显色/光学乳剂/缺陷几何/纸面窗口/第二曝光组，滑动或输入数值。参数是草稿，不会每次拖动启动全尺寸显影；点击“应用并显影”才提交。
3. 曝光、趾肩、柔化、颗粒、基础乳剂与形态缺陷、位置/角度/尺度、窗口/压边/覆膜、种子、第二照片选择/清除、混合/累加、权重/裁切/缩放均直接复用旧页面相同参数。
4. 重新显影换种子；关闭效果保留纸框；重置只改草稿，再应用才写入历史。撤销/重做恢复配方和图像；顶部取消结束当前显影/二源选择。
5. 保存批次，重新打开后配方和第二源身份恢复；第二源必须还在原位置且hash相同，否则明确报错，不找别的文件。导出PNG16/TIFF16/JPEG95仍用产品出口并校验。
6. 切图和新旧页面共用状态；换到无历史照片重置照片参数。第二图没有递归扫描，只读所选文件。透明新二源在编码sRGB域白底合成。

普通照片基本调整/曲线、排序/删除和选定步骤同步仍支持。独立RAW/V3不使用这些普通步骤，相关入口禁用并说明；新页可用V3自己的曝光/完整控制。专业RAW的解码增益/白平衡管理、旧V2相机/掷骰和其他参考匹配工具仍在旧页。高级色轮/局部范围/示波器及最小宽域生产链未新增假入口。

“步骤焦点框颜色”不是计算蒙版；版本与工程诊断移到分析区域。没有正式发行或真实相纸校准结论。
