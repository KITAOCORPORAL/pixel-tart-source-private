## A. NEX5R：零通道值如何产生

### A1. 固定选择与三个互斥来源
沿用原定义：proxy三通道严格(0,1)，且相同BOX足迹没有原production master 0/1端点，最终至少一个RGB通道为0。端点足迹已从**已保存master**重新计算并与旧mask全等，无RAW重解码。

|范围|至少一个零值的像素|零通道分量|负值裁切|精确float零|正小值量化零|
|---|---:|---:|---:|---:|---:|
|原固定选择|11,562|22,326|22,322|0|4|
|全图|11,563|22,327|22,323|0|4|

4个正小值约为1.57868e-6、2.84780e-6、3.38425e-6、6.83712e-6，均低于0.5/65535≈7.62951e-6。全图直接用实际 `uint(clamp(encoded,0,1)*65535+0.5)` 重算，与保存RGBA16**全通道0差**。这是量化分类，不是真实色准。

本地表：
- `nex5r-selected-pixels-all-channels.csv`：11,562坐标、每点所有RGB在print_linear/scan_finish/output/裁切float/uint16的数值。
- `nex5r-zero-channels.csv`：22,326个零分量的x/y/channel、阶段值、互斥分类、邻域极值。
- `nex5r-selected-neighborhoods.npz`：每个零分量真实5×5输入邻域及反射后源坐标，不用单像素公式代替空间滤波。
这些是私有像素明细，仅提交hash/计数。

### A2. 负值的直接来源：固定默认 unsharp
实际计数：print_linear负分量0 → print_scan_finish负分量22,324 → print_output负分量22,323。

已读固定源码：
- `engine/src/pipeline/pipeline.cpp:2035–2048`：scanner_blur→unsharp，overscan关闭。
- 同文件 `1774–1796`：scanner blur sigma=0直接旁路；unsharp使用 `(1+amount)*I-amount*G(I)`。
- `params.hpp::ScannerParams`：unsharp默认{sigma=.7, amount=.7}；不在99项wire resolved里。CPU真实params解析确认仍为此值；preview/lut/deactivate_spatial均false，未误把未列字段当关闭。
- `pipeline.cpp:1003–1016`：sigma按tier_ratio缩放；既有代理作为full输入，ratio=1，因此sigma=.7px。
- `numeric.cpp:78–91`、`blur.cpp:30–74`：truncate=3，半径2，先竖再横；核float32约[.0096200565,.2054236978,.5699124932,.2054236978,.0096200565]。
- `spk_sep_fir_acc.comp`：包含重复边缘像素的reflect，非mirror；`spk_lincomb3.comp`保留负的线性组合，未在锐化处clamp。

按完整图邻域复算：2876400分量的负号分类全部匹配；包括129个距离图边不足2px的负分量。单独乘加CPU与保存scan_finish最大绝对差1.19209e-7；模拟融合方式为5.96046e-8，均**不是bit-exact**，误差如实保留，不设新PASS阈值。所有选中零分量的scan_finish低于其输入5×5邻域最小值，符合锐化暗侧下冲。

### A3. 为什么输出负值少一个
`print_output`在sRGB OETF前乘实际近单位矩阵，不是逐通道原值直接编码。`spk_cctf_encode_matrix.comp`低支线性延伸负值。仅1个负号翻正；固定坐标(226,444,R)的scan_finish约−4.26404e−8，经矩阵约+7.21448e−7，实际encoded约+9.32110e−6，最终不是零。完整矩阵/OETF解析重算符号0差，数值最大差1.78814e−7。该坐标完整RGB与矩阵明细仅本地保存。

### A4. 与原画面的对应及判断
沿用花卉ROI [270,400,300,250]，不是新挑评估区。1,796个选中像素落在该区域，占2.3947%；其中640个最终RGB全零。查看原production、固定PortraA、同图零值覆盖，掩膜集中在花团/叶片等高反差边缘暗侧，与黑色细点/边缘变化对应。原after.png与RGBA16→8bit显示转换已全像素绑定。

**已确认：默认锐化下冲→编码保留负值→最终SDR输出裁切；另有4个正小值量化零。** 未发现条带接缝、边界越界、重复量化或错误读写的证据。负值、单通道零、甚至全黑点不自动构成算法bug；这里更接近**既定锐化风格/输出域取舍**，是否限制下冲需另外定义预期，并由人工评价。

最小后续候选方向（未实现/未准入）：独立版本的边缘感知或下冲约束unsharp；保持现PortraA不变。先完成两个相关成熟实现的固定代码/域/数值对照，再用固定sigma/amount、脉冲/阶跃/负值/>1/边界/条带及6开发图冻结测试，检查细节、光晕、饱和色和肤色；不能以零值数量最小化当唯一目标，也不能直接关闭锐化来宣布修复。

## B. R6：暗部层次在哪合并、底色从哪里来

### B1. 固定ROI和域
严格沿用 vehicle_shadow [0,500,300,250]，75,000像素。每阶段各用自己的单位统计重复值、分布、邻接差分；不跨域比较标准差大小。

- 输入：标准ProPhoto D50场景线性代理。
- film_scale/expose→film_blurs：胶片敏感度加权相对线性曝光，不是显示RGB。
- log：log10(max(exposure,0)+1e−10)，本次由已存正曝光和固定公式解析推算，不冒充新GPU采样。
- film_log_and_curves→grain：归一后的CMY染料密度系数，片基光谱另计；**密度0不是RGB剪切**。
- print_spectral/glare：D50照明归一的纸张扫描相对CIE XYZ。
- print_linear/scan_finish：CAT02适配到D65后的线性sRGB，前者含CAM16-UCS映射，后者含空间锐化。
- print_output/RGBA16：编码sRGB与最终clamp/uint16。

### B2. 首次明确合并在有限曲线低端
`Profile::from_json`（profile.cpp:166–175）逐通道减原采样曲线nanmin；本profile首节点就是各通道最小值，归一后[0,0,0]。log_exposure表范围[-3,4]，gamma=1。`build_interp_tables`构造分段线性表；`spk_curves.comp:interpolate`查询≤首节点时返回首值，不外推。

ROI曝光全部正、无精确0；**19,567个密度零分量全部且仅对应log曝光≤−3**，R/G/B分别5,462/9,601/4,504。不是前一层输出负值触发log保护，也不是三次插值过冲。CPU原double表/float表复算零位置均0差；数值最大差分别8.94070e−8 / 1.19209e−7，不能当独立色准。

242个原本不同的曝光三元组在此变为同一[0,0,0]密度。原固定ROI内，水平5,791、竖直5,789对原本不同的邻接分量在曲线后合并，全部合并到零。

|阶段|ROI内唯一三元组|说明|
|---|---:|---|
|prepared、film_blurs|75,000|所有三元组各异|
|film_log_and_curves|74,759|242点合成一个零密度组|
|print_spectral|73,812|纸张/扫描非线性及float数值重复继续发生|
|print_linear|72,661|XYZ转换与gamut阶段的重复值增加|
|print_scan_finish、print_output|75,000|邻域锐化使各点再次不同，**不是恢复丢失信息**|
|RGBA16|20,305|低对比区域最终量化进一步合并；非上游零密度的来源|

范围内也不能忽略原profile自身局部负斜率：固定ROI的R/G/B分别20,479/13,958/15,240个查询落在下降段。这与第五批已记录的原采样表非单调同源，不是本轮新bug；不能将整块ROI压缩只归因于曲线下限。

### B3. 零密度仍有非零底色：纸张与扫描链
针对同99项resolved的CPU core setup实读：print gain三通道0.8357499244，preflash=0，black/white correction关闭；paper morph关闭但纸张本来就采用固定CDF拟合曲线，不是film原采样表。

沿原 `print_spectral`路径：胶片密度+片基→放大机光谱曝光→print exposure→纸张CDF曲线→纸张染料+base→D50扫描XYZ。固定ROI的纸张log曝光都在0.3550–0.86465之间，**没有纸张表[-3,4]端点越界**。

零胶片密度点的链：
- 纸张log曝光约[0.791484,0.844556,0.864648]。
- 纸张密度约[2.329383,1.929610,1.809488]，不是无限密度，也非每通道都到渐近上限。
- 已观测扫描XYZ=[0.0041179145,0.0042350129,0.0044026026]；固定ROI全链CPU解析与已存XYZ最大差**7.45058e−9**。
- 映射后线性sRGB约[0.003905350,0.004238378,0.005496244]，蓝相对高；不经过黑位归零。近乎恒定底色来自固定纸张/扫描响应，而非凭空新增偏移。
- CAM16前CPU矩阵结果与该底色仅约1e−7量级差别；整个ROI前后最大差9.0762e−6，含矩阵舍入与gamut作用，不能当成精确单独gamut误差。纸张XYZ层已出现该非零底部，故不是最后锐化/OETF才制造底色。

该机制符合**固定模型的非零黑位与暗部趾部取舍，加上输入曝光覆盖不足/表端点适配风险**。目前无错误实现的直接证据；没有控制实拍或配对物理参考，不能断言其纸张底色准确、适合通用摄影，或哪一段应“纠正”。

### B4. 输入前损失与结论边界
固定ROI有54,321像素的旧master端点足迹；19,567个新零密度分量中19,554在该足迹内，13在无旧端点足迹内；242个全零密度点全部带旧足迹。已保存proxy/胶片曝光在这些点仍各异，因此新增查表合并是真实发生；但**不能排除更早RAW/production整数链已损失信息，不能把242点当原始传感器真值**。

原显示Y标准差比实算0.131662，原medianY约0.000502939→0.004264334。这是两种显示映射的同源相对观察，不是真实色差或优化目标；本轮不设“恢复至1”。

2. 若需保留趾部信息，另立带可追溯有效低曝光数据的profile/域扩展版本；不凭空外推、减黑、平滑或替换CDF。
3. 若需不同黑位呈现，将其作为独立明确扫描/纸张风格版本，不能包装成纠正绝对色准。
