# 首版功能范围

|状态|功能|边界|
|---|---|---|
|已接通|中央大图/底部胶片条/右侧五页签|R3主结构；区块/页签拖排序及完整直方图工具清单未全部迁入|
|已接通|点相纸/点框自动待显影预览|快速→原尺寸核对，最后任务生效，不写显影历史|
|已接通|显影/配方锁定/重新拍摄新变体|基于既有EditVersions承载独立变体；按变体评分/色标和完整堆叠UI未实现|
|已接通|窗口内影调/白平衡/曲线|显式应用，同一变体undo/redo；色框不染色；不是全部高级工具|
|已接通|保存重开/PNG16/TIFF16/JPEG|冻结定义、源hash、文件CAS、发布临时和独立回读保护保留|
|已接通|5相纸响应/6原创通用框|无伪造16响应，无角色框临时扩量|
|有限支持|普通胶片风格/图层节点|复用旧编辑命令，独立光片不套普通整图胶片|
|有限支持|即时预览|先小输入快速效果，再全源核对；大图不是零时延|
|有限支持|TIFF3/RAW|原准入不扩大；TIFF3专用产品RGB16精确sRGB|
|尚未接通|角色相框包|用户确认授权已登记，本版仍只开放通用6框；60/98/85清单差异保留|
|尚未完成验收|真实鼠标/物理DPI/真实录屏|官方桌面工具native pipe不可用；离屏程序化结果不能替代|
|尚未实现|任意自定义透明PNG框导入/窗口内几何裁切完整工具|目前仅注册procedural方/圆覆盖|
|尚未实现|完整R3所有面板工具/风格LUT导入/按变体评分色标|页面明确能力边界，不用可点空壳|

此包是家用第一版试用，不是全量R3正式发行。角色素材用户确认授权不等于助手独立法律核验；本版不发布角色素材仅因范围选择，非继续认定未授权。
