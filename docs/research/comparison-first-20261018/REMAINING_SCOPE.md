# 剩余事项分类与发行范围

目标范围：Windows单用户本地诊断试用；V3创作近似、受准入的已渲染输入/现有RAW定义、双照片、项目版本/历史、PNG16/TIFF16/JPEG。以下分类不能混作同一种阻断。

|类型|事项|当前证据/影响|放行/下一步|
|---|---|---|---|
|已确认缺陷（本轮关闭）|效果渲染完成还等约13秒对照|按需独立对照；原效果首显/可继续/对照准备分别测量|最终三次和竞态测试通过后关闭，保留前测|
|已确认缺陷（本轮关闭）|像素空间块重复取样|同块encoded值精确复用，保留float顺序；scratch预算显式计入|要求完整前后preview/三格式hash相同，不扩大算法版本|
|已确认缺陷（范围外仍开放）|Fuji原生解码重复性|冻结Fuji输入只能证明冻结流程，不能证明原生RAF重复|若正式宣称原生Fuji支持则必须定位并验证；诊断试用明确只承认冻结输入|
|已确认分歧（仍开放）|显示ICC路径分歧|已有显示转换参考分歧，非本轮数学节点|若发行目标包含可靠色彩管理显示则需单独对齐；当前不作此承诺|
|尚未执行验证|物理前台鼠标/键盘、不同显示器物理DPI|本轮仅WPF Dispatcher/命令/离屏图|通用桌面正式发行前人工验证；未执行不得报通过|
|尚未执行验证|真实断电/硬件满盘/网络多主文件锁|已有逻辑注入、CAS、原子发布测试不等于硬件实验|按部署目标风险决策补测；本地诊断不宣传分布式事务|
|尚未执行验证|长期运行原生/WIC内存泄漏排查|三进程采样+映射归零不构成长期无泄漏证明|正式大规模/长时间批处理前做长稳和native归属分析|
|明确不支持|完整DWG/场景RAW宽色域工作域、通用显示ICC/HDR|现只有固定版本受限管线|不属于此诊断版本承诺；不能仅为它们未实现就把已测sRGB链说成失败|
|明确不支持|TIFF3通用任意压缩/任意ICC/大于准入输入|TIFF3是专用产品RGB16精确sRGB映射|超范围回既有WIC准入或明确拒绝，不暗降尺寸/改profile标签|
|明确不支持|GPU新后端、通用增量实时原尺寸调色|本轮只CPU热点精确复用和按需对照|非本轮交付，无GPU速度承诺|
|缺少素材暂缓|完整外部LUT、特殊贴图/附件|原材料未齐，许可证/来源未全|不伪造资源，不称全部吸收；不阻塞无此资源依赖的本轮对照调度|
|验证受条件限制|完整套件中的授权/硬件/性能opt-in测试|逐项NotExecuted及原因归档|不能当Passed；按正式目标挑出必须闭合项，不以数量冒充质量|

**发行结论**：可交付有限范围诊断试用，不授予通用正式发行批准。正式发行需先固定支持输入、显示色彩、物理平台和操作范围，再对该范围强制项目签字；缺素材/范围外能力/未测风险不是同一性质。已关闭的安全发布、项目CAS、内嵌版本权威、发布源owner/消费者锁不重开或移除。
