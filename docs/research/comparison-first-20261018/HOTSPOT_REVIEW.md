# 热点分析和唯一局部优化

采样区间：授权Canon/Sony同完整4220×4863输出、1600线性面积预览，参数来自前轮冻结项目。完整条带计时 + 每tile行x=0采样，不将稀疏样本总和当作整个stage wall time。单次分析，非三次速度统计。

空间内部稀疏采样显示双源fetch/interpolate、original fetch/creative重复工作占比较大。唯一算法路径修改：每tile halo原本已经读取encoded source，保存在显式预算的小块数组，用于同tile原片端点；不再次调用双源取样与插值。每个像素的取样坐标、公式与浮点算术顺序不变，不近似Noise，不跳过Amount=0计算，不改变25tap和缩图、不GPU重写。额外数组按double scratch大小计费，未提高总预算。纸面、几何和缩图未改。

sampled.original-fetch-creative-defects由28.356ms/105980个采样点降到12.217ms；只代表采样点，不是全帧精确耗时。固定预览及三格式文件hash比较、两参考色彩数学与历史版本回归单独验收；如出现任何不一致不接受此优化。最终三次用户操作测量与该含profiling overhead运行分开报告。
