# 诊断试用说明

编写时间：2026-10-18T14:16:30.771412+08:00（Asia/Shanghai）；对应UTC 2026-10-18T06:16:30.771412+00:00。

## 可试用范围

本构建用于Windows本地单用户、现有授权素材的诊断试用：新调色页V3、第二曝光、原始已渲染文件sRGB曝光、项目保存/重开、PNG16/TIFF16/JPEG导出。它不是物理胶片标定，也不是完整RAW宽色域/通用ICC系统。目标范围内程序化验收、物理前台未执行与外部素材缺失分开登记，见REMAINING_SCOPE.md。

## 进入与应用

1. 启动BUILD_IDENTITY.json指向的独立目录中的KitaoPhotoSelector.exe。不要替换旧Release；无需安装新依赖。
2. 左侧主导航点“参考仿色”（Color Studio），在该页标题下点击“新照片调色页 V1”。顶部“导入”选择照片。
3. 右侧展开“预设与宝丽来 V3”，算法选V3，确认输入来源：Original是原文件，CurrentEdits是冻结的当前编辑输入；这不是同一种语义。
4. 调整参数后点击“应用并显影”。即时模式下，效果完成后先显示，可立即再次编辑、切图或导出。显影演示是单独展示偏好，可跳过，不改变种子/配方/像素。
5. “选择第二张照片”后调整权重、构图位置CropX/CropY和缩放Zoom，再点击应用。第二照片是冻结路径/哈希，不能在应用后暗换文件；变化会拒绝，保留旧有效结果。

## 对照的含义与状态

- 中央图片上方显示对照状态。效果就绪、对照未准备时先显示当前效果；不会拿旧版本或另一照片补作对照。
- 点击“准备当前配方基准对照（含第二曝光／几何）”，或从下拉框选“原片”“左右对比”“并排对比”触发准备。原片标签在本新管线指**配方基准对照**，不是单独第一张源照片；上方状态明确说明。
- 对照严格使用既有Original()：保留第二曝光及部分几何/纸面参数，取消规定的效果项。因此改变第二照片权重、裁切、缩放会影响它；不要把它当作第一张未加工照片。
- 准备期间效果可继续操作，提示仍显示“准备中”。切图、再次应用、撤销、重开、导出或关闭会取消旧对照并释放输入。后台完成只替换对照视图，不改效果、种子或历史。
- 按“取消”会停止准备；可重新点击准备。文件离线、哈希不匹配或预算拒绝会显示对照失败，当前效果保留。

## 原文件sRGB曝光

“线性sRGB曝光”中的“从原文件创建曝光版本”读取原始已渲染文件，**不**在当前可见Look/Stack/Film上叠加。旧编辑版本保留，顶部“撤销调整/重做调整”可以返回；这不是场景RAW曝光，也不与V3混成一条链。

## 保存、恢复、导出

- 顶部“保存批次”选择.ptstudio.json工作文件，携带自包含编辑版本。共享版本目录仍是原先独立保存命令，保存项目不会暗写共享目录。
- “打开批次”重开项目；丢源、改源、无效JSON或激活失败时旧工作区保留。同一项目被其他实例修改时保存会拒绝，不覆盖对方。
- 顶部撤销/重做恢复最近版本；左侧“历史版本”选择指定版本后点击“选择版本”。只切到选中条目尚未确认时不会直接覆盖当前版本。
- 顶部“导出”菜单先选择PNG16、TIFF16或JPEG，再选择“快速导出所选”或“快速导出可见照片”，选择输出目录。JPEG有损；Source遵循原格式，RAW导出为TIFF16，不写原RAW。
- 独立导出验证、无覆盖发布、UUID临时文件保留。导出会优先停止对照，不等待对照完成；输出来自冻结效果定义，不来自对照bitmap。

## TIFF3输入边界

TIFF3只支持产品single-strip little-endian未压缩RGB16、精确嵌入sRGB profile；保持原512MiB输入及总预算限制。其他TIFF不自动当作TIFF3；若既有WIC路径能解释且预算允许则使用已有路径，否则提示Unsupported/预算或解码失败，不暗降尺寸。不支持的profile不会仅改标签假装sRGB。照片源始终只读。

## 验证级别

本轮执行WPF调度、真实命令/控件绑定、离屏渲染和文件输出验证，未发送用户桌面输入。不能把这些记录称为真实鼠标、物理DPI或显示器色彩验收。试用仍请在照片副本和独立输出目录中进行。不要因资源账本归零就判断无原生缓存/泄漏。

本轮离屏页面已人工检查效果先显示和“对照未准备”提示，但这是RenderTargetBitmap，不是用户桌面的实体窗口截图。含私人照片的离屏PNG只留本地，不随Git/证据ZIP分发。
