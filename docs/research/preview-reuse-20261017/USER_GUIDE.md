# 操作说明与版本边界

- 新页面V3照常“应用”：即时/显影演示行为不变。已算好的图像通过验证直接提交，不再再算同一预览；演示和skip不改变最终像素。
- “从原文件创建曝光版本”：以最初打开的PNG/TIFF/JPEG等已渲染文件为输入，不把当前Look/Stack/Film效果烘焙进去。旧效果在前版本中保留；撤销/重做返回旧结果。RAW与V3混链仍不支持。TIFF3只限产品未压缩RGB16/精确sRGB ICC，不代表通用TIFF/完整RAW工作域/显示ICC。
- 保存项目仍为单文件自包含编辑快照，共享版本目录继续是独立显式命令。冲突拒绝不覆盖，不因本轮优化自动写共享目录。
- 项目打开先完整准备再移交。出现取消/故障时保留原工作区；停止按钮和关闭会取消准备。没有通过降低照片/输出尺寸换速度。
- 普通导出的UUID安全暂存/不覆盖发布、发布中间文件owner锁与消费者锁不改。旧版本解释和已生成的历史配方不迁移。

交付目录以BUILD_IDENTITY.json为准。仍是诊断构建；未正式发行，未改系统ICC/DPI。所有测量及条件未执行清单见FINAL_REPORT.md、TEST_COUNTS.json与原始TRX归档。
