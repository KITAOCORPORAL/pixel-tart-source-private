# 功能范围

|状态|功能|说明|
|---|---|---|
|已可用|新页直接进入、返回旧版|本独立试用构建启用，普通构建路线不改|
|已可用|基础影调／白平衡／RGB通道曲线|复用现有编辑栈，不复制参数状态|
|已可用|宝丽来5组响应选择|经典彩色、柔调黑白、复古暖彩、浅蓝、深蓝；共用型号明确标注|
|已可用|同照片真实色彩缩略图|JPEG/PNG/已准入TIFF；无当前编辑/颗粒/纸框，标记曝光；不是完整成片预言|
|已可用|纸框／颗粒／乳剂缺陷／双重曝光|进阶组；同种子/完整配方记录，属于创作模拟|
|已可用|效果图／配方基准／左右／并排|基准不是独立第一源；按需准备，可取消|
|已可用|缩放、平移、适合窗口、分界滑杆|实际WPF控件/现有viewport状态|
|已可用|历史、撤销重做、项目保存重开|文件锁/CAS/内嵌版本权威与回滚保护保留|
|已可用|PNG16/TIFF16/JPEG导出|既有独立验证、安全无覆盖发布、UUID暂存|
|有限支持|基础/曲线与宝丽来模式混用|独立效果版本禁用基础/曲线；需撤销或回历史，不暗叠加|
|有限支持|批量同步|普通编辑栈选中步骤；非V3配方批量同步|
|有限支持|RAW|沿现有受准入路径；本轮图库是授权冻结源的800边长评审副本，不证明原生重复性|
|有限支持|TIFF3|仅产品single-strip little-endian未压缩RGB16、精确sRGB；不是通用TIFF|
|有限支持|颜色/题材评审|3张偏暗人像/夕阳/暖灯照片；缺日光肤色、标准中性色卡和宽色域高饱和物体|
|尚未实现|单独第一源原片对照|未提供，就不在新页叫“原片”|
|尚未实现|真实胶片配对标定、完整DWG/通用ICC/HDR|不以创作配方冒充科学还原|
|尚未实现|部分历史相纸/缺LUT贴图|没有可点空壳，也不声称全部吸收|
|尚未执行|物理前台鼠标/DPI/显示色彩验收|本轮真实程序启动＋WPF命令与离屏截图，不等于物理操作|

本轮暂停性能/缓存/压力扩展。已确认的Fuji原生重复性及显示ICC分歧继续单独开放，未自动批准正式发行。
