照片调色试用｜快速开始

1. 双击 app-final\KitaoPhotoSelector.exe（或根目录“启动试用.cmd”）。本独立构建直接进入“照片调色”，右上可返回旧版；试用数据独立存放，不覆盖正式应用设置。
2. 点“导入照片”。基础调色、曲线、宝丽来各在一个标签页；滚轮缩放、拖动平移，双击适合窗口。左右对比的分界可用上方滑杆调整。
3. 宝丽来：选相纸→调整强度、曝光→点“应用相纸效果”。点“预览这些相纸”可生成同照片色彩缩略图；缩略图不含当前编辑/纸框/颗粒。i-Type与600彩色共响应，黑白型号也有共用，不代表实物标定。
4. 纸框/纸面、颗粒/乳剂缺陷、双重曝光在进阶折叠组。输入详情中“从原文件开始”和“使用当前编辑”含义不同；不会因选择缩略图自动应用。
5. “效果图／配方基准／左右／并排”名称对应实际功能；配方基准保留第二曝光、构图及部分纸面，不是独立第一张源照片。未准备时点“准备配方基准”；后台中可继续编辑，过期结果会取消。
6. “保存项目”写.ptstudio.json；“打开项目”重开。顶部撤销/重做，左侧历史可恢复旧版本。基础/曲线在独立效果版本暂不可用，页面会说明如何返回。
7. 顶部“导出”选择PNG/TIFF/JPEG，再点“快速导出所选”并选输出目录。基础页“从原文件创建曝光版本”不叠加当前Look/曲线/胶片，旧版本保留可撤销。
