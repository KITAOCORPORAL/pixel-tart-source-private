# 剩余事项分类

|分类|事项|本次试用含义|
|---|---|---|
|待用户评价|宝丽来色彩喜好、暗部色点、肤色层次、纸框颗粒强弱|输出原样保留，未手工清理或AI生成替代；需要摄影师反馈，不算程序审美通过|
|已确认范围限制|基础/曲线不能直接叠加独立V3或sRGB曝光版本|入口明确禁用原因，撤销或历史返回普通编辑；不暗丢参数|
|已确认范围限制|i-Type/600彩色、三型号黑白共用响应|5组可选响应诚实说明，没有制造营销型号差异|
|尚未执行|物理前台鼠标、不同DPI/显示器颜色验收|实际EXE隔离启动与WPF离屏截图不代替物理测试|
|尚未执行|充分日光肤色/色卡/高饱和多色素材评审|3张输入偏暗人像/夕阳/暖灯，未扫描额外目录；没有覆盖就不夸大|
|明确不支持|独立第一张源照片对照|显示“配方基准”，Original()解释不变，含第二曝光/几何/部分纸面|
|明确不支持|完整DWG/通用ICC/HDR/真实胶片标定|不是本有限试用承诺；创作模拟不能变成精确还原|
|有限输入|RAW与TIFF3|沿原准入；RAW缩略图预览禁用并说明；TIFF3只限产品未压缩RGB16精确sRGB|
|已知未关闭|Fuji原生重复性、显示ICC分歧|冻结Fuji只用于已冻结输入材料，非原生支持关闭证明|
|缺素材暂缓|部分历史相纸/完整LUT/特殊贴图|无可点击空壳，不声称全部吸收|
|沿前轮未验证|真实断电/满盘/网络多主锁、长稳内存归属|本轮不扩展压力/性能矩阵，既有安全逻辑测试保留|

交付结论：可直接打开的摄影师诊断试用，明确支持范围内已完成入口/绑定/模式/历史/保存重开/一次完整导出。审美由用户评审，通用正式发行批准未授予。
