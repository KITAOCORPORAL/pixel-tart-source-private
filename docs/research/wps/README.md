# WPS Black-Box Research Package

This package collects the already written WPS Writer/Presentation research scaffold and Pixel Tart Planning Center proposals. It is `PARTIAL`: the version baseline records installation and executable metadata, but its raw command output is not attached. The screenshot folders contain only `.gitkeep` placeholders, and no WPS UI traversal or file round trip is evidenced here.

Start with the [Evidence Manifest](17_WPS_RESEARCH_EVIDENCE_MANIFEST.md), then the [Feature Matrix](08_WPS_COMPLETE_FEATURE_MATRIX.md) and [Planning Center borrowing plan](12_PIXEL_TART_PLANNING_CENTER_BORROWING_PLAN.md). `VERIFIED` is limited to the exact existing record or inventory fact cited. `NOT VERIFIED` is not a negative capability claim. The planning documents are recommendations, not evidence of WPS parity or current Pixel Tart acceptance.
