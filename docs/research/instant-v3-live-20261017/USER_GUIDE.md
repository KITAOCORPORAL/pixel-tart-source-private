# V3 使用说明（本轮隔离构建）

1. 从现有工作台进入 Color Studio，打开照片；使用原有「即时成像」面板。
2. 引擎明确选择 **V3**，再选相纸。现代彩色、现代黑白、SX-70创作、Reclaimed Blue、Blue Duochrome为五类基础。V2仍可单独选择，旧项目不会自动切换。
3. 调整V3曝光、趾部、肩部、表观密度、柔化/高光扩散、乳剂、过期/褪色等。纸纹/划痕/灰尘、纸面反射/方向/宽度、圆窗口/裁切/缩放独立于乳剂。
4. 保持根种子可复现；「重新显影」明确重抽，普通参数修改不自动重抽其他子流。生成提交后可「撤销显影」「重做显影」。保存使用原有项目/会话保存，重开恢复完整V3配方。
5. 原图比较保持相同构图；1:1/局部详情使用原像素坐标，不把屏幕预览当导出源。
6. 原有导出入口TIFF16/PNG16/JPEG现在按正式Core V3条带直接渲染，不需要先运行研究工具。嵌入输出sRGB；JPEG固定有损容差，不能与16位无损逐码相等混淆。

「Womb01351.Stock0…5」是用户附件明确公式的计算复现，使用中性编号，非旧App实际输出、非相纸化学标定。尤其Stock4旧蓝映射与Reclaimed Blue/Blue Duochrome独立，现代i-Type/600没有因此拆成两个化学模型。

程序纹理/缺陷为原创创作形态。明显缺陷、结晶、漏液默认0；没有动物/达摩/妖怪贴图的假入口，三张33³ LUT仅存摘要，不伪造完整LUT。多曝目前只有线性光Core算子，没有第二照片选择/项目保存产品闭环，不能在此说明中声称可操作。

发行仍为诊断版：Fuji旧解码不稳定、历史P3长尾和未完成的前台/物理DPI验收保持独立阻断。V3是创作模拟，不是相纸/相机实测标定。
