# 剩余边界与发行阻断

1. Fuji 原生旧解码重复性仍独立阻断正式发行；本轮冻结输入不能关闭该问题。
2. 前台独立 EXE 的真实点击、关闭后原生内存回落、物理100/150/200% DPI 未验收；只读空闲时间不是获得独占的证明，不发送桌面输入。
3. 显示器 ICC 分歧、真实场景宽色域输入/输出变换/显示管理仍未准入。PhotoWideV1 是独立公式基础，不是完整 Resolve 色彩引擎。
4. 所称四份 Resolve 附件，本地仅明确找到并核验一个12成员ZIP；其余原始附件仍未定位，不能编造吸收完成。
5. 三组33³完整LUT、特殊第三方贴图缺失，不伪造。
6. 全尺寸多组合数值与局部视觉证据已经扩展，但不能宣称所有高频、所有输出尺寸、实拍极端组合审美都通过。
7. P3已有索引修复与成功测量继续有效；历史长尾根因未全部关闭不是当前必现性能失败。

原先“第二照片入口、窗口双边线、可编辑缺陷几何缺失”已在本轮实现，不继续列作未实现。正式发行仍 BLOCKED_DIAGNOSTIC_BUILD_WITH_V3_CORRECTIONS。
