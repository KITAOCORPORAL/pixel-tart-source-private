# 本轮软件操作

这是隔离诊断构建，不覆盖旧 Release，旧页面仍保留。入口与最终目录见 FINAL_REPORT.md。

## 新调色页

在 Color Studio 标题栏选择“新照片调色页 V1”。导入照片，中央查看预览，底部选择照片；添加基础调整或曲线，在右侧改参数，顶部切换前后对照、撤销/重做。选中一个调整步骤，勾选底部目标照片后“同步到所选照片”只同步当前步骤。保存批次后重新打开可恢复照片、步骤和已有版本，导出仍用真实产品出口。顶部“返回旧页面”不会迁移算法。

在“预设与宝丽来 V3”选择 V3、曝光和种子并生成。当前照片已经进入独立 RAW/V3 显影模式时，普通调整面板禁用，因为这些普通节点不参与该独立处理链；需要的完整 V3 创作、窗口、缺陷和多曝控制仍在旧页。不是将灰掉控件当作实现了算法。V3 的撤销/重做走相片版本历史；普通照片走调整历史。“步骤焦点框颜色”只是焦点框，不是计算蒙版。

## V3 与多重曝光

1. 选择照片、V3 和五类基础相纸之一。新版 Creative2 修复六种旧风格覆盖上游效果；历史 Creative1 保持原解释。
2. 基础乳剂缺陷与形态缺陷强度分开；None 不产生所选形态，但独立结晶、漏液或基础缺陷仍由各自数值控制。
3. Paper3 为新采样/圆窗与窗口双边线；画布外沿亮线不是照片窗口。非整数缩放使用双线性，不保证所有极端高频内容无混叠。
4. 选择“第二张照片”只读取明确选定文件，当前对话框支持 PNG/TIFF/JPEG。归一化混合和曝光累加为两种明确语义，可设置权重、构图和缩放，保存双源身份。第二源移动、缺失或变更会报错，不静默用别的照片。
5. 缺陷几何可写入位置、角度、尺度；重新显影更新固定种子并同步配方与界面。
6. 生成完成后保存批次、重开、导出 TIFF16 / PNG16 / JPEG。输出为 sRGB；宽色域公式库没有暗中接入旧 V3，也不会恢复曾裁掉的 RAW 信息。

完整 LUT 和第三方特殊贴图仍缺资源，不提供假入口。物理 DPI、前台真实鼠标操作、显示器 ICC 与 Fuji 原生重复性不由这些说明宣布通过。
