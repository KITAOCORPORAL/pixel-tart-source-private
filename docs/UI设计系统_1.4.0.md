# 北尾鸲归片助手 UI 设计系统 1.4.0

## 目标

1.4.0 只重构界面表现与交互组织，不改变编号解析、索引、匹配、复制、报告、授权、教程和安装行为。设计语言遵循现代 Windows 桌面软件：低噪声、清晰层级、有限圆角、少量强调色和完整键盘可达性。

## 资源结构

设计系统位于 `src/RAWSelectionAssistant/Resources/DesignSystem/`：

- `DesignTokens.xaml`：字号、控件高度、行高、侧栏宽度、内边距、圆角和动效时长。
- `Theme.Light.xaml`：浅色语义颜色。
- `Theme.Dark.xaml`：深色语义颜色。
- `Theme.HighContrast.xaml`：Windows 高对比度系统色。
- `AccentColors.xaml`：强调色、悬停、按下、浅底和前景色。
- `Typography.xaml`：窗口、正文、标题、说明文字。
- `Controls.*.xaml`：按钮、输入、卡片、表格、导航、菜单、弹窗和状态控件。

视图只引用语义资源，不直接依赖具体颜色值。主题、强调色、密度与字号使用 `DynamicResource`，切换时不重新创建主 ViewModel，不清空项目状态。

## 颜色语义

| 语义 | 用途 |
|---|---|
| WindowBackground / ContentBackground | 窗口与页面画布 |
| SurfacePrimary / SurfaceSecondary / SurfaceHover | 卡片、控件与交互层 |
| Border / Divider | 边框与分隔线 |
| TextPrimary / Secondary / Tertiary / Disabled | 四级文字 |
| Accent / AccentHover / AccentPressed / AccentSoft | 品牌与主要操作 |
| Success / Warning / Danger / Info | 状态，不仅依靠颜色，始终配合文字 |

深色模式不是颜色反相，而是独立的表面、边框、文字和状态色。高对比度模式直接使用 Windows `SystemColors`。

## 强调色

提供 Windows 强调色、北尾鸲蓝、苔藓绿、酒红、夜紫、暖琥珀、石墨灰和自定义 `#RRGGBB`。运行时生成 Hover、Pressed 与 Soft 状态，并通过相对亮度选择黑色或白色按钮前景。文件大小、授权状态或业务结果不会影响颜色配置。

## 排版与密度

- 默认字体：Microsoft YaHei UI。
- 正文字号：13；大字号：15。
- 舒适控件高度：38；紧凑控件高度：32。
- 舒适表格行高：42；紧凑表格行高：34。
- 页面主标题：28；应用标题：20；区块标题：16。
- 侧栏展开：220；收起：0。收起时容器完全移出布局，只在顶部应用栏保留独立的 36×36 展开按钮。

## 页面框架

1. 顶层菜单：文件、项目、编辑、视图、工具、帮助。
2. 应用栏：品牌、版本、当前项目、项目状态、当前步骤、索引、侧栏、外观、版本与取消任务。
3. 左侧栏：项目中心、归片工作区、项目历史、授权与版本、设置、帮助。
4. 主内容区：项目中心或四步归片工作区。
5. 底部状态栏：状态、当前文件、处理数量和进度。
6. 右上角 Toast：非阻塞地确认外观变更。

## 四步工作流

1. 来源与索引：来源目录、目录用途、优先级、扫描、归片类别、客户 JPG 模式。
2. 导入选片：安全说明、拖放区、文本输入、粘贴、解析和清空。
3. 匹配检查：统计、搜索、待处理过滤、结果表、行内明细和快速摘要。
4. 输出交付：项目名、输出目录、输出模式、复制、报告、打开目录和清空任务。

`查看明细` 固定在“总体状态”右侧并冻结在前部，同时提供所选记录下方按钮和 `Alt+Enter` 快捷入口。

## 外观设置

- 主题：跟随 Windows、浅色、深色。
- 强调色：系统色、六种预设和自定义。
- 密度：舒适、紧凑。
- 侧栏：始终展开、窄窗口自动收起、记住上次状态。
- 动效：标准、减少动效。
- 字号：标准、大字号。
- 实时预览：主要按钮、次要按钮、状态标签和当前颜色值。
- 恢复默认：恢复系统主题、北尾鸲蓝、舒适密度、记忆侧栏、标准动效和标准字号。

## 交互与可访问性

- 按钮具备默认、悬停、按下、禁用与键盘焦点状态。
- 弹窗提供默认按钮、取消按钮和 Esc 关闭行为。
- `Ctrl+N` 新建项目，`Ctrl+S` 保存，`Ctrl+F` 聚焦搜索，`Ctrl+B` 切换侧栏，`Ctrl+Shift+F` 打开建议与问题反馈，`F1` 打开帮助，`Alt+Enter` 打开选中记录明细。
- 结果状态同时显示中文文字和颜色。
- 遵循 Windows 高对比度，系统主题变化会自动重新应用。
- Release XAML 不包含 UI Preview 或演示入口。

## 设置兼容

旧版 `settings.json` 缺少 `Appearance` 时自动补默认值。未知枚举或无效自定义颜色安全回退，不影响原有字段。外观变更即时应用并保存，不重建项目、不清空匹配结果。

## 1.4.2 顶部与侧栏精修

- 顶部信息区改为无外框平面信息带，仅保留 1px 底部分隔线。
- 左、中、右三段分别承载页面语义、任务状态和版本 / 任务操作，整条高度保持 72。
- 索引标签、版本标签、升级入口与取消任务采用统一 32 高度体系，文字垂直居中并启用像素取整。
- 侧栏使用 `Grid` 三段分层：可滚动导航、固定版本卡、固定收起按钮。
- 版本卡最小高度 80、内边距 14、正文行高 19；窗口变矮时优先滚动导航，不压缩版本卡。
- 全局状态栏固定为独立 34 高度底行，不参与侧栏内部布局。

## 1.4.3 侧栏与反馈功能

- 侧栏收起后宽度为 0，导航、图标、分组、版本卡、背景和分隔线全部隐藏，主内容区释放全部宽度。
- 展开按钮位于顶部应用栏左侧，独立于侧栏容器；展开与收起按钮通过互斥可见性保证不会同时出现。
- 侧栏内部继续采用三行 `Grid`，底部收起按钮位于独立 `Auto` 行并保留 14 像素底部内边距，不进入滚动区。
- “视图 → 显示侧边栏”同步勾选状态，并提供 `Ctrl+B`；`sidebarCollapsed` 继续写入设置并在启动时恢复。
- “帮助 → 建议与问题反馈”提供 `Ctrl+Shift+F`，打开跟随主题和强调色的内部窗口。
- 反馈邮件模板只自动填入软件版本和 Windows 版本；复制失败、默认邮件应用缺失或启动失败都在窗口内部提示，不使用阻塞式消息框。

## 1.4.4 顶部精简与项目中心排版

- 菜单下方原 72 像素全局信息带已移除，内容区直接承接菜单栏，窗口只保留菜单、主体和底部状态栏三行结构。
- 全局索引、版本胶囊、升级入口和取消任务不再集中在顶部；升级入口迁入侧栏版本卡，取消任务迁入归片工作区的任务操作区。
- 侧栏收起后的展开按钮位于主体内容左侧独立窄列，不依赖已删除的顶部信息带，也不会覆盖页面内容。
- 项目中心版本卡采用“正文、18 像素间隔、操作按钮”三列网格，正文允许换行，操作按钮固定完整热区。
- 最近项目卡采用同样的三列网格，项目名、更新时间和摘要独立成三行，摘要换行且不会进入按钮区域。
- 项目中心使用 32/26/32/28 页面边距，主要模块间距统一到 22–24 像素；卡片样式继续使用动态主题资源并兼容高 DPI。

## 1.5.1 深色菜单与结果表横向滚动

- 顶部菜单、下拉子菜单、多级子菜单和右键菜单统一使用应用内 `MenuItem` / `ContextMenu` 模板，弹层背景、边框、文字、快捷键、悬停、打开、禁用、选中和键盘焦点状态全部使用动态主题资源。
- 浅色、深色和高对比主题分别定义菜单弹层与滚动条配色；主题字典替换后弹层和滚动条即时更新，无需重启。
- 结果表继续使用一个 `DataGrid` 内部滚动视口，横向滚动条为 `Auto`：正常宽度隐藏，列总宽度溢出时显示在表格底部、快捷摘要上方。
- 表头与数据体由同一 `DataGrid` 滚动视口驱动，拖动滚动条时同步移动；前三个冻结列继续固定，其余列和对应表头保持对齐。
- 滚动槽、滑块、悬停与拖动状态使用动态资源；水平滚动条高度 14、滑块最小宽度 28，兼顾 100%、125% 和 150% DPI。
