# 像素蛋挞

像素蛋挞是一款面向摄影师的 Windows 本地工具平台，提供本地分片、专业归片、项目历史以及照片压缩、水印、整理、重命名和转档等工具入口。照片、路径、编号、EXIF 和报告始终只在本机处理；现有归片能力继续读取客户返回的 JPG、TXT、CSV、文件夹或编号文本，在照片来源目录中建立综合索引并安全复制用户确认的文件。

## 普通用户安装

普通用户只需双击 `像素蛋挞_Setup_2.0.4_x64.exe`，按图形安装向导完成安装，然后从桌面或开始菜单打开“像素蛋挞”。安装包已包含 .NET 运行环境，不需要安装 Visual Studio、.NET Runtime 或任何命令行工具。

## 首次新手教程

全新安装第一次启动时会进入 22 步强制交互式教程。教程使用 `%LocalAppData%\KitaoPhotoSelector\Tutorial\` 中的有效演示 JPG 和安全 RAW 占位文件，逐步引导添加来源、扫描、导入编号、匹配、复制和导出报告。教程每一步都需要用户操作真实按钮并验证结果，未完成时下次启动会恢复最近有效步骤。

已使用旧版的用户升级后不会被强制锁定，可以在“帮助”中选择“重新查看完整教程”“重置教程演示数据”或“删除教程演示数据”。教程数据清理会严格验证路径，只处理应用创建的 Tutorial 目录。

“帮助 → 建议与问题反馈”会打开软件内部反馈窗口。`Ctrl+Shift+F` 可直接打开，`Ctrl+B` 可展开或收起侧栏。只有用户主动点击“撰写邮件”时才会调用 Windows 默认邮件应用；模板仅自动填写软件版本和 Windows 版本，不包含照片、路径、项目、客户、EXIF、授权或日志信息。

系统要求：Windows 10 x64（Build 19041 或以上）或 Windows 11 x64。不支持 32 位 Windows、macOS 和 Linux。

## 免费版与专业版

- 免费版无需激活，可完成 JPG、RAW、JPG + RAW、客户 JPG / TXT / CSV 输入、递归扫描、基础冲突选择、分类复制、基础 CSV 报告和完整教程；每项目最多 30 个唯一编号、1 个来源目录，显示最近 1 个项目。
- 专业版通过同一 EXE 即时解锁不限编号、多来源、持久化高速索引、自定义格式、进阶 JPG / 冲突分析、全部项目历史、JSON 与完整日志报告、输出预设和批量项目。
- 授权失效或停用只会退回免费版，不会删除项目、索引、照片、报告或输出文件。生产授权参数缺失时软件仍以免费版安全启动。

## 支持的归片类别

- 仅 JPG：查找 `.JPG`、`.JPEG`。
- 仅 RAW：查找 ARW、CR2、CR3、NEF、RAF、DNG 等默认 RAW 格式。
- JPG + RAW：同一条选片记录分别匹配 JPG 和 RAW，允许完整匹配或部分匹配。
- 自定义格式：可输入 XMP、TIF、TIFF、PSD 等扩展名，自动补点、转大写、去重并校验。

默认类别为“JPG + RAW”，默认输出模式为“按文件类别输出”，生成 `JPG`、`RAW` 和 `OTHER` 子目录。

## 使用流程

1. 添加照片来源目录，为目录设置 JPG、RAW、混合或其他格式用途及优先级，然后扫描照片文件；免费版支持 1 个目录，专业版支持多个目录和磁盘。
2. 选择归片类别；如使用自定义格式，输入目标扩展名。
3. 把客户选中的 JPG、文件夹、TXT 或 CSV 拖入软件，也可以粘贴编号后解析。
4. 单击“开始匹配”。索引为空时按钮仍可点击，并会明确显示未找到项。
5. 存在冲突时，打开“查看明细”并为相应格式手动选择正确候选。
6. 选择输出目录、填写项目名称和输出模式，单击“复制已匹配文件”。
7. 免费版输出 `匹配报告.csv`；专业版同时输出 `匹配报告.json` 和 `操作日志.txt`。

## JPG 来源质量规则

客户拖入的 JPG 默认只作为选片依据，用于读取文件名、编号和必要的画面核验信息；正式 JPG 始终优先从照片来源目录查找。软件会读取像素尺寸、总像素、EXIF、相机品牌和型号、原始拍摄时间、ICC、软件处理标记、方向及文件大小，并对来源文件和客户文件进行比较。文件大小只作为辅助提示和排序末项，绝不会单独用于认定图片是否为原图。

“来源 JPG 未找到时”提供三种模式：

- 严格模式（默认）：不采用客户文件，显示“未找到来源 JPG；客户返回文件未自动采用”。
- 智能备用模式：展示完整质量信息和风险提示，必须由用户在明细中手动确认后才可复制。
- 允许客户文件模式：可采用客户文件，但界面和报告会标记“使用客户返回 JPG；原始质量未经确认”。

JPG 文件来源在界面和报告中区分为来源目录、客户返回和用户手动指定。多个来源目录 JPG 不能明确选择时保持冲突，由用户手动处理，不会因为某个文件更大就自动采用。

## 匹配与安全规则

- 先按标准化完整文件名和目标扩展名匹配，再按末尾数字编号和目标扩展名匹配。
- JPG、RAW 和自定义格式独立匹配；一种格式缺失或冲突不会抹掉其他格式的正确结果。
- 不使用模糊匹配、编辑距离或随机候选自动认定。
- 多候选冲突必须由用户手动选择。
- 客户输入记录全部保留，实际复制按规范化完整源路径去重。
- 已有同名目标文件不会被覆盖，软件会生成 `_2`、`_3` 等安全文件名。
- 软件只复制，不会移动、删除、重命名或修改任何源文件。

## 数据位置

程序文件安装在 `C:\Program Files\像素蛋挞\`。为兼容旧版本，用户设置、综合索引、技术日志和教程数据继续保存在：

```text
%LocalAppData%\KitaoPhotoSelector\
├─ settings.json
├─ Indexes\
├─ Logs\
├─ Cache\
├─ License\
├─ Projects\
└─ Tutorial\
```

卸载默认保留用户设置、索引和日志。

## 开发构建

开发环境使用 .NET 10、C#、WPF 和 MVVM。解决方案为 `RAWSelectionAssistant.sln`。

```powershell
.\build_debug.ps1
.\build_release.ps1
.\build_installer.ps1
```

这些脚本仅供开发和发布维护使用。正式程序的快捷方式直接指向 `KitaoPhotoSelector.exe`。

## 项目结构

```text
src/RAWSelectionAssistant.Core/    通用模型、解析、索引、匹配、复制、报告、设置
src/RAWSelectionAssistant/         WPF 界面、MVVM、桌面交互、单实例入口
tests/RAWSelectionAssistant.Tests/ 自动化测试和完整验收场景
installer/                         Inno Setup 安装脚本
artifacts/publish/win-x64/         Release 自包含发布目录
artifacts/installer/               最终单文件安装包
```

## 隐私

软件不主动联网、不启动 HTTP 服务、不监听 localhost、不包含登录、云端或遥测功能。所有照片文件名、索引和报告均保留在本机。反馈功能只在用户主动操作后调用系统默认邮件应用，不自动上传任何业务数据。
